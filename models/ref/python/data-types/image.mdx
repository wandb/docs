## <Badge color="yellow" size="lg" shape="rounded">Class</Badge> wandb.Image



A class for logging images to W&B.



```python
data_or_path: 'ImageDataOrPathType',
mode: 'str | None' = None,
caption: 'str | None' = None,
grouping: 'int | None' = None,
classes: 'Classes | Sequence[dict] | None' = None,
boxes: 'dict[str, BoundingBoxes2D] | dict[str, dict] | None' = None,
masks: 'dict[str, ImageMask] | dict[str, dict] | None' = None,
file_type: 'str | None' = None
```

## Args

<ResponseField name="data_or_path" type="ImageDataOrPathType">
Accepts NumPy array/pytorch tensor of image data,
a PIL image object, or a path to an image file. If a NumPy
array or pytorch tensor is provided,
the image data will be saved to the given file type.
Values are expected to already be in the range [0, 255].
- pytorch tensor should be in the format (channel, height, width)
- NumPy array should be in the format (height, width, channel)
</ResponseField>

<ResponseField name="mode" type="str | None">
The PIL mode for an image. Most common are "L", "RGB", "RGBA". Full Pillow docs for more information https://pillow.readthedocs.io/en/stable/handbook/concepts.html#modes
</ResponseField>

<ResponseField name="caption" type="str | None">
Label for display of image.
</ResponseField>

<ResponseField name="grouping" type="int | None">
The grouping number for the image.
</ResponseField>

<ResponseField name="classes" type="Classes | Sequence[dict] | None">
A list of class information for the image, used for labeling bounding boxes, and image masks.
</ResponseField>

<ResponseField name="boxes" type="dict[str, BoundingBoxes2D] | dict[str, dict] | None">
A dictionary containing bounding box information for the image. see https://docs.wandb.ai/models/ref/python/data-types/boundingboxes2d
</ResponseField>

<ResponseField name="masks" type="dict[str, ImageMask] | dict[str, dict] | None">
A dictionary containing mask information for the image. see https://docs.wandb.ai/models/ref/python/data-types/imagemask
</ResponseField>

<ResponseField name="file_type" type="str | None">
The file type to save the image as. This parameter has no effect if `data_or_path` is a path to an image file.
</ResponseField>
