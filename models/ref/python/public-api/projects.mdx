## <Badge color="yellow" size="lg" shape="rounded">Class</Badge> wandb.apis.public.Projects
```python
service_api: 'ServiceApi',
entity: 'str',
per_page: 'int' = 50
```



An lazy iterator of `Project` objects.

An iterable interface to access projects created and saved by the entity.



## Args

<ResponseField name="service_api" type="ServiceApi">
The service API used to query W&B.
</ResponseField>

<ResponseField name="entity" type="str">
The entity which owns the projects.
</ResponseField>

<ResponseField name="per_page" type="int">
The number of projects to fetch per request to the API.
</ResponseField>



## Examples

```python
from wandb.apis.public.api import Api

# Find projects that belong to this entity
projects = Api().projects(entity="entity")

# Iterate over files
for project in projects:
    print(f"Project: {project.name}")
    print(f"- URL: {project.url}")
    print(f"- Created at: {project.created_at}")
    print(f"- Is benchmark: {project.is_benchmark}")
```
