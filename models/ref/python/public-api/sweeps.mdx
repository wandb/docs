## <Badge color="yellow" size="lg" shape="rounded">Class</Badge> wandb.apis.public.Sweeps



A lazy iterator over a collection of `Sweep` objects.



```python
service_api: 'ServiceApi',
entity: 'str',
project: 'str',
per_page: 'int' = 50,
filters: 'dict[str, Any] | None' = None
```

## Args

<ResponseField name="service_api" type="ServiceApi">
The service API used to query W&B.
</ResponseField>

<ResponseField name="entity" type="str">
The entity which owns the sweeps.
</ResponseField>

<ResponseField name="project" type="str">
The project which contains the sweeps.
</ResponseField>

<ResponseField name="per_page" type="int">
The number of sweeps to fetch per request to the API.
</ResponseField>

<ResponseField name="filters" type="dict[str, Any] | None">
(dict) queries for specific sweeps using the runs filters, See wandb/apis/public/api.py:runs for more details.
</ResponseField>





## Examples

```python
from wandb.apis.public import Api

sweeps = Api().project(name="project_name", entity="entity").sweeps()

# Iterate over sweeps and print details
for sweep in sweeps:
    print(f"Sweep name: {sweep.name}")
    print(f"Sweep ID: {sweep.id}")
    print(f"Sweep URL: {sweep.url}")
    print("----------")
```
