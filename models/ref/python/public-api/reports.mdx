## <Badge color="yellow" size="lg" shape="rounded">Class</Badge> wandb.apis.public.Reports



Reports is a lazy iterator of `BetaReport` objects.



```python
(service_api: 'ServiceApi',
project: 'Project',
name: 'str | None' = None,
entity: 'str | None' = None,
per_page: 'int' = 50)
```

## Args

<ResponseField name="service_api" type="ServiceApi">
Interface to the wandb-core service that performs W&B API calls for this collection.
</ResponseField>

<ResponseField name="project" type="Project">
The project to fetch reports from.
</ResponseField>

<ResponseField name="name" type="str | None">
The name of the report to filter by. If `None`, fetches all reports.
</ResponseField>

<ResponseField name="entity" type="str | None">
The entity name for the project. Defaults to the project entity.
</ResponseField>

<ResponseField name="per_page" type="int">
Number of reports to fetch per page (default is 50).
</ResponseField>
