## Usage

```bash
server [OPTIONS] COMMAND [ARGS]...
```

## Description

Commands for operating a local W&B server

## Subcommands

| Command | Description |
|---------|-------------|
| `wandb server start` | Start a local W&B Server instance in a Docker container. |
| `wandb server stop` | Stop a running local W&B server. |
