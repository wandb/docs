## Create a new notebook

<Tabs>
<Tab title="Landing page">
From landing page (`https://wandb.ai/`)

    1. Select **Notebooks** tab.
    2. From the modal, select a project from the **Project** dropdown.
    3. Click **Create**.
</Tab>
<Tab title="Project">

From a project page (`https://wandb.ai/org/project`)

    1. From the project sidebar, select **Notebooks**.
    2. Click **Create notebook**.

1. Select Notebooks from sidebar
2. Click Create notebook
</Tab>
</Tabs>
