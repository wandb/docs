title: Configure a notebook
---

Configure a notebook's settings to tailor its behavior and appearance to your needs.

## Open notebook settings

Configure how your notebook or application looks and behaves. Notebook settings are specific to each notebook and do not impact other notebooks. You can customize settings such as the notebook's display, export options, upload custom CSS and HTML files to alter the appearance of your notebook, and more.

To edit notebook settings:

1. Select **NOTEBOOK SETTINGS** (<Icon icon="gear" iconType="solid"/>) in the upper-right corner of the notebook.
2. Adjust the desired notebook settings from the menu that appears.

For more information, see the [Notebook settings documentation](https://docs.marimo.io/guides/configuration/notebook_settings/).

## Configure startup behavior

Configure how a notebook behaves on startup, on cell changes, and on module changes by adjusting the [runtime execution settings](https://docs.marimo.io/guides/configuration/runtime_configuration/).

- **On startup**: Whether to automatically run the notebook when it is opened.
- **On cell change**: Whether to automatically run dependent cells when a cell is modified.
- **On module change**: Whether to automatically run impacted cells when an imported module is updated.

Select the notebook run button (<Icon icon="bolt-lightning" iconType="solid"/>) in the notebook footer. Toggle the desired runtime execution settings from the menu that appears.

## Configure editor preferences
To configure editor preferences:

1. Select **NOTEBOOK SETTINGS** (<Icon icon="gear" iconType="solid"/>) in the upper-right corner of the notebook.
2. Navigate to the **Editor** section in the settings menu.
3. Adjust the desired editor preferences, such as code font size, line numbers, and syntax highlighting options.

For more information, see the [Editor preferences documentation](https://docs.marimo.io/guides/editor_features/overview/)
