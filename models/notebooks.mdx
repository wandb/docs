---
title: Notebooks overview
---

Notebooks contain *cells* that can hold code, text, or SQL queries.

Unlike traditional notebooks, Notebooks understand the relationships between cells and uses this information to keep your code and outputs consistent. These relationships are represented as a dataflow graph, which encodes how variables flow from one cell to another.
