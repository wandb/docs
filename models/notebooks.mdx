---
title: Notebooks overview
---

Notebooks contain *cells* that can hold code, text, or SQL queries.

Unlike traditional notebooks, marimo understands the relationships between cells and uses this information to keep your code and outputs consistent. These relationships are represented as a dataflow graph, which encodes how variables flow from one cell to another.

Use the [Variables explorer](https://docs.marimo.io/guides/editor_features/dataflow/#variables-explorer) or the [Dependencies panel](https://docs.marimo.io/guides/editor_features/dataflow/#dependencies-panel) to understand relationships between cells.
