이 페이지에서는 채팅 시작 및 재개, 후속 메시지 큐잉, 컨텍스트 추가, 네트워크 액세스 부여, 응답에 대한 피드백 제공 등 ARIA와의 대화를 관리하는 방법을 설명합니다. 컨텍스트에는 run, workspace 패널, W&amp;B Weave 트레이스, 이미지 등이 포함될 수 있습니다. 또한 대화 이름 변경, 고정, 삭제를 통해 채팅 이력을 정리하는 방법도 다룹니다.

## 새 채팅 시작 {#start-a-new-chat}

새 채팅을 시작하려면 ARIA를 연 다음, 채팅 창 오른쪽 위에 있는 연필 아이콘을 클릭하세요.

한 번에 여러 채팅을 동시에 진행할 수 있습니다. 채팅 창을 닫았더라도 ARIA가 채팅에 응답하면 알림을 받게 됩니다.

새 채팅을 시작해도 이전 대화는 삭제되지 않습니다. [이전 대화 보기](/ko/aria/chat#view-chat-history)를 하려면 **<Icon icon="sidebar-reveal" iconType="solid" />**(**채팅 이력 표시**)를 클릭하여 채팅 이력 사이드바를 여세요.

## 메시지 보내기 {#send-a-message}

메시지를 입력하고 **Enter**를 눌러 전송하세요.

* 새 줄을 추가하려면 **Shift+Enter**를 누르세요.
* 이미지를 추가하려면 **+**를 클릭하세요.
* run 레퍼런스를 추가하려면 `<Icon icon="at" iconType="solid"/>`를 입력하고 목록에서 run을 선택하세요. 입력하여 목록을 필터링하거나 퍼지 검색할 수 있습니다.
* 더 복잡한 메시지를 작성해야 하는 경우 텍스트 편집기에서 작성한 후 붙여넣으세요. 일반 텍스트도 지원되며, 붙여넣은 `@` 문자는 run 레퍼런스로 인식되지 않습니다.

현재 오퍼레이션을 취소하고 다음 [큐에 대기 중인 메시지](#queue-messages)를 *즉시* 전송하려면 텍스트 입력란 오른쪽의 중지 아이콘을 누르세요.

컨텍스트를 유지할 수 있도록 ARIA는 선형 플롯과 막대 차트를 채팅에 바로 렌더링하며, 전체 화면 뷰도 지원합니다. Workspace의 **Runs** 탭에서 run 위에 마우스를 올리면 ARIA에서 해당 run의 플롯이 강조 표시되고, ARIA에서 Panel 위에 마우스를 올리면 **Runs** 탭에서 해당 run이 강조 표시됩니다.

## 큐 메시지 {#queue-messages}

메시지 큐에는 ARIA가 작업하는 동안 ARIA에 보내는 후속 작업과 질문이 저장됩니다. ARIA는 전체 대화를 컨텍스트로 사용하여 큐에 대기 중인 각 메시지를 순서대로 처리합니다. 이전 메시지가 종료되는 즉시 다음 메시지가 실행됩니다.

메시지를 하나씩 보내기 위해 채팅으로 돌아오는 대신, 큐를 사용해 여러 step을 한 번에 등록한 후 자리를 비우세요. 예를 들어, 비교 작업부터 시작할 수 있습니다.

<AriaChatBubbles prompt="최근 10개의 run을 비교하고 어떤 하이퍼파라미터가 가장 중요했는지 알려줘." response="학습률과 배치 크기가 해당 10개 run의 검증 손실 분산 대부분을 차지합니다. 각 run의 세부 정보는 아래에서 확인하세요." />

ARIA가 작업하는 동안 채팅 창으로 추가 요청을 보내세요. W&amp;B는 대기 중인 요청을 ARIA의 큐에 추가합니다.

이 예제에서는 한 번에 두 개의 메시지를 보냅니다.

```text title="Queued messages"
해당 run들의 검증 손실을 학습률에 따라 차트로 그려주세요.

비교 결과를 팀과 공유할 수 있도록 리포트로 작성해주세요.
```

큐 헤더에는 대기 중인 메시지 수가 표시됩니다. 큐에 대기 중인 각 메시지에는 세 가지 컨트롤이 있습니다.

* **연필 아이콘** (<Icon icon="pencil" iconType="solid" />): ARIA가 메시지를 실행하기 전에 메시지를 편집합니다. ARIA는 메시지를 메시지 입력 상자로 옮기고 큐에서 제거하므로, 다시 큐에 추가하려면 메시지를 다시 전송하세요. 메시지 입력 상자에 이미 초안이 있으면 이 컨트롤을 사용할 수 없습니다.
* **위쪽 화살표 아이콘** (<Icon icon="arrow-up" iconType="solid" />): 순서를 기다리지 않고 지금 메시지를 실행합니다. ARIA는 현재 작업을 중지하고 이 메시지를 다음으로 실행합니다. 다른 큐의 메시지는 순서를 유지합니다.
* **휴지통 아이콘** (<Icon icon="trash" iconType="solid" />): 큐에서 메시지를 Delete합니다.

큐에 대기 중인 메시지는 [run 멘션](/ko/aria/chat#add-context-to-a-conversation) 및 [이미지](/ko/aria/chat#add-an-image-to-a-conversation)를 포함해 연결한 컨텍스트를 유지합니다.

큐는 실행할 대화가 필요하므로 채팅에서 첫 번째 메시지를 보낸 후에 큐잉이 시작됩니다. 처음 전송하는 메시지와 빈 큐가 있는 유휴 채팅에 전송하는 모든 메시지는 즉시 ARIA로 전송됩니다. 각 채팅에는 자체 큐가 있으며, 닫은 채팅의 큐도 계속 실행됩니다.

ARIA가 계속 진행하기 전에 추가 설명을 위한 답변이나 권한이 필요하면 응답할 때까지 큐가 일시 중지됩니다. 먼저 응답하지 않고 큐에 대기 중인 메시지를 실행하려면 해당 메시지 옆의 위쪽 화살표 아이콘을 클릭하세요.

## 대화 관리 {#manage-conversations}

다음 섹션에서는 대화를 보고, 이름을 변경하고, 고정하고, 삭제하는 방법을 설명합니다.

### 채팅 이력 보기 {#view-chat-history}

이전 대화를 보려면 다음을 수행하세요.

1. ARIA를 엽니다.
2. **<Icon icon="sidebar-reveal" iconType="solid" />**(**Reveal chat history**)를 클릭하여 채팅 이력 사이드바를 엽니다. 기본적으로 접혀 있습니다. 사이드바가 열려 있는 동안에는 동일한 컨트롤이 **Collapse chat history**로 표시됩니다.
3. 재개할 대화를 선택하세요.

고정된 대화는 날짜별로 그룹화되지 않고 단일 **Pinned** 헤더 아래에 가장 먼저 표시됩니다. 이어서 고정되지 않은 대화가 **Today**, **Yesterday**, **Last 7 Days**, **Last 30 Days** 순으로, 그다음에는 월별로, 1년이 넘은 대화는 연월별로 그룹화되어 표시됩니다. 각 그룹 내에서는 가장 최근에 활동이 있었던 대화가 먼저 표시됩니다.

대화 행에 마우스를 올리거나 키보드로 포커스를 이동하면 두 가지 컨트롤이 나타납니다.

* **<Icon icon="thumbtack" iconType="solid" />**(**Pin chat** / **Unpin chat**): [대화 고정](#pin-a-conversation)을 참조하세요.
* **<Icon icon="ellipsis" iconType="solid" />**(**Chat actions**): **Rename chat** 및 **Delete chat** 항목이 있는 메뉴가 열립니다. [대화 이름 변경](#rename-a-conversation) 및 [이전 대화 삭제](#delete-previous-conversations)를 참조하세요.

채팅 이력 사이드바의 **Customize** 섹션에는 사용자가 만든 ARIA 자동화도 함께 표시됩니다. [ARIA에서 자동화 사용하기](/ko/models/automations/create-automations/aria)를 참조하세요.

### 대화 이름 바꾸기 {#rename-a-conversation}

새 채팅에서 첫 메시지를 보내면 ARIA가 대화 제목을 생성합니다. ARIA가 제목을 작성하는 동안에는 채팅 이력 사이드바에서 제목이 반짝이는 효과로 표시됩니다. ARIA가 제목을 생성하지 못하면 첫 프롬프트의 일부 발췌문이 대화 제목으로 사용됩니다. ARIA는 대화 제목을 한 번만 생성하므로 이후에 메시지를 보내도 제목은 바뀌지 않습니다.

대화 제목을 변경하려면 다음 단계를 따르세요.

1. 채팅 이력 사이드바에서 이름을 바꾸려는 대화에 마우스를 올립니다.
2. **<Icon icon="ellipsis" iconType="solid" />** (**Chat actions**)를 클릭한 다음 **Rename chat**을 선택합니다. 제목이 편집 가능한 필드로 바뀝니다.
3. 제목을 최대 255자까지 입력합니다.
4. **Enter** 키를 누르거나 **<Icon icon="check" iconType="solid" />** (**Save chat title**)를 클릭하여 저장합니다. 변경 사항을 취소하려면 **Escape** 키를 누르거나 **<Icon icon="xmark" iconType="solid" />** (**Cancel rename**)를 클릭합니다.

필드를 비운 채로 저장하면 제목이 첫 프롬프트의 발췌문으로 바뀌며, 발췌문이 없으면 **Untitled conversation**으로 바뀝니다. 공백만 입력하고 저장하면 제목이 지워지지 않고 이름 바꾸기가 취소됩니다.

변경된 제목은 열려 있는 모든 브라우저 탭에 동기화됩니다. 휴대폰에서도 채팅 이름을 바꿀 수 있습니다. 자세한 내용은 모바일 앱 문서의 [Chat with ARIA](/ko/platform/hosting/monitoring-usage/mobile-app#chat-with-aria)를 참조하세요.

### 대화 고정 {#pin-a-conversation}

대화를 고정하면 새 chat이 쌓여도 아래로 밀려나지 않고 채팅 이력 사이드바 맨 위에 계속 표시됩니다.

1. 채팅 이력 사이드바에서 고정할 대화 위에 마우스를 올립니다.
2. **<Icon icon="thumbtack" iconType="solid" />**(**Pin chat**)을 클릭합니다. 해당 대화가 **Pinned** 헤더 아래로 이동합니다.
3. 고정을 해제하려면 고정된 대화에서 **<Icon icon="thumbtack" iconType="solid" />**(**Unpin chat**)을 클릭합니다.

고정할 수 있는 대화 수에는 제한이 없으며, 고정 변경 사항은 열려 있는 모든 브라우저 탭에 동기화됩니다. 고정은 본인의 대화 목록에만 적용되며, 동일한 프로젝트에 액세스 권한이 있는 팀원에게 보이는 내용에는 영향을 주지 않습니다.

### 이전 대화 삭제 {#delete-previous-conversations}

이전 대화를 삭제하려면 다음 단계를 따르세요:

1. ARIA를 엽니다.
2. **<Icon icon="sidebar-reveal" iconType="solid" />**(**Reveal chat history**)를 클릭해 채팅 이력 사이드바를 엽니다.
3. 삭제하려는 대화에 마우스를 올린 후 **<Icon icon="ellipsis" iconType="solid" />**(**Chat actions**)를 클릭한 다음 **Delete chat**을 선택합니다.
4. **Delete this chat?** 대화상자에서 **Delete**를 클릭해 확인합니다. 이 작업은 되돌릴 수 없습니다.

## 채팅 창 분리 {#undock-chat-window}

채팅 창을 별도의 창으로 분리할 수 있으며, 이렇게 하면 ARIA의 응답을 프로젝트 데이터와 나란히 볼 수 있습니다.

채팅을 분리하려면 채팅 창 오른쪽 상단에서 닫기(**X**) 버튼 옆에 있는 분리 아이콘을 클릭하세요.

## 대화에 컨텍스트 추가하기 {#add-context-to-a-conversation}

run, workspace 패널, Weave 트레이스, 평가를 채팅에 첨부하면 질문에 필요한 정확한 컨텍스트를 ARIA에 제공할 수 있습니다. 첨부한 각 항목은 메시지 입력란에 태그로 표시되며, 필요 없으면 제거할 수 있습니다. 메시지 하나에 여러 항목을 첨부할 수도 있습니다. 컨텍스트를 추가해도 메시지가 자동으로 전송되지는 않으니, 준비가 되면 **Send**를 클릭하세요.

페이지에서 컨텍스트를 추가하면 ARIA는 채팅 창에 열려 있는 대화에 해당 컨텍스트를 추가합니다. 열려 있는 대화가 없으면 ARIA가 새 대화를 시작합니다.

### run 언급하기 {#mention-a-run}

메시지 상자에 `@`를 입력하고 run을 선택하세요. 예를 들어, 프롬프트에 run 이름을 포함해 ARIA에 특정 run을 분석해 달라고 요청할 수 있습니다:

```text title="User prompt"
Analyze the run @run-20230615_123456-abcdefg and summarize the results
```

workspace의 **Runs** table에서 run을 추가할 수도 있습니다. run에 마우스를 올리고 **액션 (<Icon icon="ellipsis" iconType="solid" />)** 메뉴를 클릭한 다음 **Ask ARIA**를 선택하세요.

### workspace 패널 추가 {#add-a-workspace-panel}

workspace 패널을 채팅에 첨부하려면 다음 단계를 따르세요.

1. workspace에서 패널에 마우스를 올린 다음 패널의 **액션 (<Icon icon="ellipsis" iconType="solid" />)** 메뉴를 클릭하세요.
2. **Ask ARIA**를 선택하세요. 패널이 첨부된 상태로 ARIA가 열립니다.
3. `Why does loss spike after step 2,000?`와 같은 질문을 입력하고 전송하세요.

**Ask ARIA**는 편집 권한이 있는 workspace의 패널 메뉴에 표시되며, report의 패널에는 표시되지 않습니다.

### Weave 트레이스 및 평가 추가 {#add-weave-traces-and-evaluations}

Weave에서 ARIA 버튼을 클릭하면 트레이스, 평가 또는 평가 결과를 채팅에 첨부할 수 있습니다. 버튼에 마우스를 올리면 **Ask ARIA about this trace** 또는 **Ask ARIA about these evals**와 같은 레이블을 확인할 수 있습니다. 버튼은 다음 위치에 표시됩니다.

* **Traces** 또는 **Evals** table: 하나 이상의 행을 선택하세요. table 툴바에 버튼이 나타나며, 버튼을 누르면 선택한 모든 행이 첨부됩니다.
* **트레이스 또는 평가 세부 정보 페이지**: 페이지 헤더에 버튼이 나타납니다.
* **평가 비교**: 평가를 비교하면서 예시의 세부 정보를 볼 때 버튼을 누르면 해당 예시의 예측과 점수가 첨부됩니다.

ARIA는 첨부된 트레이스와 평가를 바탕으로 질문에 답변합니다. 예를 들면 다음과 같습니다.

```text title="User prompt"
이 예시들에서 모델 점수가 이전 평가보다 낮게 나온 이유는 무엇인가요?
```

## 대화에 이미지 추가하기 {#add-an-image-to-a-conversation}

채팅 창 왼쪽 하단의 더하기 아이콘(`+`)을 클릭해 대화에 이미지를 추가하세요. 그런 다음 ARIA에게 이미지를 분석하거나 이미지에 관한 정보를 알려 달라고 요청할 수 있습니다.

## 네트워크 액세스 허용 {#grant-network-access}

작업에 ARIA의 샌드박스가 차단하는 도메인이 필요하면 ARIA는 네트워크 액세스를 요청하고 응답을 기다립니다. 예를 들어 Python 패키지를 설치하는 작업에는 `pypi.org`와 `files.pythonhosted.org`가 필요합니다. 기본적으로 ARIA가 코드를 실행하는 샌드박스는 W&amp;B 서비스에는 연결할 수 있지만, 그 밖의 인터넷 도메인은 대부분 차단합니다.

요청은 채팅의 **The agent is requesting network access** 아래에 표시됩니다. 요청 사유와 요청된 도메인 목록이 표시되며, 모든 도메인이 선택되어 있습니다. 다음 중 한 가지 방법으로 요청에 응답하세요.

* 액세스를 허용하려면 허용하지 않을 도메인의 선택을 해제한 다음 **Grant access**를 클릭하세요. ARIA가 작업을 계속 진행하며, 허용된 도메인에 연결할 수 있습니다.
* 액세스를 거부하려면 **Deny**를 클릭하세요. ARIA는 추가 액세스 없이 작업을 계속 진행합니다.

요청이 대기 중인 동안에는 메시지를 보낼 수 없으며, 큐에 대기 중인 메시지도 실행되지 않습니다.

<Warning>
  샌드박스에서 실행되는 코드는 허용된 모든 도메인으로 데이터를 전송할 수 있습니다. 신뢰할 수 있는 도메인에만 액세스를 허용하세요.
</Warning>

허용된 도메인은 철회하지 않는 한 해당 대화가 끝날 때까지 계속 사용할 수 있습니다. 새 채팅은 항상 기본 액세스만 허용된 상태로 시작합니다. 도메인을 직접 추가할 수는 없으며, 작업에 필요할 때 ARIA가 요청합니다.

### 네트워크 액세스 검토 또는 철회 {#review-or-revoke-network-access}

대화에서 액세스를 허용하면 메시지 입력란의 더하기 아이콘(`+`) 옆에 **<Icon icon="link" iconType="solid" />** (**Manage network access**)가 표시됩니다.

액세스를 철회하려면 다음을 수행하세요.

1. **<Icon icon="link" iconType="solid" />** (**Manage network access**)를 클릭합니다. 해당 대화에서 허용된 도메인 목록이 열립니다.
2. 철회하려는 도메인의 선택을 해제합니다.
3. **Update access**를 클릭합니다.

W&amp;B가 철회된 도메인 목록을 담은 메시지를 ARIA에 보내며, 이후 ARIA는 해당 도메인에 액세스하지 않고 실행됩니다. ARIA가 작업 중일 때는 네트워크 액세스를 변경할 수 없습니다.

## 피드백 제공 {#provide-feedback}

ARIA 응답에 대한 피드백을 제공하려면 응답 끝에 있는 엄지손가락 올림 또는 내림 아이콘을 클릭하세요. 여러분의 피드백은 W&amp;B가 ARIA의 성능과 정확도를 개선하는 데 도움이 됩니다.

W&amp;B가 ARIA의 데이터 사용을 어떻게 처리하는지에 대한 자세한 내용은 [거버넌스 및 보안](/ko/aria/governance)을 참조하세요.
