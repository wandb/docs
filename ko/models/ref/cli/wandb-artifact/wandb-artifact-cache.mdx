## 설명 {#description}

로컬 아티팩트 캐시를 관리합니다.

중복 다운로드를 방지하기 위해 다운로드한 아티팩트 파일을 로컬에 캐시합니다.

하위 명령을 사용해 캐시가 사용하는 디스크 공간을 확인하고 확보하세요.

## 하위 명령어 {#subcommands}

| 명령어                            | 설명                    |
| ------------------------------ | --------------------- |
| `wandb artifact cache cleanup` | 로컬 아티팩트 캐시의 크기를 줄입니다. |
