## 설명 {#description}

프로젝트의 작업 목록 보기

## 옵션 {#options}

| Flag            | Type | 설명                                |
| --------------- | ---- | --------------------------------- |
| `--project, -p` | STR  | 작업 목록을 가져올 프로젝트입니다. **기본값**: None |
| `--entity, -e`  | STR  | 작업이 속한 entity입니다. **기본값**: models |
