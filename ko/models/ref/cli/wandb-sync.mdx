<div id="usage">
  ## 사용
</div>

```bash
sync [OPTIONS] [PATHS]...
```

<div id="description">
  ## 설명
</div>

기존 로컬 W&amp;B run 데이터를 클라우드에 업로드합니다.

오프라인 상태이거나 완료되지 않은 runs를 W&amp;B 서버에 동기화합니다. 특정 runs를 동기화하려면 PATHS를 지정하고, 인수 없이 실행하면 wandb 폴더에서 아직 업로드되지 않은 runs가 동기화됩니다.

PATHS를 지정하지 않으면 동기화 전에 확인을 요청합니다. 확인을 건너뛰려면 --yes를, 동기화하지 않고 종료하려면 --dry-run을 전달하세요.

PATHS는 run 디렉터리여야 하며, 일반적으로 다음과 같은 형식입니다.

./wandb/run-YYYYMMDD&#95;HHMMSS-RUN&#95;ID

YYYYMMDD&#95;HHMMSS는 run이 생성된 시각의 timestamp이고, RUN&#95;ID는 해당 run의 unique ID입니다.

예를 들어 로컬 runs와 각각의 동기화 status를 summary로 표시하려면 다음과 같이 실행합니다.

```bash
wandb sync --dry-run
```

./wandb/run-20170617&#95;000000-abcd1234에 저장된 run ID abcd1234를 동기화하려면 다음을 실행하세요.

```bash
wandb sync ./wandb/run-20170617_000000-abcd1234
```

wandb 폴더에 있는 동기화되지 않은 run을 모두 동기화하려면 다음을 실행하세요.

```bash
wandb sync
```

동기화된 run의 로컬 데이터를 삭제하려면 `wandb clean`을 사용하세요. 참조:

```bash
wandb clean --help
```

에서 자세한 내용을 확인하세요.

<div id="options">
  ## Options
</div>

| 플래그                                  | 유형        | 설명                                                                                                                                                   |
| ------------------------------------ | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `-v, --verbose`                      | BOOL Flag | 더 자세한 정보를 출력합니다. **Default**: False                                                                                                                  |
| `--yes`                              | BOOL Flag | 확인을 요청하지 않습니다. **Default**: False                                                                                                                    |
| `--id`                               | STR       | 기존 run ID로 업로드합니다. 동일한 entity 및 프로젝트의 여러 파일을 동기화할 때 이 값이 설정되어 있으면, 파일이 시작 시간 순서대로 동기화됩니다. **Default**: None                                          |
| `--project, -p`                      | STR       | 동기화되는 모든 run의 프로젝트를 재정의합니다. **Default**: None                                                                                                        |
| `--entity, -e`                       | STR       | 동기화되는 모든 run의 entity를 재정의합니다. **Default**: None                                                                                                      |
| `--job-type`                         | STR       | 동기화되는 모든 run의 작업 유형을 재정의합니다. **Default**: None                                                                                                       |
| `--include-online, --no-skip-online` | BOOL Flag | 온라인 모드에서 생성된 run을 포함합니다. **Default**: None                                                                                                           |
| `--include-synced, --no-skip-synced` | BOOL Flag | 이미 동기화된 run을 포함합니다. **Default**: None                                                                                                                |
| `--replace-tags`                     | STR       | &#39;old1=new1,old2=new2&#39; 형식으로 tags의 이름을 변경합니다. **Default**: None                                                                                |
| `--dry-run`                          | BOOL Flag | 아무것도 업로드하지 않고 수행될 작업만 출력합니다. **Default**: False                                                                                                      |
| `-n`                                 | INT       | 한 번에 동기화할 run의 최대 개수입니다. 동일한 run에 속한 여러 파일을 동기화할 때는 이 설정과 관계없이 시작 시간 순서대로 파일이 순차적으로 동기화됩니다. 재개된 run이거나 --id 파라미터를 사용하는 경우가 여기에 해당합니다. **Default**: 5 |
