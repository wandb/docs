## 사용 {#usage}

```bash
server [OPTIONS] COMMAND [ARGS]...
```

## 설명 {#description}

로컬 W&amp;B 서버를 관리하기 위한 명령어

## 하위 명령어 {#subcommands}

| 명령어                  | 설명                                       |
| -------------------- | ---------------------------------------- |
| `wandb server start` | 도커 컨테이너에서 로컬 W&amp;B 서버 인스턴스를 시작합니다. |
| `wandb server stop`  | 실행 중인 로컬 W&amp;B 서버를 중지합니다.          |
