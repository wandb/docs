<div id="method-moleculefrom_rdkit">
  ### <Badge color="blue" size="lg" shape="rounded">방법</Badge> Molecule.from_rdkit()
</div>

```python
data_or_path: 'RDKitDataType',
caption: 'str | None' = None,
convert_to_3d_and_optimize: 'bool' = True,
mmff_optimize_molecule_max_iterations: 'int' = 200
```

RDKit에서 지원되는 파일/객체 유형을 wandb.Molecule로 변환합니다.

<div id="arguments">
  ##### 인수
</div>

<ResponseField name="data_or_path" type="RDKitDataType">
  (`string`, rdkit.Chem.rdchem.Mol) 파일 이름 또는 rdkit.Chem.rdchem.Mol 객체로부터 Molecule을 초기화할 수 있습니다.
</ResponseField>

<ResponseField name="caption" type="str | None">
  (`string`) 표시용으로 분자에 연결된 캡션입니다.
</ResponseField>

<ResponseField name="convert_to_3d_and_optimize" type="bool">
  (bool) 3D 좌표가 있는 rdkit.Chem.rdchem.Mol로 변환합니다. 비용이 큰 오퍼레이션이므로 복잡한 분자의 경우 시간이 오래 걸릴 수 있습니다.
</ResponseField>

<div id="method-moleculefrom_smiles">
  ### <Badge color="blue" size="lg" shape="rounded">방법</Badge> Molecule.from_smiles()
</div>

```python
data: 'str',
caption: 'str | None' = None,
sanitize: 'bool' = True,
convert_to_3d_and_optimize: 'bool' = True,
mmff_optimize_molecule_max_iterations: 'int' = 200
```

SMILES 문자열을 wandb.Molecule로 변환합니다.

<div id="arguments-2">
  ##### 인수
</div>

<ResponseField name="data" type="str">
  SMILES 문자열입니다.
</ResponseField>

<ResponseField name="caption" type="str | None">
  분자를 표시할 때 함께 사용할 캡션입니다.
</ResponseField>

<ResponseField name="sanitize" type="bool">
  RDKit의 정의에 따라 분자가 화학적으로 타당한지 확인합니다.
</ResponseField>

<ResponseField name="convert_to_3d_and_optimize" type="bool">
  3D 좌표가 포함된 `rdkit.Chem.rdchem.Mol`로 변환합니다. 이는 계산 비용이 큰 오퍼레이션이므로 복잡한 분자의 경우 시간이 오래 걸릴 수 있습니다.
</ResponseField>
