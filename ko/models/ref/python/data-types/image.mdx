<div id="class-wandbimage">
  ## <Badge color="yellow" size="lg" shape="rounded">클래스</Badge> wandb.Image
</div>

W&amp;B에 이미지를 로깅하는 클래스입니다.

```python
data_or_path: 'ImageDataOrPathType',
mode: 'str | None' = None,
caption: 'str | None' = None,
grouping: 'int | None' = None,
classes: 'Classes | Sequence[dict] | None' = None,
boxes: 'dict[str, BoundingBoxes2D] | dict[str, dict] | None' = None,
masks: 'dict[str, ImageMask] | dict[str, dict] | None' = None,
file_type: 'str | None' = None
```

<div id="args">
  ## 인수
</div>

<ResponseField name="data_or_path" type="ImageDataOrPathType">
  이미지 데이터의 NumPy 배열/pytorch 텐서,
  PIL 이미지 객체 또는 이미지 파일 경로를 받습니다. NumPy
  배열 또는 pytorch 텐서가 제공되면
  이미지 데이터는 지정한 파일 유형으로 저장됩니다.
  값은 이미 &#91;0, 255&#93; 범위에 있어야 합니다.

  * pytorch 텐서는 (channel, height, width) 형식이어야 합니다
  * NumPy 배열은 (height, width, channel) 형식이어야 합니다
</ResponseField>

<ResponseField name="mode" type="str | None">
  이미지의 PIL 모드입니다. 가장 일반적인 값은 &quot;L&quot;, &quot;RGB&quot;, &quot;RGBA&quot;입니다. 자세한 내용은 전체 Pillow 문서를 참조하세요 [https://pillow.readthedocs.io/en/stable/handbook/concepts.html#modes](https://pillow.readthedocs.io/en/stable/handbook/concepts.html#modes)
</ResponseField>

<ResponseField name="caption" type="str | None">
  이미지 표시에 사용할 레이블입니다.
</ResponseField>

<ResponseField name="grouping" type="int | None">
  이미지의 그룹 번호입니다.
</ResponseField>

<ResponseField name="classes" type="Classes | Sequence[dict] | None">
  이미지의 클래스 정보 목록으로, 바운딩 박스와 이미지 마스크의 레이블 지정에 사용됩니다.
</ResponseField>

<ResponseField name="boxes" type="dict[str, BoundingBoxes2D] | dict[str, dict] | None">
  이미지의 바운딩 박스 정보가 들어 있는 딕셔너리입니다. 참조 [https://docs.wandb.ai/models/ref/python/data-types/boundingboxes2d](https://docs.wandb.ai/models/ref/python/data-types/boundingboxes2d)
</ResponseField>

<ResponseField name="masks" type="dict[str, ImageMask] | dict[str, dict] | None">
  이미지의 마스크 정보가 들어 있는 딕셔너리입니다. 참조 [https://docs.wandb.ai/models/ref/python/data-types/imagemask](https://docs.wandb.ai/models/ref/python/data-types/imagemask)
</ResponseField>

<ResponseField name="file_type" type="str | None">
  이미지를 저장할 파일 유형입니다. `data_or_path`가 이미지 파일 경로인 경우 이 매개변수는 적용되지 않습니다.
</ResponseField>
