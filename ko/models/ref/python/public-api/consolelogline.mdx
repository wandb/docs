number: 'int',

<div id="attributes">
  ## 속성
</div>

* `number`: 0부터 시작하는 run 콘솔 로그의 줄 위치입니다.
* `timestamp`: 줄이 캡처된 시간이며, 시간대 정보가 포함된 UTC datetime입니다. backend가 해당 줄의 시간을 기록하지 않았거나 예상치 못한 형식으로 전송한 경우 None입니다.
* `level`: 줄의 심각도입니다. stderr에 기록된 줄은 `"error"`이며, 그 외에는 비어 있습니다.
* `label`: 여러 process가 동일한 run에 기록하는 경우 해당 줄을 기록한 process를 식별하는 레이블입니다. 공유 모드에서 `x_label` 설정으로 지정됩니다. 단일 작성자 run에서는 비어 있습니다.
* `content`: 줄의 텍스트입니다.
