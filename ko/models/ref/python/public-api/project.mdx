## <Badge color="yellow" size="lg" shape="rounded">클래스</Badge> wandb.apis.public.Project

프로젝트는 Runs의 네임스페이스입니다.

```python
service_api: 'ServiceApi',
entity: 'str',
project: 'str',
attrs: 'Mapping[str, Any]'
```

<div id="args">
  ## 인수
</div>

<ResponseField name="service_api" type="ServiceApi">
  W&amp;B를 쿼리하는 데 사용하는 Service API입니다.
</ResponseField>

<ResponseField name="entity" type="str">
  프로젝트를 소유한 entity입니다.
</ResponseField>

<ResponseField name="project" type="str">
  쿼리할 프로젝트의 이름입니다.
</ResponseField>

<ResponseField name="attrs" type="Mapping[str, Any]">
  프로젝트의 속성입니다.
</ResponseField>

<div id="properties">
  ## 속성
</div>

<ResponseField name="id" type="str">
  설명이 제공되지 않았습니다.
</ResponseField>

<ResponseField name="owner" type="public.User">
  프로젝트 소유자를 User 객체로 반환합니다.
</ResponseField>

<ResponseField name="path" type="list[str]">
  프로젝트의 경로를 반환합니다. 경로는 entity와 프로젝트 이름을 포함하는 목록입니다.
</ResponseField>

<ResponseField name="url" type="str">
  프로젝트의 URL을 반환합니다.
</ResponseField>

### <Badge color="blue" size="lg" shape="rounded">방법</Badge> Project.collections()

```python
self,
filters: 'Mapping[str, Any] | None' = None,
order: 'str | None' = None,
per_page: 'int' = 50
```

이 프로젝트와 연결된 모든 artifact collection을 반환합니다.

<div id="arguments">
  ##### 인수
</div>

<ResponseField name="filters" type="Mapping[str, Any] | None">
  쿼리에 적용할 필터의 선택적 매핑입니다.
</ResponseField>

<ResponseField name="order" type="str | None">
  결과 순서를 지정하는 선택적 문자열입니다. `order` 앞에 `+`를 붙이면 오름차순(기본값)이고, `-`를 붙이면 내림차순입니다.
</ResponseField>

<ResponseField name="per_page" type="int">
  페이지당 가져올 artifact collection의 수입니다. 기본값은 50입니다.
</ResponseField>

</ResponseField>
