## <Badge color="yellow" size="lg" shape="rounded">클래스</Badge> wandb.apis.public.ArtifactType {#class-wandbapispublicartifacttype}

지정된 유형에 따라 쿼리 조건을 만족하는 artifact 객체입니다.

## 속성 {#properties}

<ResponseField name="id" type="str">
  artifact 유형의 고유 식별자입니다.
</ResponseField>

<ResponseField name="name" type="str">
  artifact 유형의 이름입니다.
</ResponseField>

## 메서드 {#methods}

### <Badge color="blue" size="lg" shape="rounded">방법</Badge> ArtifactType.collection() {#method-artifacttypecollection}

```python
self,
name: 'str'
```

이름으로 특정 artifact collection을 조회합니다.

##### 인수 {#arguments}

<ResponseField name="name" type="str">
  조회할 artifact collection의 이름입니다.
</ResponseField>

### <Badge color="blue" size="lg" shape="rounded">방법</Badge> ArtifactType.collections() {#method-artifacttypecollections}

```python
self,
filters: 'Mapping[str, Any] | None' = None,
order: 'str | None' = None,
per_page: 'int' = 50,
start: 'str | None' = None
```

이 artifact 유형에 연결된 모든 artifact collection을 조회합니다.

##### 인수 {#arguments-2}

<ResponseField name="filters" type="Mapping[str, Any] | None">
  쿼리에 적용할 필터의 선택 사항인 매핑입니다.
</ResponseField>

<ResponseField name="order" type="str | None">
  결과 순서를 지정하는 선택 사항인 문자열입니다. `order` 앞에 `+`를 붙이면 오름차순(기본값)입니다. `order` 앞에 `-`를 붙이면 내림차순입니다. 기본 순서는 collection ID의 내림차순입니다.
</ResponseField>

<ResponseField name="per_page" type="int">
  페이지당 가져올 artifact collection 수입니다. 기본값은 50입니다.
</ResponseField>

<ResponseField name="start" type="str | None">
  이전 paginator의 `.cursor` 속성에서 캡처한, 이전 쿼리를 이어서 실행하기 위한 페이지네이션 커서입니다.
</ResponseField>
