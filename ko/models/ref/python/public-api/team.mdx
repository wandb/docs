<div id="class-wandbapispublicteam">
  ## <Badge color="yellow" size="lg" shape="rounded">클래스</Badge> wandb.apis.public.Team
</div>

W&amp;B 팀을 나타내는 클래스입니다.

이 클래스는 팀 생성, 구성원 초대, 서비스 계정 관리 등을 포함해 W&amp;B 팀을 관리하기 위한 메서드를 제공합니다. 팀 속성 관리를 위해 Attrs를 상속합니다.

```python
(service_api: 'ServiceApi',
name: 'str',
attrs: 'Mapping[str, Any] | None' = None)
```

<div id="args">
  ## 인수
</div>

<ResponseField name="service_api" type="ServiceApi">
  W&amp;B를 쿼리하는 데 사용할 Service API 인스턴스입니다.
</ResponseField>

<ResponseField name="name" type="str">
  팀 이름
</ResponseField>

<ResponseField name="attrs" type="Mapping[str, Any] | None">
  선택적 팀 속성 딕셔너리
</ResponseField>

<div id="examples">
  ## 예시
</div>

팀을 찾아보고 구성원을 초대하세요.

```python
import wandb

api = wandb.Api()
team = api.team("my-team")
team.invite("user@example.com")
```

팀을 만들고 서비스 계정을 추가하세요.

```python
import wandb

api = wandb.Api()
team = api.create_team("my-team")
team.create_service_account("CI service account")
```
