## <kbd>클래스</kbd> wandb.apis.public.ConsoleLogs

```python
(service_api: 'ServiceApi',
run: 'Run',
per_page: 'int' = 1000,
last: 'int | None' = None)
```

run의 콘솔 로그 줄을 오래된 것부터 순서대로 제공하는 지연 iterator입니다.

W&amp;B backend에서 페이지별로 가져옵니다. 가져온 줄은
메모리에 유지되므로, 두 번째로 반복하면 다시 가져오는 대신 동일한 줄이 반환됩니다.
추가되었을 수 있는 로그를 다시 조회하려면 새 인스턴스를 만드세요.

<div id="args">
  ## 인수
</div>

* `service_api`: W&amp;B를 쿼리하는 데 사용하는 Service API 인스턴스입니다.
* `run`: 콘솔 로그를 조회할 run입니다.
* `per_page`: 처음부터 로그를 조회할 때 요청당 가져올 줄 수입니다. `last`가 지정되면 무시됩니다.
* `last`: 설정하면 처음부터 조회하는 대신 단일 요청으로 로그의 마지막 N줄만 가져옵니다. backend에서는 한 요청으로 반환할 수 있는 줄 수를 제한하므로, 더 많은 줄을 요청하면 최신 줄만 반환됩니다.
