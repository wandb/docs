## <Badge color="yellow" size="lg" shape="rounded">클래스</Badge> wandb.apis.public.Sweeps

`Sweep` 객체 컬렉션을 지연 방식으로 순회하는 이터레이터입니다.

```python
service_api: 'ServiceApi',
entity: 'str',
project: 'str',
per_page: 'int' = 50,
filters: 'dict[str, Any] | None' = None
```

<div id="args">
  ## 인수
</div>

<ResponseField name="service_api" type="ServiceApi">
  W&amp;B를 쿼리하는 데 사용하는 Service API입니다.
</ResponseField>

<ResponseField name="entity" type="str">
  스윕을 소유한 entity입니다.
</ResponseField>

<ResponseField name="project" type="str">
  스윕이 포함된 프로젝트입니다.
</ResponseField>

<ResponseField name="per_page" type="int">
  API 요청당 가져올 스윕 수입니다.
</ResponseField>

<ResponseField name="filters" type="dict[str, Any] | None">
  (dict) run 필터를 사용하여 특정 스윕을 쿼리합니다. 자세한 내용은 wandb/apis/public/api.py:runs를 참조하세요.
</ResponseField>

<div id="examples">
  ## 예시
</div>

```python
from wandb.apis.public import Api

sweeps = Api().project(name="project_name", entity="entity").sweeps()

# 스윕을 순회하며 세부 정보 출력
for sweep in sweeps:
    print(f"Sweep name: {sweep.name}")
    print(f"Sweep ID: {sweep.id}")
    print(f"Sweep URL: {sweep.url}")
    print("----------")
```
