<ResponseField name="aliases" type="list[str]">

<ResponseField name="description" type="str | None">

</ResponseField>

<ResponseField name="entity" type="str">
  프로젝트를 소유한 엔터티(사용자 또는 팀)입니다.
</ResponseField>

<ResponseField name="id" type="str">
  아티팩트 컬렉션의 고유 식별자입니다.
</ResponseField>

<ResponseField name="name" type="str">
  아티팩트 컬렉션의 이름입니다.
</ResponseField>

<ResponseField name="project" type="str">
  아티팩트 컬렉션이 포함된 프로젝트입니다.
</ResponseField>

<ResponseField name="project_id" type="str">
  이 컬렉션이 속한 프로젝트의 인코딩된 GraphQL ID입니다.
</ResponseField>

<ResponseField name="project_internal_id" type="str | None">
  가져온 경우 이 컬렉션의 기반 프로젝트에 대한 GraphQL `internalId`입니다.

  이는 base64로 인코딩된 전역 ID입니다. 디코딩하면 `Project:123` 또는 `ProjectInternalId:123`과 같은 형식입니다.
</ResponseField>

<ResponseField name="tags" type="list[str]">
  아티팩트 컬렉션과 연결된 태그입니다.
</ResponseField>

<ResponseField name="type" type="">
  아티팩트 컬렉션의 유형을 반환합니다.
</ResponseField>

<ResponseField name="updated_at" type="str | None">
  아티팩트 컬렉션이 마지막으로 업데이트된 날짜입니다.
</ResponseField>
