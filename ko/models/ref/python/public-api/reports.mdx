## <Badge color="yellow" size="lg" shape="rounded">클래스</Badge> wandb.apis.public.Reports

Reports는 `BetaReport` 객체에 대한 지연 이터레이터입니다.

```python
(service_api: 'ServiceApi',
project: 'Project',
name: 'str | None' = None,
entity: 'str | None' = None,
per_page: 'int' = 50)
```

<div id="args">
  ## 인수
</div>

<ResponseField name="service_api" type="ServiceApi">
  이 컬렉션에 대한 W&amp;B API 호출을 수행하는 wandb-core 서비스의 인터페이스입니다.
</ResponseField>

<ResponseField name="project" type="Project">
  Reports를 가져올 프로젝트입니다.
</ResponseField>

<ResponseField name="name" type="str | None">
  필터링할 report 이름입니다. `None`이면 모든 Reports를 가져옵니다.
</ResponseField>

<ResponseField name="entity" type="str | None">
  프로젝트의 entity 이름입니다. 기본값은 프로젝트 entity입니다.
</ResponseField>

<ResponseField name="per_page" type="int">
  페이지당 가져올 Reports 수입니다(기본값: 50).
</ResponseField>
