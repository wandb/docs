<div id="examples">
  ## 예시
</div>

메트릭 &quot;my-metric&quot;의 최근 5개 값 평균이 123.45를 초과할 때
프로젝트 &quot;my-project&quot;의 모든 run에 대해 트리거되는 이벤트를 정의합니다:

```python
from wandb import Api
from wandb.automations import OnRunMetric, RunEvent

api = Api()
project = api.project(name="my-project")

event = OnRunMetric(
    scope=project,
    filter=RunEvent.metric("my-metric").avg(5).gt(123.45),
)
```
