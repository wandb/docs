## <Badge color="blue" size="lg" shape="rounded">함수</Badge> wandb.plot.line_series()

선 시리즈 차트를 생성합니다.

```python
xs: 'Iterable[Iterable[Any]] | Iterable[Any]',
ys: 'Iterable[Iterable[Any]]',
keys: 'Iterable[str] | None' = None,
title: 'str' = '',
xname: 'str' = 'x',
split_table: 'bool' = False
```

<div id="args">
  ## 인수
</div>

<ResponseField name="xs" type="Iterable[Iterable[Any]] | Iterable[Any]">
  x 값 시퀀스입니다. 단일 배열을 제공하면 모든 y 값이 해당 x 배열을 기준으로 플롯됩니다. 배열의 배열을 제공하면 각 y 값이 대응하는 x 배열을 기준으로 플롯됩니다.
</ResponseField>

<ResponseField name="ys" type="Iterable[Iterable[Any]]">
  y 값 시퀀스입니다. 각 iterable은 별도의 선 시리즈를 나타냅니다.
</ResponseField>

<ResponseField name="keys" type="Iterable[str] | None">
  각 선 시리즈의 레이블로 사용할 키 시퀀스입니다. 제공하지 않으면 &quot;line&#95;1&quot;, &quot;line&#95;2&quot; 등의 키가 자동으로 생성됩니다.
</ResponseField>

<ResponseField name="title" type="str">
  차트 제목입니다.
</ResponseField>

<ResponseField name="xname" type="str">
  X축 레이블입니다.
</ResponseField>

<ResponseField name="split_table" type="bool">
  테이블을 W&amp;B UI의 별도 섹션으로 분리할지 여부입니다. `True`이면 테이블이 &quot;Custom Chart Tables&quot;라는 섹션에 표시됩니다. 기본값은 `False`입니다.
</ResponseField>

<div id="returns">
  ## 반환값
</div>

`CustomChart`: W&amp;B에 로깅할 수 있는 커스텀 차트 객체입니다. 차트를 로깅하려면 `wandb.log()`에 전달하면 됩니다.

<div id="examples">
  ## 예시
</div>

모든 y 계열이 동일한 x 값을 기준으로 플로팅되는 단일 x 배열을 로깅하는 예시:

```python
import wandb

# W&B run 초기화
with wandb.init(project="line_series_example") as run:
    # 모든 y 시리즈에서 공유되는 x 값
    xs = list(range(10))

    # 플롯할 여러 y 시리즈
    ys = [
        [i for i in range(10)],  # y = x
        [i**2 for i in range(10)],  # y = x^2
        [i**3 for i in range(10)],  # y = x^3
    ]

    # 선 시리즈 차트 생성 및 로깅
    line_series_chart = wandb.plot.line_series(
        xs,
        ys,
        title="title",
        xname="step",
    )
    run.log({"line-series-single-x": line_series_chart})
```

이 예제에서는 모든 `ys` 시리즈에 하나의 `xs` 시리즈(공유 x값)를
사용합니다. 그 결과 각 y 시리즈는 동일한
x값(0-9)을 기준으로 플로팅됩니다.

각 y 시리즈가 해당 x 배열을 기준으로 플로팅되도록 여러 x 배열을 로깅하는 방법:

```python
import wandb

# W&B run 초기화
with wandb.init(project="line_series_example") as run:
    # 각 y 시리즈별 개별 x 값
    xs = [
        [i for i in range(10)],  # 첫 번째 시리즈의 x
        [2 * i for i in range(10)],  # 두 번째 시리즈의 x (확장됨)
        [3 * i for i in range(10)],  # 세 번째 시리즈의 x (더 확장됨)
    ]

    # 대응하는 y 시리즈
    ys = [
        [i for i in range(10)],  # y = x
        [i**2 for i in range(10)],  # y = x^2
        [i**3 for i in range(10)],  # y = x^3
    ]

    # 선 시리즈 차트 생성 및 로깅
    line_series_chart = wandb.plot.line_series(
        xs, ys, title="Multiple X Arrays Example", xname="Step"
    )
    run.log({"line-series-multiple-x": line_series_chart})
```

이 예제에서는 각 y 시리즈를 서로 고유한 x 시리즈에 대해 플로팅합니다.
이 방식은 데이터 시리즈마다 x 값이 일정하지 않을 때 더 유연하게
표현할 수 있게 해줍니다.

`keys`를 사용해 선 레이블 맞춤 설정:

```python
import wandb

# W&B run 초기화
with wandb.init(project="line_series_example") as run:
    xs = list(range(10))  # 단일 x 배열
    ys = [
        [i for i in range(10)],  # y = x
        [i**2 for i in range(10)],  # y = x^2
        [i**3 for i in range(10)],  # y = x^3
    ]

    # 각 선에 대한 맞춤형 레이블
    keys = ["Linear", "Quadratic", "Cubic"]

    # 선 시리즈 차트 생성 및 로깅
    line_series_chart = wandb.plot.line_series(
        xs,
        ys,
        keys=keys,  # 맞춤형 키 (선 레이블)
        title="Custom Line Labels Example",
        xname="Step",
    )
    run.log({"line-series-custom-keys": line_series_chart})
```

이 예제는 `keys` 인수를 사용해 선에 대한 맞춤형 레이블을
지정하는 방법을 보여줍니다. 키는 범례에 &quot;Linear&quot;,
&quot;Quadratic&quot;, &quot;Cubic&quot;으로 표시됩니다.
