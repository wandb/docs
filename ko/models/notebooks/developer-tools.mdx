<div id="open-the-developer-panel">
  ## 개발자 패널 열기
</div>

다음 방법 중 하나를 사용하세요.

* 노트북 하단 푸터에서 **Developer panel**을 선택하세요.
* macOS에서는 **Command+J**, Windows 또는 Linux에서는 **Ctrl+J**를 누르세요. 이 단축키로 패널을 열거나 닫을 수 있습니다.

<div id="inspect-errors-and-warnings">
  ## 오류 및 경고 확인
</div>

**Errors** 탭에는 Python 예외, 구문 오류, 순환 참조, 유효하지 않은 반응형 의존성, 여러 셀에 정의된 변수 등 노트북 전반의 오류와 경고가 표시됩니다.

<div id="use-the-scratchpad">
  ## 스크래치패드 사용하기
</div>

**Scratchpad** 탭을 사용하면 노트북의 반응형 그래프에 코드를 추가하지 않고도 임시 Python 코드를 실행할 수 있습니다. 스크래치패드에서는 노트북 셀에 정의된 변수에 액세스할 수 있습니다.

노트북 셀과 달리 스크래치패드는 전역 변수 이름의 고유성을 강제 적용하지 않습니다. 스크래치패드에 정의한 코드와 변수는 저장되지 않으므로, 계속 보관하려는 코드는 노트북 셀에 복사하세요.

스크래치패드 코드를 실행하려면 macOS에서는 **Command+Enter**, Windows 또는 Linux에서는 **Control+Enter**를 누르세요. 또는 **Run**(<Icon icon="circle-play" iconType="solid" />)을 선택하세요.

스크래치패드 출력은 코드 오른쪽에 표시됩니다.

<div id="inspect-execution-traces">
  ## 실행 트레이스 확인
</div>

**Tracing** 탭에서 셀 실행 순서와 소요 시간을 확인하세요. 트레이스를 활용하면 느리거나 실패한 셀을 파악하고, 반응형 실행 이벤트에서 어떤 셀이 실행되었는지 확인할 수 있습니다.

각 **Run** 제목은 동일한 실행 이벤트에서 실행된 셀들을 하나로 묶어 보여줍니다. 가로 막대는 각 셀이 실행된 시점을 나타내며, 해당 이벤트 내 다른 셀과 소요 시간을 비교할 수 있게 해줍니다. 각 항목에는 셀 링크, 코드 미리보기, 소요 시간, 상태 아이콘이 포함됩니다. 상태 아이콘은 실행이 성공했는지, 실패했는지, 중단되었는지를 나타냅니다.

소요 시간은 반올림되므로 짧은 실행은 `0 ms`로 표시될 수 있습니다. 트레이스 항목에 마우스를 올리면 정확한 시작 및 종료 시간을 확인할 수 있습니다. 셀 링크를 선택하면 해당 노트북 셀이 열립니다.

**Clear**를 선택하면 표시된 트레이스 이력이 삭제됩니다. 이력을 지워도 노트북 셀이나 변수는 삭제되지 않습니다.

**Inline chart**를 활성화하면 해당 노트북 셀 근처에 실행 시간이 표시됩니다.

다음 이미지는 developer panel에서 **Tracing** 탭을 연 &quot;Hello World&quot; 노트북의 모습입니다. `cell-4`는 변수 pet을 정의하고, `cell-5`는 이를 사용해 &quot;Do you have a cat?&quot;이라는 출력을 생성합니다. 두 셀 모두 정상적으로 완료되었습니다. 트레이스에는 `cell-4`의 소요 시간이 14 ms, `cell-5`가 `0 ms`로 표시됩니다. 툴팁에는 `cell-5`의 정확한 시작 및 종료 시간이 표시됩니다.

<div id="view-logs">
  ## 로그 보기
</div>

**Logs** 탭에서 노트북 셀과 스크래치패드의 표준 출력(`stdout`)과 표준 오류(`stderr`)를 확인할 수 있습니다. 명확한 인라인 오류가 표시되지 않는 실행 실패를 조사할 때 로그를 활용하세요.

다음 이미지는 해당 노트북 셀이 `[5:42:51 PM]`에 로깅한 출력 `"Do you have a cat?"`을 보여줍니다.

<Frame>
  <img src="/images/notebooks/hello_world_logs.png" alt="노트북의 표준 출력과 오류 출력을 보여주는 Logs 탭" />
</Frame>

<Note>
  **Logs** 탭에는 [**Scratchpad**](/ko/models/notebooks/developer-tools#use-the-scratchpad)의 출력과 오류도 함께 표시됩니다. 이미지에서 `[5:44:00 PM]` 항목은 `cell--1`로 표시되어 있으며, 스크래치패드에서 발생한 것입니다.
</Note>

<div id="use-the-terminal">
  ## 터미널 사용
</div>

**Terminal** 탭을 사용하면 노트북 런타임과 동일한 샌드박스 환경에서 셸을 열 수 있습니다. 터미널에서 파일을 확인하고, 커맨드라인 도구를 실행하고, 패키지를 관리하고, 스크립트를 실행할 수 있습니다. 터미널에서 수행한 변경 사항은 노트북과 동일한 워크스페이스에 적용됩니다.
