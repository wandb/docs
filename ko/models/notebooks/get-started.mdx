다음 가이드에서는 첫 노트북 만들기부터 트레이닝 실험 실행까지, W&amp;B 노트북을 시작하는 방법을 안내합니다.

<div id="create-your-first-notebook">
  ## 첫 번째 노트북 만들기
</div>

1. 프로젝트의 workspace로 이동합니다.
2. 프로젝트 사이드바에서 **Notebooks**를 선택합니다.
3. **Create notebook**을 클릭합니다.

자세한 내용은 [노트북 만들기 및 관리](/ko/models/notebooks/create-notebook)를 참조하세요.

<div id="run-a-training-experiment">
  ## 트레이닝 실험 실행하기
</div>

이 예제 트레이닝 스크립트는 시뮬레이션된 정확도와 loss 메트릭을 W&amp;B에 로깅합니다. 다음 코드를 Python 스크립트나 노트북 셀에 복사하여 붙여넣은 후 실행하세요:

1. **Python**을 선택하여 새 코드 셀을 만듭니다.

2. 다음 코드를 셀에 복사하여 붙여넣습니다:

   ```python
   import random
   import wandb

   PROJECT = "your-project-name"

   # 하이퍼파라미터가 담긴 딕셔너리
   config = {
       'epochs' : 10,
       'lr' : 0.01
   }

   with wandb.init(project=PROJECT, config=config) as run:
       offset = random.random() / 5
       print(f"lr: {config['lr']}")
       
       # 트레이닝 run 시뮬레이션
       for epoch in range(2, config['epochs']):
           acc = 1 - 2**-config['epochs'] - random.random() / config['epochs'] - offset
           loss = 2**-config['epochs'] + random.random() / config['epochs'] + offset
           print(f"epoch={config['epochs']}, accuracy={acc}, loss={loss}")
           run.log({"accuracy": acc, "loss": loss})
   ```

3. macOS에서는 **Command + Enter**, Windows 또는 Linux에서는 **Ctrl+Enter**를 누르세요. 또는 셀 옆의 **재생**(<Icon icon="circle-play" iconType="solid" />) 버튼을 클릭하세요.

<div id="view-your-experiment">
  ## 실험 보기
</div>

트레이닝 실험 중에 로깅된 정확도와 loss 메트릭을 확인하세요:

1. 프로젝트 사이드바에서 **Workspace**를 선택하세요.
2. Workspace에서 run과 시각화를 살펴보세요. [runs](/ko/models/runs) 목록에는 프로젝트에 로깅된 각 run과 세부 정보가 표시됩니다. [Workspace 패널](/ko/models/app/features/panels)에는 각 run에서 로깅된 메트릭의 시각화가 표시됩니다.

<div id="save-the-notebook">
  ## 노트북 저장
</div>

W&amp;B는 노트북을 [W&amp;B Artifact](/ko/models/artifacts)로 저장하며, 30초마다 그리고 노트북의 컴퓨팅 세션이 중지될 때 변경 사항을 새 [아티팩트 버전](/ko/models/artifacts/create-a-new-artifact-version)으로 자동 저장합니다.

최신 변경 사항을 즉시 저장하려면 다음 방법 중 하나를 사용하세요.

* macOS에서는 **Command+S**, Windows 또는 Linux에서는 **Ctrl+S**를 누릅니다.
* 노트북 하단에서 **Save**(<Icon icon="floppy-disk" iconType="solid" />)를 클릭합니다.
