{/* ## 기존 노트북 가져오기 */}

팀의 개요 페이지나 프로젝트 워크스페이스에서 노트북을 생성하고, 이름을 변경하고, 복제하거나 삭제할 수 있습니다.

## 새 노트북 만들기 {#create-a-new-notebook}

기존 프로젝트 또는 팀 워크스페이스에서 노트북을 만들 수 있습니다.

<Tabs>
  <Tab title="팀 개요">
    1. 팀 개요 페이지로 이동하세요.
    2. **Notebooks** 탭을 선택하세요.
    3. **Create notebook**을 선택하세요.
    4. **Project** 드롭다운에서 노트북을 만들 프로젝트를 선택하세요. 새 프로젝트를 사용하려면 **Create a new project**를 선택하세요.
  </Tab>

  <Tab title="프로젝트">
    1. 프로젝트 워크스페이스로 이동하세요.
    2. 프로젝트 사이드바에서 **Notebooks**를 선택하세요.
    3. **Create notebook**을 선택하세요.
  </Tab>
</Tabs>

## 노트북 이름 변경 {#rename-a-notebook}

팀 개요 페이지 또는 프로젝트 워크스페이스에서 기존 노트북의 이름을 변경할 수 있습니다.

<Tabs>
  <Tab title="팀 개요">
    1. 팀 개요 페이지로 이동하세요.
    2. **Notebooks** 탭을 선택하세요.
    3. **액션 (<Icon icon="ellipsis" iconType="solid" />)** 메뉴를 열고 **Rename notebook**을 선택하세요.
    4. 노트북의 새 이름을 입력하고 **Save**를 선택하세요.
  </Tab>

  <Tab title="프로젝트">
    1. 프로젝트 워크스페이스로 이동하세요.
    2. 프로젝트 사이드바에서 **Notebooks**를 선택하세요.
    3. **액션 (<Icon icon="ellipsis" iconType="solid" />)** 메뉴를 열고 **Rename notebook**을 선택하세요.
    4. 노트북의 새 이름을 입력하고 **Save**를 선택하세요.
  </Tab>
</Tabs>

## 노트북 복제하기 {#duplicate-a-notebook}

노트북을 복제하면 같은 프로젝트나 다른 프로젝트에 사본을 만들 수 있습니다. 복제된 노트북의 이름은 원본 노트북 이름 앞에 `Copy`가 붙은 형태로 W&amp;B가 자동으로 지정합니다.

<Tabs>
  <Tab title="팀 개요">
    1. 팀 개요 페이지로 이동하세요.
    2. **Notebooks** 탭을 선택하세요.
    3. **액션(<Icon icon="ellipsis" iconType="solid" />)** 메뉴를 열고 **Make a copy**를 선택하세요.
  </Tab>

  <Tab title="프로젝트">
    1. 프로젝트 워크스페이스로 이동하세요.
    2. 프로젝트 사이드바에서 **Notebooks**를 선택하세요.
    3. **액션(<Icon icon="ellipsis" iconType="solid" />)** 메뉴를 열고 **Make a copy**를 선택하세요.
  </Tab>
</Tabs>

## 노트북 삭제 {#delete-a-notebook}

팀의 개요 페이지 또는 프로젝트 워크스페이스에서 노트북을 삭제할 수 있습니다.

<Tabs>
  <Tab title="팀 개요">
    1. 팀의 개요 페이지로 이동하세요.
    2. **Notebooks** 탭을 선택하세요.
    3. **액션(<Icon icon="ellipsis" iconType="solid" />)** 메뉴를 열고 **Delete notebook**을 선택하세요.
    4. **Delete notebook**을 선택하세요.
  </Tab>

  <Tab title="프로젝트">
    1. 프로젝트 워크스페이스로 이동하세요.
    2. 프로젝트 사이드바에서 **Notebooks**를 선택하세요.
    3. **액션(<Icon icon="ellipsis" iconType="solid" />)** 메뉴를 열고 **Delete notebook**을 선택하세요.
    4. **Delete notebook**을 선택하세요.
  </Tab>
</Tabs>
