Conversation은 단일 `gen_ai.conversation.id`로 여러 Turn을 묶습니다. Conversation 자체는
OTel span이 아니며, 하위 span이 자체 span에 conversation id를 기록합니다.

<div id="startturn">
  ### startTurn()
</div>

> **startTurn**(`opts?`): [`Turn`](./turn)

이 `Conversation`에서 새 `Turn`을 시작합니다. 이 turn은
conversation의 `conversationId`를 상속합니다. `agentName`, `agentId`, `agentDescription`,
`agentVersion`, `model`은 `opts`에 제공되지 않으면 conversation의 값을 사용합니다.

정의 위치: [src/genai/conversation.ts:156](https://github.com/wandb/weave/blob/8c5f077eb11c42b84000726ff20504abc728d3fb/sdks/node/src/genai/conversation.ts#L156)

<div id="parameters">
  #### 매개변수
</div>

<div id="opts">
  ##### opts?
</div>

[`TurnInit`](./turninit) = `{}`

#### 반환값

[`Turn`](./turn)

<div id="examples">
  #### 예시
</div>

```ts twoslash
// @noErrors
const turn = conversation.startTurn();
```

```ts twoslash
// @noErrors
const turn = conversation.startTurn({
  model: 'gpt-4o',
  agentName: 'research-bot',
  agentId: 'research-bot-prod',
  agentDescription: 'Looks up facts on Wikipedia.',
  agentVersion: '1.4.2',
  userMessage: 'What is the weather in Tokyo?',
  systemInstructions: ['You are a helpful weather bot.'],
  startTime: new Date('2026-05-29T10:00:00.000Z'),
});
```
