<div id="startturn">
  ### startTurn()
</div>

> **startTurn**(`opts?`): [`Turn`](./turn)

이 `Conversation`에서 새 `Turn`을 시작합니다. 이 turn은
conversation의 `conversationId`를 상속합니다. `agentName`, `agentId`, `agentDescription`,
`agentVersion`, `model`은 `opts`에 제공되지 않으면 conversation의 값을 사용합니다.

<div id="parameters-2">
  #### 매개변수
</div>

<ParamField path="opts" type="TurnInit = {}">
  [`TurnInit`](./turninit)을 참조하세요.
</ParamField>

<div id="returns-7">
  #### 반환값
</div>

[`Turn`](./turn)

<div id="examples">
  #### 예시
</div>

```ts twoslash
// @noErrors
const turn = conversation.startTurn();
```

```ts twoslash
// @noErrors
const turn = conversation.startTurn({
  model: 'gpt-4o',
  agentName: 'research-bot',
  agentId: 'research-bot-prod',
  agentDescription: 'Looks up facts on Wikipedia.',
  agentVersion: '1.4.2',
  userMessage: 'What is the weather in Tokyo?',
  systemInstructions: ['You are a helpful weather bot.'],
  startTime: new Date('2026-05-29T10:00:00.000Z'),
});
```
