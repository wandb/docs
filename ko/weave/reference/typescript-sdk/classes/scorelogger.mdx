ScoreLogger는 단일 예측의 점수 산정을 관리합니다.
EvaluationLogger.logPrediction()에서 반환되는 객체입니다.

정의된 위치: [src/evaluationLogger.ts:330](https://github.com/wandb/weave/blob/8c5f077eb11c42b84000726ff20504abc728d3fb/sdks/node/src/evaluationLogger.ts#L330)

<div id="example">
  ## 예시
</div>

```ts twoslash
// @noErrors
const pred = await ev.logPrediction(example, output);
await pred.logScore("accuracy", 0.95);
await pred.logScore("relevance", 0.8);
await pred.finish(); // 예측을 완료합니다
```

<div id="finish">
  ### finish()
</div>

> **finish**(): `Promise`&lt;`void`&gt;

예측의 점수 산정 과정을 완료합니다.
누적된 점수로 predict&#95;and&#95;score call을 완료합니다.
incremental 집계를 업데이트하고 메모리를 해제합니다.

정의된 위치: [src/evaluationLogger.ts:470](https://github.com/wandb/weave/blob/8c5f077eb11c42b84000726ff20504abc728d3fb/sdks/node/src/evaluationLogger.ts#L470)
