ScoreLogger는 단일 예측의 점수 산정을 관리합니다.
EvaluationLogger.logPrediction()에서 반환되는 객체입니다.

## 예시 {#example}

```ts twoslash
// @noErrors
const pred = await ev.logPrediction(example, output);
await pred.logScore("accuracy", 0.95);
await pred.logScore("relevance", 0.8);
await pred.finish(); // 예측을 완료합니다
```

### isFinishCalled {#isfinishcalled}

#### 시그니처 조회 {#get-signature}

> **get** **isFinishCalled**(): `boolean`

finish()가 호출되었는지 확인합니다.
EvaluationLogger에서 완료되지 않은 예측을 감지하는 데 사용됩니다.

`boolean`

## 메서드 {#methods}

### finish() {#finish}

> **finish**(): `Promise`&lt;`void`&gt;

예측의 점수 산정 과정을 완료합니다.
누적된 점수로 predict&#95;and&#95;score call을 완료합니다.
incremental 집계를 업데이트하고 메모리를 해제합니다.

#### 반환값 {#returns-3}

`Promise`&lt;`void`&gt;

***

### logScore() {#logscore}

> **logScore**(`scorerName`, `score`): `Promise`&lt;`void`&gt;

이 예측에 대한 점수를 기록합니다.
predict&#95;and&#95;score의 하위 Call로 Scorer Call을 생성합니다.

#### Parameters {#parameters-2}

<ParamField path="scorerName" type="string" required>
  scorer 이름(예: &quot;accuracy&quot;, &quot;f1&#95;score&quot;)
</ParamField>

<ParamField path="score" type="any" required>
  점수 값
</ParamField>

#### 반환값 {#returns-4}

`Promise`&lt;`void`&gt;
