```ts
init(project: string, settings?: Partial<{…}>): Promise<WeaveClient>
```

<GitHubLink url="https://github.com/wandb/weave/blob/7c9efdc9fe05ffcaf2430dd652ef9bc5b3ffdfaa/sdks/node/src/clientApi.ts#L86" />

Weave 클라이언트를 초기화합니다. 트레이싱이 동작하려면 반드시 필요합니다.

<div id="parameters">
  ## Parameters
</div>

<ParamField path="project" type="string" required>
  W&amp;B 프로젝트 이름입니다(`project` 또는 `entity/project` 형식일 수 있습니다). W&amp;B 팀(예: `team/project`)을
  지정하지 않으면 기본 entity가 사용됩니다.
  기본 entity를 확인하거나 업데이트하려면 User Settings[https://docs.wandb.ai/platform/app/settings-page/user-settings#default-team](https://docs.wandb.ai/platform/app/settings-page/user-settings#default-team)t-team 를 참고하세요
</ParamField>

<ParamField path="settings" type="Partial<{…}>">
  (선택) 트레이싱 설정

  Full type: `Partial<{ attributes: Record<string, any>; genai: { batchOptions?: BufferConfig; spanProcessor?: "batch" | "simple" | SpanProcessor; }; printCallLink: boolean; useCallsComplete: boolean; useOTelV2: boolean; }>`
</ParamField>

<div id="returns">
  ## 반환값
</div>

`Promise`&lt;[`WeaveClient`](../interfaces/weaveclient)&gt;

초기화된 Weave 클라이언트로 해석되는 Promise입니다.

<div id="throws">
  ## 예외 발생
</div>

초기화에 실패한 경우
