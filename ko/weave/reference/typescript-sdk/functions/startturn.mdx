```ts
startTurn(opts?: TurnInit = {}): Turn
```

<GitHubLink url="https://github.com/wandb/weave/blob/7c9efdc9fe05ffcaf2430dd652ef9bc5b3ffdfaa/sdks/node/src/genai/api.ts#L54" />

새 Turn을 시작합니다. 활성 상태인 Conversation이 있으면 Turn이 해당
`conversationId`를 상속받고, 그렇지 않으면 Turn에는 conversation ID가 없습니다.
