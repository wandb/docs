```ts
startTool(opts: ToolInit): Tool
```

<GitHubLink url="https://github.com/wandb/weave/blob/7c9efdc9fe05ffcaf2430dd652ef9bc5b3ffdfaa/sdks/node/src/genai/api.ts#L110" />

Tool span을 시작합니다. 상위 항목 결정 방식은 다음과 같습니다(설계의 &quot;기본적으로는 평면 구조, 중첩하면 계층 구조&quot;와 일치).

* LLM이 활성화되어 있으면 Tool은 그 하위에 중첩됩니다.
* 그렇지 않으면 Tool은 현재 Turn과 같은 수준의 항목이 됩니다.

Turn과 LLM이 모두 활성화되어 있지 않으면 예외를 발생시킵니다.
