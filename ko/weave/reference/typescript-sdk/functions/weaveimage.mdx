<ParamField path="options" type="object" required>
  이 미디어 유형에 대한 옵션입니다

  * data: Buffer 형식의 원시 이미지 데이터
  * imageType: (선택) 이미지 형식으로 &#39;png&#39;(기본값), &#39;jpeg&#39; 또는 &#39;webp&#39;입니다.
    게시 시 저장되는 파일 이름은 항상 image.png입니다
