---
title: "액세스를 교체하거나 철회하려면 어떻게 해야 하나요?"
keywords: ["관리자", "보안", "API 키"]
---

계정에 액세스할 수 있는 경우 개인 API 키를 직접 철회하거나 교체할 수 있습니다. 계정에 액세스할 수 없거나, 키 소유자가 조직을 떠났거나, 이 지침을 따르는 데 어려움이 있는 경우 [지원팀](mailto:support@wandb.com)에 문의하세요.
조직 관리자는 조직 전체의 API 키를 철회하거나 교체할 수 있으며, 팀 관리자는 팀의 API 키에 대해 이러한 작업을 수행할 수 있습니다.

일반적인 상황에서 API 키를 교체하려면 다음 단계를 따르세요.

1. 새 API 키를 만듭니다.
2. 새 키를 사용하도록 스크립트를 재구성합니다.
3. 이전 키를 삭제합니다.

<Warning>API 키가 유출되었거나 손상된 경우 기다리지 말고 이전 키를 즉시 삭제하세요.</Warning>

단계별 지침은 [API 키](/ko/platform/app/settings-page/user-settings#api-keys)를 참조하세요.
