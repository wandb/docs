<div id="workspace">
  ### Workspace
</div>

| キー                         | 動作                                                              |
| -------------------------- | --------------------------------------------------------------- |
| `h`, `?`                   | ヘルプの表示を切り替えます。                                                  |
| `q`, `ctrl+c`              | 終了します。                                                          |
| `alt+r`                    | LEET を再起動します。                                                   |
| `esc`                      | 適用中のフィルターまたは全画面メディアを解除し、Runs 一覧にフォーカスします (非表示の場合はフォーカスを解除します) 。 |
| `enter`                    | Runs 一覧にフォーカスがあるとき、ハイライトされた run を単一 run ビューで開きます。               |
| `1`                        | メトリクスグリッドの表示を切り替えます。                                            |
| `[`                        | Runs サイドバーの表示を切り替えます。                                           |
| `2`                        | システムメトリクスペインの表示を切り替えます。                                         |
| `]`                        | run 概要サイドバーの表示を切り替えます。                                          |
| `3`                        | メディアペインの表示を切り替えます。                                              |
| `4`                        | コンソールログペインの表示を切り替えます。                                           |
| `0`                        | このビューのペインと概要セクションのサイズをリセットします。                                  |
| `f`                        | 名前またはメタデータで runs をフィルターします。                                     |
| `ctrl+f`                   | runs のフィルターをクリアします。                                             |
| `space`                    | run を選択または選択解除します。                                              |
| `p`                        | run をピン留めまたはピン留め解除します。                                          |
| `/`                        | メトリクスをフィルターします。ログペインにフォーカスがある場合はコンソールログをフィルターします。               |
| `\`                        | システムメトリクスをフィルターします。                                             |
| `ctrl+/`, `ctrl+l`         | メトリクスのフィルターをクリアします。ログペインにフォーカスがある場合はコンソールのフィルターをクリアします。         |
| `ctrl+\`                   | システムメトリクスのフィルターをクリアします。                                         |
| `o`                        | run 概要の項目をフィルターします。                                             |
| `ctrl+o`                   | 概要のフィルターをクリアします。                                                |
| `y`                        | フォーカス中のチャートのモードを順に切り替えます。                                       |
| `g`                        | チャートのガイドを順に切り替えます: オフ、ドット、水平。                                   |
| `c`                        | フォーカス中のグリッドの列数を設定します。                                           |
| `r`                        | フォーカス中のグリッドの行数を設定します。                                           |
| `tab`, `shift+tab`         | 表示中のペイン間でフォーカスを順に移動します。                                         |
| `w`, `a`, `s`, `d` または矢印キー | フォーカス中のペイン内を移動します。メディアでは矢印キーでフレームをスクラブし、WASD でタイルを選択します。           |
| `N`, `pgup`                | 前のページ。                                                          |
| `n`, `pgdown`              | 次のページ。                                                          |
| `home`                     | 最初の項目、最初のページ、または最初のメディアフレームに移動します。                              |
| `end`                      | 最後の項目、最後のページ、または最新のメディアフレームに移動します。                              |

<div id="media">
  ### メディア
</div>

これらのショートカットは、Workspace または単一 run ビューでメディアペインがフォーカスされているときに有効です。

| キー                        | アクション                                                    |
| ------------------------- | -------------------------------------------------------- |
| `w`、`a`、`s`、`d`           | 画像タイルを選択します。                                             |
| 左矢印、右矢印                   | 1 フレーム分だけ前後にスクラブします。                                     |
| 上矢印、下矢印                   | 10 フレーム分だけ前後にスクラブします。                                    |
| `home`、`end`              | 最初または最新のフレームに移動します。                                      |
| `N`、`pgup` / `n`、`pgdown` | 画像時系列の前または次のページに移動します。                                   |
| `enter`                   | 選択した画像の全画面表示を切り替えます。                                     |
| `esc`                     | 全画面のメディア表示を終了します。                                        |
| `l`                       | 画像時系列間の連動スクラブを切り替えます。                                    |
| `k`                       | Kitty グラフィックスプロトコルをサポートするターミナルで、ANSI と高解像度レンダリングを切り替えます。 |

<div id="record-inspector">
  ### レコードインスペクター
</div>

`wandb leet inspect` を実行するか、ローカル run の単一 run ビューで `i` を押すとインスペクターが開きます。

| キー                          | アクション                                                          |
| --------------------------- | -------------------------------------------------------------- |
| `h`, `?`                    | ヘルプの表示を切り替えます。                                                 |
| `q`, `ctrl+c`               | LEET を終了します。                                                   |
| `esc`                       | フィルターの編集を終了し、レコードリストにフォーカスを移します。リストで押すと、`i` で開いた場合は run に戻ります。 |
| `tab`, `shift+tab`          | レコードリストと detail ペインの間でフォーカスを切り替えます。                            |
| `w`, `s`, 上矢印, 下矢印          | レコードを選択、または detail ペインをスクロールします。                               |
| `N`, `pgup` / `n`, `pgdown` | 前のページまたは次のページに移動します。                                           |
| `home`                      | 最初のレコード、または detail ペインの先頭に移動します。                               |
| `end`                       | 最後のレコード、または detail ペインの末尾に移動します。最後のレコードでは、ライブ更新に追従します。         |
| `/`                         | レコードをタイプまたはサマリーでフィルタリングします。                                    |
| `ctrl+/`                    | レコードのフィルターをクリアします。                                             |
| `0`                         | インスペクターのペインサイズをリセットします。                                        |

<div id="filter-editing">
  ### フィルターの編集
</div>

これらのショートカットは、フィルター入力がアクティブな状態で有効です。

| キー      | アクション                      |
| ------- | -------------------------- |
| `tab`   | 正規表現マッチングとグロブマッチングを切り替えます。 |
| `enter` | フィルターを適用して編集を終了します。        |
| `esc`   | 編集中のクエリを破棄して編集を終了します。      |

<div id="mouse">
  ### マウス
</div>

| 入力                      | 操作                                                            |
| ----------------------- | ------------------------------------------------------------- |
| クリック                    | チャートにフォーカスするか、メディアタイルを選択します。                                  |
| 境界線または区切り線を左クリックしてドラッグ  | ペイン、サイドバー、または run 概要 のセクションのサイズを変更します。                  |
| ホイール                    | フォーカスしたチャートをズームします。                                           |
| 右クリックしてドラッグ             | チャート上の最も近いポイントを確認します。                                         |
| `alt` を押しながら右クリックしてドラッグ | 同じグリッド内の表示中のチャートを同期して確認します。メトリクスのチャートは X-axis を共有している必要があります。 |
| `shift` を押しながらドラッグ      | ターミナルのテキストを選択します。                                             |
