## Install the CLI

The `wandb` CLI ships with the W&B Python SDK. Install it with `pip`:

```bash
pip install wandb
```

Verify the installation:

```bash
wandb --version
```

After installing, authenticate your machine with [`wandb login`](/models/ref/cli/wandb-login). For a full walkthrough, see the [W&B Quickstart](/models/quickstart).
