- **In the Automations hub**: Select **Automations** in the left navigation to see every automation you can access across all scopes: organization, team, project, registry, or collection. You choose the scope when you create an automation. See [Automations hub](/models/automations#automations-hub).
- **In a project**: Open the project, then select the **Automations** tab in the project sidebar.
- **In a registry**: Open the registry, then select the **Automations** tab.
