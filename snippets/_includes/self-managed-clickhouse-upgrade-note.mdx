<Note>
**Self-Managed deployments that use W&B Weave:** Verify your ClickHouse version before you upgrade W&B Server. Weave supports ClickHouse 25.8 through 25.12, and 26.3 or newer. Weave does not work with ClickHouse 26.1 or 26.2.

If you must change ClickHouse versions, upgrade **both** ClickHouse Server and ClickHouse Keeper. See [ClickHouse compatibility for upgrades](/platform/hosting/self-managed/operator#clickhouse-compatibility-for-upgrades).

Dedicated Cloud deployments already run a compatible ClickHouse version and are not affected.
</Note>
