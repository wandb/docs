<div id="workspace">
  ### Workspace
</div>

| 키                         | 액션                                                                |
| ------------------------- | ----------------------------------------------------------------- |
| `h`, `?`                  | 도움말 표시/숨기기.                                                       |
| `q`, `ctrl+c`             | 종료.                                                               |
| `alt+r`                   | LEET 재시작.                                                         |
| `esc`                     | 활성 필터 또는 전체 화면 미디어에서 빠져나온 다음 Runs 목록에 포커스합니다(숨겨져 있으면 포커스를 해제합니다). |
| `enter`                   | Runs 목록에 포커스가 있을 때 강조된 run을 단일 run 뷰로 엽니다.                        |
| `1`                       | 메트릭 그리드 표시/숨기기.                                                   |
| `[`                       | Runs 사이드바 표시/숨기기.                                                 |
| `2`                       | 시스템 메트릭 패널 표시/숨기기.                                                |
| `]`                       | run 개요 사이드바 표시/숨기기.                                               |
| `3`                       | 미디어 패널 표시/숨기기.                                                    |
| `4`                       | 콘솔 로그 패널 표시/숨기기.                                                  |
| `0`                       | 이 뷰의 패널 및 개요 섹션 크기를 재설정합니다.                                       |
| `f`                       | 이름 또는 메타데이터로 Runs를 필터링합니다.                                        |
| `ctrl+f`                  | Runs 필터를 지웁니다.                                                    |
| `space`                   | run 선택 또는 선택 해제.                                                  |
| `p`                       | run 고정 또는 고정 해제.                                                  |
| `/`                       | 메트릭을 필터링합니다. 로그 패널에 포커스가 있으면 콘솔 로그를 필터링합니다.                       |
| `\`                       | 시스템 메트릭을 필터링합니다.                                                  |
| `ctrl+/`, `ctrl+l`        | 메트릭 필터를 지웁니다. 로그 패널에 포커스가 있으면 콘솔 필터를 지웁니다.                        |
| `ctrl+\`                  | 시스템 메트릭 필터를 지웁니다.                                                 |
| `o`                       | run 개요 항목을 필터링합니다.                                                |
| `ctrl+o`                  | 개요 필터를 지웁니다.                                                      |
| `y`                       | 포커스된 차트 모드를 차례로 전환합니다.                                            |
| `g`                       | 차트 가이드를 차례로 전환합니다: 끄기, 점, 가로선.                                    |
| `c`                       | 포커스된 그리드의 열을 설정합니다.                                               |
| `r`                       | 포커스된 그리드의 행을 설정합니다.                                               |
| `tab`, `shift+tab`        | 표시된 패널 간에 포커스를 차례로 이동합니다.                                         |
| `w`, `a`, `s`, `d` 또는 방향키 | 포커스된 패널 안에서 이동합니다. 미디어에서는 방향키로 프레임을 탐색하고 WASD로 타일을 선택합니다.         |
| `N`, `pgup`               | 이전 페이지.                                                           |
| `n`, `pgdown`             | 다음 페이지.                                                           |
| `home`                    | 첫 항목, 첫 페이지 또는 첫 미디어 프레임으로 이동합니다.                                 |
| `end`                     | 마지막 항목, 마지막 페이지 또는 최신 미디어 프레임으로 이동합니다.                            |

<div id="symon">
  ### SYMON
</div>

| 키                           | 액션                             |
| --------------------------- | ------------------------------ |
| `h`, `?`                    | 도움말 표시/숨기기.                  |
| `q`, `ctrl+c`               | 종료합니다.                         |
| `alt+r`                     | 다시 시작합니다.                      |
| `y`                         | 포커스된 차트 모드를 차례로 전환합니다.         |
| `g`                         | 차트 가이드를 차례로 전환합니다: 끄기, 점, 가로선. |
| `\`                         | 시스템 메트릭을 필터링합니다.               |
| `ctrl+\`                    | 시스템 메트릭 필터를 지웁니다.              |
| `c`, `C`                    | 그리드 열을 설정합니다.                  |
| `r`, `R`                    | 그리드 행을 설정합니다.                  |

| `N`, `pgup`                 | 이전 차트 페이지로 이동합니다.              |
| `n`, `pgdown`               | 다음 차트 페이지로 이동합니다.              |
| `home`                      | 첫 번째 차트 페이지로 이동합니다.            |
| `end`                       | 마지막 차트 페이지로 이동합니다.             |

<div id="media">
  ### 미디어
</div>

이 단축키는 workspace 또는 단일 run 뷰에서 미디어 패널에 포커스가 있을 때 적용됩니다.

| 키                           | 액션                                                   |
| --------------------------- | ---------------------------------------------------- |
| `w`, `a`, `s`, `d`          | 이미지 타일을 선택합니다.                                       |
| 왼쪽 화살표, 오른쪽 화살표             | 한 프레임 뒤로 또는 앞으로 이동합니다.                               |
| 위쪽 화살표, 아래쪽 화살표             | 10프레임 뒤로 또는 앞으로 이동합니다.                               |
| `home`, `end`               | 첫 프레임 또는 마지막 프레임으로 이동합니다.                            |
| `N`, `pgup` / `n`, `pgdown` | 이미지 시리즈의 이전 또는 다음 페이지로 이동합니다.                        |
| `enter`                     | 선택한 이미지의 전체 화면 표시/숨기기.                              |
| `esc`                       | 전체 화면 미디어를 종료합니다.                                    |
| `l`                         | 이미지 시리즈 간 연동 스크러빙 표시/숨기기.                          |
| `k`                         | Kitty 그래픽 프로토콜을 지원하는 터미널에서 ANSI 및 고해상도 렌더링 표시/숨기기. |

<div id="record-inspector">
  ### 레코드 인스펙터
</div>

`wandb leet inspect`로 인스펙터를 열거나, 로컬 run의 단일 run 뷰에서 `i`를 누르세요.

| 키                           | 액션                                                          |
| --------------------------- | ----------------------------------------------------------- |
| `h`, `?`                    | 도움말 표시/숨기기.                                                 |
| `q`, `ctrl+c`               | LEET 종료.                                                    |
| `esc`                       | 필터 편집을 종료하고 레코드 목록으로 포커스 이동. 목록에서는 `i`로 열었을 경우 run으로 돌아갑니다. |
| `tab`, `shift+tab`          | 레코드 목록과 상세 패널 간 포커스 전환.                                     |
| `w`, `s`, 위쪽 화살표, 아래쪽 화살표   | 레코드 선택 또는 상세 패널 스크롤.                                        |
| `N`, `pgup` / `n`, `pgdown` | 이전 또는 다음 페이지.                                               |
| `home`                      | 첫 번째 레코드 또는 상세 패널 맨 위.                                      |
| `end`                       | 마지막 레코드 또는 상세 패널 맨 아래. 마지막 레코드에서는 실시간 업데이트를 따라갑니다.          |
| `/`                         | 유형 또는 요약으로 레코드 필터링.                                         |
| `ctrl+/`                    | 레코드 필터 지우기.                                                 |
| `0`                         | 인스펙터 패널 크기 재설정.                                             |

<div id="filter-editing">
  ### 필터 편집
</div>

다음 단축키는 필터 입력란이 활성화된 상태에서 적용됩니다.

| 키       | 액션                      |
| ------- | ----------------------- |
| `tab`   | 정규식 매칭과 glob 매칭을 전환합니다. |
| `enter` | 필터를 적용하고 편집을 종료합니다.     |
| `esc`   | 초안 쿼리를 버리고 편집을 종료합니다.   |

<div id="mouse">
  ### 마우스
</div>

| 입력                      | 액션                                                    |
| ----------------------- | ----------------------------------------------------- |
| 클릭                      | 차트에 포커스를 두거나 미디어 타일을 선택합니다.                           |
| 테두리 또는 구분선을 왼쪽 클릭 후 드래그 | 패널, 사이드바 또는 run 개요 섹션의 크기를 조절합니다.                     |
| 휠                       | 포커스된 차트를 확대/축소합니다.                                    |
| 오른쪽 클릭 후 드래그            | 차트에서 가장 가까운 지점을 확인합니다.                                |
| `alt` + 오른쪽 클릭 후 드래그    | 같은 그리드에 표시된 차트를 동기화하여 함께 확인합니다. 메트릭 차트는 X축을 공유해야 합니다. |
| `shift` + 드래그           | 터미널 텍스트를 선택합니다.                                       |
