---
title: 작업 목록
---

* **Slack 알림**: 트리거된 이벤트의 세부 정보를 담은 메시지를 Slack 채널로 보냅니다. 메시지에는 이벤트 요약과 W&amp;B에서 자세한 내용을 볼 수 있는 링크가 포함됩니다.
* **웹훅**: 트리거된 이벤트 정보가 포함된 JSON 페이로드와 함께 웹훅 URL을 호출합니다. 웹훅을 사용하여 CI/CD 파이프라인, 모델 배포 서비스, 맞춤형 워크플로와 같은 외부 시스템과 통합하세요.
* **Trigger ARIA**: [ARIA](/ko/aria/overview)에 프롬프트를 보내면 새 대화가 시작되고 ARIA가 사용자를 대신해 해당 프롬프트를 처리합니다. ARIA 액션을 사용하여 새 모델 버전을 분석하거나, 실패한 run을 진단하거나, 임계값을 넘은 메트릭을 조사하세요. W&amp;B Multi-tenant Cloud에서만 사용 가능합니다.
