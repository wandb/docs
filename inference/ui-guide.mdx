Use CoreWeave Forge to browse Serverless Inference models, compare their capabilities and prices, and test responses in the Playground. This guide covers the Inference catalog and Playground in Forge.

Before you use the UI, complete the [prerequisites](/inference/prerequisites).

## Access the Inference service

Open [Inference in Forge](https://forge.coreweave.com/inference/) and sign in to your account. The Inference sidebar provides these pages:

- **Getting started** introduces the available services and links to the Playground, code quickstart, and model catalog.
- **Models** lists available models, prices, context windows, and model actions.
- **Playground** lets you send prompts to a selected model.

### Browse models

To find a model, open **Models** in the Inference sidebar:

1. Use **Search models**, **Filters**, or the sort menu to narrow the catalog.
2. Select a project with the project selector. The selected project affects which models are available.
3. Select a model name to open its details, including its capabilities, prices, and context window.

Use **Connection settings > Manage connections** to inspect the serving connections available to your account.

## Try a model in the Playground

To test a model's response, open it from the catalog:

1. In **Models**, select the model name to open its details.
2. Select **Try in playground**. The Playground opens with that model selected.
3. Confirm the selected model and project. The project controls the available models and where W&B Weave traces are logged.
4. Enter a prompt and send the request. The response appears in the conversation.

You can also open **Playground** from the Inference sidebar and use the model selector. Open **Settings** to adjust the model's generation parameters. Use **Trace calls with Weave** to control tracing, and **View call** on a traced response to inspect its saved request.

## Compare multiple models

The **Compare models** page displays model information side by side, including capabilities, prices, and context windows. To compare model responses, test each model with your prompt in the [Playground](#try-a-model-in-the-playground).

To open the comparison page, select models from the catalog:

1. Open **Models** in the Inference sidebar.
2. In a model's **Actions** column, open **Model actions** and select **Select for Comparison**. Selection checkboxes appear in the catalog.
3. Select another model using its checkbox or **Model actions > Select for Comparison**.
4. Select **Compare 2 selected**, or the corresponding button for your selected model count. The **Compare models** page opens.

On the comparison page, use **Add model** to add another model or the removal control in a model's column to remove it. If you remove every model, use **Add model** to start a new comparison.

## View billing and usage information

Organization and billing administrators can review their organization's usage and charges in the W&B **Billing** settings. See [Manage billing settings](/platform/app/settings-page/billing-settings) for the available views and access requirements. If **Billing** is unavailable, ask your organization's billing administrator for access or usage information.

Visit the [token pricing page](https://wandb.ai/site/pricing/tokens/) for per-model pricing details.
</Tip>
