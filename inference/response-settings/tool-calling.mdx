Tool calling extends a model's capabilities to include invoking tools as part of its response. This lets the model fetch live data, trigger actions in your application, or otherwise reach beyond its training data to fulfill a request. Serverless Inference only supports calling functions.

To call functions, specify them and their arguments as part of your request to the model. The model decides whether to run a function to answer the prompt, and if so, supplies the argument values.

The following example defines a `get_weather` function and asks the model a question that requires invoking it.

<Tabs>
  <Tab title="Python">
    ```python
    import openai

    client = openai.OpenAI(
        base_url='https://api.inference.wandb.ai/v1',
        api_key="[YOUR-API-KEY]",  # Create an API key at https://wandb.ai/settings
    )

    response = client.chat.completions.create(
        model="openai/gpt-oss-20b",
        messages=[
            {"role": "user", "content": "What is the weather like in San Francisco? Use Fahrenheit."},
        ],
        tool_choice="auto",
        tools=[
            {
                "type": "function",
                "function": {
                    "name": "get_weather",
                    "description": "Get the current weather in a given location",
                    "parameters": {
                        "type": "object",
                        "properties": {
                            "location": {"type": "string", "description": "City and state, e.g., 'San Francisco, CA'"},
                            "unit": {"type": "string", "enum": ["celsius", "fahrenheit"]},
                        },
                        "required": ["location", "unit"],
                    },
                },
            }
        ],
    )

    print(response.choices[0].message.tool_calls)
    ```

## Run tool loops with agent SDKs

Agent software development kits (SDKs) execute the requested functions and send their results back to the model. The following Python examples use `zai-org/GLM-5.3-Flash` with the Serverless Inference Chat Completions endpoint.

Before you start, complete the [Serverless Inference prerequisites](/inference/prerequisites) and set the `WANDB_API_KEY` environment variable to your W&B API key. Use Python 3.12 in a virtual environment for these examples.

### OpenHands SDK

The [OpenHands SDK](https://docs.openhands.dev/sdk/getting-started) example reads, edits, and reads a temporary file again. It uses the file editor tool and checks the resulting file contents. Install the matching SDK and tools versions used in this example:

```bash
python -m pip install "openhands-sdk==1.21.0" "openhands-tools==1.21.0"
```

The `openai/` prefix in `model` selects the OpenAI-compatible provider. The request sent to Serverless Inference uses `zai-org/GLM-5.3-Flash` as the model ID.

```python
import os
from pathlib import Path
from tempfile import TemporaryDirectory

from openhands.sdk import LLM, Agent, Conversation, Tool
from openhands.tools.file_editor import FileEditorTool
from pydantic import SecretStr

llm = LLM(
    model="openai/zai-org/GLM-5.3-Flash",
    base_url="https://api.inference.wandb.ai/v1",
    api_key=SecretStr(os.environ["WANDB_API_KEY"]),
    native_tool_calling=True,
    max_input_tokens=1048576,
    max_output_tokens=2048,
    num_retries=0,
    timeout=35,
    reasoning_effort=None,
    caching_prompt=False,
)
agent = Agent(llm=llm, tools=[Tool(name=FileEditorTool.name)])

with TemporaryDirectory() as workspace:
    target = Path(workspace) / "greeting.txt"
    target.write_text("Hello before OpenHands.\n", encoding="utf-8")
    conversation = Conversation(
        agent=agent,
        workspace=workspace,
        persistence_dir=None,
        max_iteration_per_run=4,
    )
    try:
        conversation.send_message(
            f"Use the file editor to view {target}, replace only the text "
            "'Hello before OpenHands.' with 'Hello from Serverless Inference.', "
            "then view the file again. Use a separate tool call for each operation. "
            "Do not access other files. Then finish immediately."
        )
        conversation.run()
        assert target.read_text(encoding="utf-8") == "Hello from Serverless Inference.\n"
        print("File edit verified.")
    finally:
        conversation.close()
```

The script prints `File edit verified.` after the file contents pass the check. This example configures the Python SDK directly.

### smolagents

The [smolagents `ToolCallingAgent`](https://huggingface.co/docs/smolagents/v1.26.0/en/reference/agents#smolagents.ToolCallingAgent) calls Python functions that you register with `@tool`. This example looks up a quantity in sample inventory data and returns the answer.

Install the package with its OpenAI client dependency:

```bash
python -m pip install "smolagents[openai]==1.26.0"
```

Configure [`OpenAIModel`](https://huggingface.co/docs/smolagents/v1.26.0/en/reference/models#smolagents.OpenAIModel) with the endpoint and the model ID, then pass your function to the agent:

```python
import os

from smolagents import OpenAIModel, ToolCallingAgent, tool


@tool
def get_stock(product: str) -> int:
    """Return the available quantity from sample inventory data.

    Args:
        product: Product name, either notebook or pen.
    """
    inventory = {"notebook": 12, "pen": 30}
    return inventory[product]


model = OpenAIModel(
    model_id="zai-org/GLM-5.3-Flash",
    api_base="https://api.inference.wandb.ai/v1",
    api_key=os.environ["WANDB_API_KEY"],
    client_kwargs={"max_retries": 0, "timeout": 35},
    retry=False,
    max_tokens=2048,
)
agent = ToolCallingAgent(
    tools=[get_stock],
    model=model,
    max_steps=3,
    verbosity_level=0,
)
answer = agent.run(
    "Call get_stock with product 'notebook', then return the quantity in stock."
)
print(answer)
```

The answer reports that 12 notebooks are in stock. `ToolCallingAgent` executes `get_stock()` locally and sends its result to the model to produce the final answer.

### Pydantic AI

[Pydantic AI](https://pydantic.dev/docs/ai/models/openai/) executes your Python tools and validates the final result against a Python type. This example calls an inventory tool and returns a `StockResult` object.

Install the packages used in this example:

```bash
python -m pip install "pydantic-ai-slim[openai]==2.46.0" "openai==3.16.2"
```

Configure `OpenAIChatModel` with a custom `OpenAIProvider`. The model profile selects `max_tokens` and turns off strict tool definitions. [`ToolOutput`](https://pydantic.dev/docs/ai/core-concepts/output/#tool-output) returns structured data through a tool call, which Pydantic validates locally. This example doesn't use server-enforced JSON schema output.

```python
import asyncio
import os
from typing import Literal

from openai import AsyncOpenAI
from pydantic import BaseModel
from pydantic_ai import Agent, ToolOutput
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.profiles.openai import OpenAIModelProfile
from pydantic_ai.providers.openai import OpenAIProvider
from pydantic_ai.usage import UsageLimits


class StockResult(BaseModel):
    product: Literal["notebook"]
    quantity: int


async def main():
    async with AsyncOpenAI(
        base_url="https://api.inference.wandb.ai/v1",
        api_key=os.environ["WANDB_API_KEY"],
        max_retries=0,
        timeout=35,
    ) as client:
        model = OpenAIChatModel(
            "zai-org/GLM-5.3-Flash",
            provider=OpenAIProvider(openai_client=client),
            profile=OpenAIModelProfile(
                openai_chat_supports_max_completion_tokens=False,
                openai_supports_strict_tool_definition=False,
            ),
        )
        agent = Agent(
            model,
            output_type=ToolOutput(StockResult, strict=False),
            instructions=(
                "Use get_stock to look up inventory. Return its product and "
                "quantity as structured output. Do not guess the quantity."
            ),
            model_settings={"max_tokens": 2048},
            retries=0,
        )

        @agent.tool_plain
        def get_stock(product: Literal["notebook", "pen"]) -> int:
            """Return available units from sample inventory data."""
            return {"notebook": 12, "pen": 30}[product]

        async with agent.run_stream(
            "How many notebooks are available?",
            usage_limits=UsageLimits(request_limit=4, tool_calls_limit=3),
        ) as result:
            output = await result.get_output()
            print(output.model_dump_json())


asyncio.run(main())
```

The script uses streaming requests and prints the validated inventory result:

```text
{"product":"notebook","quantity":12}
```
