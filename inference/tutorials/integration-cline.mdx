[Cline](https://cline.bot) is an AI-powered coding assistant. This tutorial demonstrates how to configure Cline to use models provided by Serverless Inference, so that you can use open-weight models hosted on W&B Inference for your coding tasks.

The following sections describe configuration with the Cline CLI, Cline Desktop, and the Visual Studio Code extension.

## Prerequisites

You need your [W&B API key](../prerequisites#set-up-your-wb-account-and-project).

## Set up Cline in the command line

Install the [Cline CLI](https://docs.cline.bot/cline-cli/installation).

```bash
npm install -g cline
```

See [Cline's installation instructions](https://docs.cline.bot/cline-cli/installation) for troubleshooting.

Run `cline version` to verify what you have installed.

### Use the native W&B provider

This configuration was tested with Cline CLI version `3.0.61` on macOS. Set the `WANDB_API_KEY` environment variable to your W&B API key. Then run:

```bash
cline -P wandb -m zai-org/GLM-5.3-Flash "What is 2 + 2?"
```

The provider's command-line ID is `wandb`. Depending on your Cline version and interface, its display name is **CoreWeave**, **W&B Inference by CoreWeave**, **Weights & Biases**, or **W&B**. These labels use the same W&B API key. Cline uses that provider's configured Serverless Inference endpoint. If Cline responds with an answer, the connection is working.

### Use the OpenAI-compatible provider

The following instructions were tested with Cline CLI version `2.5.1`.

Next, authenticate Cline against the Serverless Inference endpoint. The following command configures Cline to use the Serverless Inference OpenAI-compatible endpoint and the Kimi K2.6 model. Substitute `[YOUR-API-KEY]` with your W&B API key.

```bash
cline auth -k [YOUR-API-KEY] -p openai -b https://api.inference.wandb.ai/v1 -m moonshotai/Kimi-K2.6
```

For model availability and pricing, see the [W&B Inference model catalog](https://wandb.ai/inference).

Run a test to verify everything is working:

```bash
cline "What is 2 + 2?"
```

If Cline responds with an answer, your installation and authentication are complete.

For more information about using the Cline CLI, see the [Cline Quickstart](https://docs.cline.bot/cline-cli/installation#quick-start).

## Set up Cline Desktop

The provider connection, saved credentials, and file-editing workflow were verified with Cline Desktop `0.0.31` on macOS using `zai-org/GLM-5.3-Flash`. This verification doesn't establish tool-calling support for every model in the catalog.

To configure the provider in [Cline Desktop](https://docs.cline.bot/usage/cline-desktop):

1. Open **Settings**, then **API Providers**, and select **CoreWeave**.
2. Enter your W&B API key. The **Get a CoreWeave API key** link opens [W&B user settings](https://wandb.ai/settings). Keep the default base URL, `https://api.inference.wandb.ai/v1`.
3. Return to the session composer, select the **Local** environment, and open the workspace you want Cline to edit.
4. Select **CoreWeave** and **GLM 5.3 Flash** (`zai-org/GLM-5.3-Flash`) in the provider and model selectors.
5. [Verify a file edit](#verify-a-file-edit) before using the connection for a larger task.

If you've used Cline in VS Code, check the Desktop provider configuration separately. Don't assume an existing extension API key has been imported. After configuring Desktop, restart it and confirm that **CoreWeave** remains **Configured** and the selected model is retained.

### Use the built-in provider

Cline extension `4.1.19` includes both an older interface and a newer interface. The provider label and model list depend on the active interface, even with the same extension version.

To use the built-in provider:

1. In Cline's provider settings, select **CoreWeave**. In the older interface, select **W&B Inference by CoreWeave**.
2. Enter your W&B API key in the provider's API key field.
3. Select a model available in that interface. The newer interface was verified with `zai-org/GLM-5.3-Flash`. The older interface was verified with `deepseek-ai/DeepSeek-V3.1` and didn't list GLM 5.3 Flash.
4. [Verify a file edit](#verify-a-file-edit).

For available models and capabilities, see the [model catalog](../models). If your interface doesn't offer the model you need, use the OpenAI-compatible configuration in the following section with an exact model ID from the catalog.

### Use the OpenAI-compatible provider

Specify the following values, substituting `[YOUR-API-KEY]` with your W&B API key:

| Setting                    | Value                               |
| -------------------------- | ----------------------------------- |
| API Provider               | `OpenAI Compatible`                 |
| Base URL                   | `https://api.inference.wandb.ai/v1` |
| OpenAI Compatible API Key  | `[API-KEY]`                         |
| Model ID                   | `moonshotai/Kimi-K2.6`              |

Specify pricing by expanding **Model Configuration**.

Click **Continue**.

Try submitting a prompt like "Write a Python program to compute the first 10 Fibonacci Numbers".

## Verify a file edit

Use a test workspace to confirm that the selected model can read and edit files, beyond answering a chat prompt:

1. Create `greeting.txt` with `status=pending` on one line and a single final newline.
2. Submit this prompt in Cline:

   ```text
   Read greeting.txt using the file-reading tool. Then use the
   editor to replace status=pending with status=verified,
   preserving the final newline. Read the file again to verify.
   Work only on greeting.txt in this workspace. Do not run
   commands, access the network, read other files, create
   tasks, or spawn agents. Finish with a short confirmation.
   ```

3. Review any requested file-edit approval, then inspect the resulting file. It should contain `status=verified` with one final newline and no extra blank line.

Check the file contents even if the model reports success. In the Desktop `0.0.31` verification, the first edit added an extra newline, and a corrective prompt was needed. Authentication and file tools worked, but the first response didn't guarantee exact formatting.
