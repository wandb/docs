このページでは、チャットの開始と再開、フォローアップメッセージのキューイング、コンテキストの追加、ネットワークアクセスの許可、応答に対するフィードバックの提供など、ARIA との会話を管理する方法について説明します。コンテキストには、Runs、Workspace のパネル、W&amp;B Weave のトレース、画像などを含めることができます。また、会話の名前変更、ピン留め、削除によってチャット履歴を整理する方法についても説明します。

## 新しいチャットを開始する {#start-a-new-chat}

新しいチャットを開始するには、ARIA を開き、チャットウィンドウの右上にある鉛筆アイコンをクリックします。

複数のチャットを同時並行で進めることができます。チャットウィンドウを閉じていても、チャットに返信があると ARIA から通知されます。

新しいチャットを開始しても、以前の会話は削除されません。[以前の会話を表示する](/ja/aria/chat#view-chat-history)には、**<Icon icon="sidebar-reveal" iconType="solid" />** (**Reveal chat history**) をクリックしてチャット履歴のサイドバーを開きます。

## メッセージを送信する {#send-a-message}

メッセージを入力し、**Enter** を押して送信します。

* **Shift+Enter** を押すと改行できます。
* **+** をクリックして画像を追加します。
* run 参照を追加するには、`<Icon icon="at" iconType="solid"/>` と入力し、リストから run を選択します。入力すると、リストをフィルターしたり、あいまい検索したりできます。
* より柔軟に操作するには、テキストエディターで複雑なメッセージを作成して貼り付けます。プレーンテキストに対応しており、貼り付けた `@` 文字は run 参照として解決されません。

現在の操作をキャンセルし、次の[キューに入っているメッセージ](#queue-messages)を&#95;すぐに&#95;送信するには、テキスト入力欄の右にある停止アイコンを押します。

コンテキストを保ちやすくするため、ARIA は折れ線グラフや棒グラフをチャット内に直接レンダリングし、全画面表示にも対応しています。Workspace の **Runs** タブで run にカーソルを合わせると、ARIA 内でその run のグラフがハイライトされ、ARIA 内のパネルにカーソルを合わせると **Runs** タブで該当の run がハイライトされます。

## キュー内のメッセージ {#queue-messages}

メッセージキューには、ARIA の処理中に送信した後続のタスクや質問が保持されます。ARIA は、会話全体をコンテキストとして使用し、キューに入れられた各メッセージを順番に実行します。前のメッセージが完了すると、すぐに次のメッセージが実行されます。

キューを使用すると、ステップごとにチャットに戻って送信する代わりに、複数のステップを一度に並べて、その場を離れることができます。たとえば、まず比較を依頼できます。

<AriaChatBubbles prompt="直近の 10 件の Runs を比較し、最も影響の大きかったハイパーパラメーターを教えてください。" response="これら 10 件の Runs における検証損失のばらつきの大部分は、学習率とバッチサイズによるものです。各 run の詳細を以下に示します。" />

ARIA の処理中に、追加のリクエストをチャットウィンドウに送信できます。W&amp;B は保留中のリクエストを ARIA のキューに追加します。

この例では、2 つのメッセージを同時に送信します。

```text title="Queued messages"
これらの run について、学習率に対する検証損失をチャートにしてください。

その比較内容を、チームで共有できる report にまとめてください。
```

キューのヘッダーには、待機中のメッセージ数が表示されます。キューに入っている各メッセージには、3 つの操作があります。

* **鉛筆アイコン** (<Icon icon="pencil" iconType="solid" />): ARIA が実行する前にメッセージを編集します。ARIA はメッセージをメッセージボックスに移動してキューから削除するため、キューに入れ直すにはもう一度送信します。メッセージボックスにすでに下書きがある場合、この操作は使用できません。
* **上矢印アイコン** (<Icon icon="arrow-up" iconType="solid" />): 順番を待たずに、メッセージを今すぐ実行します。ARIA は現在の処理を中断し、このメッセージを次に実行します。キュー内の他のメッセージの順序は維持されます。
* **ごみ箱アイコン** (<Icon icon="trash" iconType="solid" />): キューからメッセージを削除します。

キューに入っているメッセージには、[run メンション](/ja/aria/chat#add-context-to-a-conversation)や[画像](/ja/aria/chat#add-an-image-to-a-conversation)を含め、添付したコンテキストが保持されます。

キューで実行するには会話が必要なため、キューイングはチャットで最初のメッセージを送信した後に開始されます。最初に送信するメッセージと、キューが空のアイドル状態のチャットに送信するメッセージは、すぐに ARIA に送られます。各チャットには独自のキューがあり、閉じたチャットのキューも引き続き実行されます。

ARIA が続行前に確認への回答や許可を求める場合、応答するまでキューは一時停止します。先に応答せずにキュー内のメッセージを実行するには、その横にある上矢印アイコンをクリックします。

## 会話を管理する {#manage-conversations}

以下のセクションでは、会話の表示、リネーム、ピン留め、削除の方法について説明します。

### チャット履歴 を表示する {#view-chat-history}

過去の会話を表示するには、次の手順に従います。

1. ARIA を開きます。
2. **<Icon icon="sidebar-reveal" iconType="solid" />** (**Reveal chat history**) をクリックして、チャット履歴 サイドバーを開きます。デフォルトでは折りたたまれています。サイドバーが開いている間、同じコントロールの表示は **Collapse chat history** に変わります。
3. 再開したい会話を選択します。

ピン留めされた会話は日付ごとにグループ化されず、単一の **Pinned** ヘッダーの下にまとめて先頭に表示されます。その後にピン留めされていない会話が続き、**Today**、**Yesterday**、**Last 7 Days**、**Last 30 Days**、さらに月単位、1 年より古い会話は年月単位でグループ化されます。各グループ内では、直近に活動があった会話が先頭に表示されます。

会話の行にマウスオーバーするか、キーボードでフォーカスすると、次の 2 つのコントロールが表示されます。

* **<Icon icon="thumbtack" iconType="solid" />** (**Pin chat** / **Unpin chat**) : [会話をピン留めする](#pin-a-conversation) を参照してください。
* **<Icon icon="ellipsis" iconType="solid" />** (**Chat actions**) : **Rename chat** と **Delete chat** を含むメニューが開きます。詳しくは、[会話をリネームする](#rename-a-conversation) および [過去の会話を削除する](#delete-previous-conversations) を参照してください。

チャット履歴 サイドバーの **Customize** セクションには、作成した ARIA のオートメーションも一覧表示されます。[ARIA でオートメーションを使用する](/ja/models/automations/create-automations/aria) を参照してください。

### 会話をリネームする {#rename-a-conversation}

新しいチャットで最初のメッセージを送信すると、ARIA が会話のタイトルを生成します。生成中は、チャット履歴サイドバーのタイトルがきらめくように表示されます。ARIA がタイトルを生成できなかった場合は、最初のプロンプトの抜粋がその会話のタイトルになります。ARIA が会話にタイトルを付けるのは 1 回だけで、以降のメッセージによってタイトルが変わることはありません。

会話のタイトルを変更するには、次の手順を実行します。

1. チャット履歴サイドバーで、リネームする会話にカーソルを合わせます。
2. **<Icon icon="ellipsis" iconType="solid" />** (**Chat actions**) をクリックし、**Rename chat** を選択します。タイトルが編集可能なフィールドに切り替わります。
3. タイトルを入力します (最大 255 文字)。
4. **Enter** キーを押すか、**<Icon icon="check" iconType="solid" />** (**Save chat title**) をクリックして保存します。変更を破棄するには、**Escape** キーを押すか、**<Icon icon="xmark" iconType="solid" />** (**Cancel rename**) をクリックします。

フィールドを空にして保存すると、タイトルは最初のプロンプトの抜粋に置き換えられます。抜粋がない場合は **Untitled conversation** になります。空白のみを入力して保存した場合は、タイトルはクリアされず、リネームがキャンセルされます。

リネームしたタイトルは、開いているすべてのブラウザータブに同期されます。スマートフォンからチャットをリネームすることもできます。詳細については、モバイルアプリのドキュメントの [Chat with ARIA](/ja/platform/hosting/monitoring-usage/mobile-app#chat-with-aria) を参照してください。

### 会話をピン留めする {#pin-a-conversation}

会話をピン留めすると、新しい chat が増えても下に流れてしまうことなく、チャット履歴 サイドバーの最上部に固定できます。

1. チャット履歴 サイドバーで、ピン留めする会話にカーソルを合わせます。
2. **<Icon icon="thumbtack" iconType="solid" />** (**Pin chat**) をクリックします。会話が **Pinned** ヘッダーの下に移動します。
3. ピン留めを解除するには、ピン留め済みの会話で **<Icon icon="thumbtack" iconType="solid" />** (**Unpin chat**) をクリックします。

ピン留めできる会話の数に制限はなく、ピン留めの変更は開いているブラウザータブ間で同期されます。ピン留めが影響するのは自分の会話リストのみで、同じ project にアクセスできるチームメンバーの表示には影響しません。

### 以前の会話を削除する {#delete-previous-conversations}

以前の会話を削除するには、次の手順に従ってください。

1. ARIA を開きます。
2. **<Icon icon="sidebar-reveal" iconType="solid" />** (**Reveal chat history**) をクリックして、チャット履歴のサイドバーを開きます。
3. 削除したい会話にカーソルを合わせ、**<Icon icon="ellipsis" iconType="solid" />** (**Chat actions**) をクリックしてから、**Delete chat** を選択します。
4. **Delete this chat?** ダイアログで **Delete** をクリックして確定します。この操作は元に戻せません。

## チャットウィンドウを切り離す {#undock-chat-window}

チャットウィンドウを別ウィンドウとして切り離すことができます。これにより、ARIA の応答を project データと並べて表示できます。

チャットを切り離すには、チャットウィンドウの右上にある閉じる (**X**) ボタンの横の切り離しアイコンをクリックします。

## 会話にコンテキストを追加する {#add-context-to-a-conversation}

run、Workspace パネル、Weave のトレースや評価をチャットに添付すると、質問に必要なコンテキストを ARIA に正確に伝えられます。添付した項目は、それぞれメッセージボックス内に削除可能なタグとして表示されます。1 つのメッセージに複数の項目を添付できます。コンテキストを追加しただけでは、メッセージは送信されません。準備ができたら **Send** をクリックしてください。

ページからコンテキストを追加すると、ARIA はチャットウィンドウで開いている会話にそのコンテキストを追加します。開いている会話がない場合は、ARIA が新しい会話を開始します。

### run をメンションする {#mention-a-run}

メッセージボックスに `@` を入力し、run を選択します。たとえば、プロンプトにその run 名を含めることで、ARIA に特定の run を分析するよう依頼できます。

```text title="User prompt"
Analyze the run @run-20230615_123456-abcdefg and summarize the results
```

Workspace の **Runs** 表から run を追加することもできます。run にカーソルを合わせて **アクション (<Icon icon="ellipsis" iconType="solid" />)** メニューをクリックし、**Ask ARIA** を選択します。

### Workspace パネルを追加する {#add-a-workspace-panel}

Workspace パネルをチャットに添付するには、次の手順を実行します。

1. Workspace でパネルにカーソルを合わせ、**アクション (<Icon icon="ellipsis" iconType="solid" />)** メニューをクリックします。
2. **Ask ARIA** を選択します。パネルが添付された状態で ARIA が開きます。
3. `Why does loss spike after step 2,000?` のような質問を入力して送信します。

**Ask ARIA** は、編集権限のある Workspace のパネルメニューに表示されます。Reports 内のパネルには表示されません。

### Weave のトレースと評価を追加する {#add-weave-traces-and-evaluations}

Weave では、ARIA ボタンをクリックして、トレース、評価、または評価結果をチャットに添付できます。ボタンにカーソルを合わせると、**Ask ARIA about this trace** や **Ask ARIA about these evals** などのラベルが表示されます。このボタンは次の場所に表示されます。

* **Traces** または **Evals** 表: 1 つ以上の行を選択すると、表のツールバーにボタンが表示されます。このボタンをクリックすると、選択したすべての行が添付されます。
* **トレースまたは評価の詳細ページ**: ページヘッダーにボタンが表示されます。
* **評価の比較**: 評価を比較して例の詳細を表示している場合、このボタンをクリックすると、その例の予測とスコアが添付されます。

ARIA は、添付されたトレースと評価を使用して質問に回答します。例:

```text title="User prompt"
これらの例で、モデルのスコアが前回の評価よりも低くなったのはなぜですか？
```

## 会話に画像を追加する {#add-an-image-to-a-conversation}

チャットウィンドウの左下にあるプラスアイコン (`+`) をクリックすると、会話に画像を追加できます。その後、ARIA に画像の分析や説明を依頼できます。

## ネットワークアクセスを許可する {#grant-network-access}

ARIA のサンドボックスでブロックされているドメインがタスクに必要な場合、ARIA はネットワークアクセスの許可を求め、応答を待ちます。たとえば、Python パッケージをインストールするタスクには `pypi.org` と `files.pythonhosted.org` へのアクセスが必要です。デフォルトでは、ARIA がコードを実行するサンドボックスは W&amp;B のサービスにはアクセスできますが、インターネット上のその他のほとんどのドメインへのアクセスはブロックされています。

リクエストはチャット内の **The agent is requesting network access** の下に表示されます。リクエストの理由と、要求されたドメインの一覧が表示されます。ドメインは最初はすべて選択された状態です。次のいずれかの方法でリクエストに応答します。

* アクセスを許可するには、許可しないドメインの選択を解除してから **Grant access** をクリックします。ARIA は作業を再開し、許可されたドメインにアクセスできるようになります。
* アクセスを拒否するには、**Deny** をクリックします。ARIA は追加のアクセス権なしで作業を続行します。

リクエストへの応答を待っている間は、メッセージを送信できません。また、キューに入っているメッセージも実行されません。

<Warning>
  サンドボックス内で実行されるコードは、許可したドメインであればどこにでもデータを送信できます。アクセスは信頼できるドメインにのみ許可してください。
</Warning>

許可したドメインは、取り消さない限りその会話が終わるまで利用できます。新しいチャットは、いずれもデフォルトのアクセス権のみで開始されます。ドメインを自分で追加することはできません。タスクで必要になった時点で ARIA がリクエストします。

### ネットワークアクセスの確認または取り消し {#review-or-revoke-network-access}

会話でアクセスを許可すると、メッセージボックスのプラスアイコン (`+`) の横に **<Icon icon="link" iconType="solid" />** (**Manage network access**) が表示されます。

アクセスを取り消すには、次の手順を実行します。

1. **<Icon icon="link" iconType="solid" />** (**Manage network access**) をクリックします。この会話でアクセスが許可されているドメインの一覧が開きます。
2. 取り消すドメインのチェックを外します。
3. **Update access** をクリックします。

W&amp;B は取り消されたドメインの一覧を記載したメッセージを ARIA に送信し、ARIA はそれ以降、これらのドメインにアクセスせずに動作します。ARIA の処理中はネットワークアクセスを変更できません。

## フィードバックを送信する {#provide-feedback}

ARIA の応答についてフィードバックを送信するには、応答の末尾にあるサムズアップまたはサムズダウンのアイコンをクリックします。お寄せいただいたフィードバックは、W&amp;B による ARIA のパフォーマンスと精度の向上に役立ちます。

W&amp;B における ARIA のデータ利用の取り扱いについては、[ガバナンスとセキュリティ](/ja/aria/governance)を参照してください。
