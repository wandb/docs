<div id="usage">
  ## 使い方
</div>

```bash
sync [OPTIONS] [PATHS]...
```

<div id="description">
  ## Description
</div>

既存のローカル W&amp;B run データをクラウドにアップロードします。

オフラインまたは未完了の runs を W&amp;B server に同期します。特定の runs を同期する場合は PATHS を指定します。引数なしで実行すると、wandb フォルダー内のアップロードされていない runs が同期されます。

PATHS を指定しない場合は、同期前に確認が求められます。確認をスキップするには --yes、同期せずに終了するには --dry-run を指定してください。

PATHS には run のディレクトリを指定します。通常は次の形式です。

./wandb/run-YYYYMMDD&#95;HHMMSS-RUN&#95;ID

YYYYMMDD&#95;HHMMSS は run が作成された時点の timestamp、RUN&#95;ID はその run の一意の ID です。

たとえば、ローカルの runs とその同期ステータスの summary を表示するには、次のように実行します。

```bash
wandb sync --dry-run
```

./wandb/run-20170617&#95;000000-abcd1234 に保存されている Run ID abcd1234 を同期するには、次のようにします。

```bash
wandb sync ./wandb/run-20170617_000000-abcd1234
```

wandb フォルダー内の未同期の run をすべて同期するには、次のようにします。

```bash
wandb sync
```

`wandb clean` を使用すると、同期済みの run のローカルデータを削除できます。参照:

```bash
wandb clean --help
```

の詳細については、こちらをご覧ください。

<div id="options">
  ## オプション
</div>

| フラグ                                  | タイプ      | 説明                                                                                                                                      |
| ------------------------------------ | -------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `-v, --verbose`                      | BOOL フラグ | より詳細な情報を表示します。**デフォルト**: False                                                                                                          |
| `--yes`                              | BOOL フラグ | 確認のプロンプトを表示しません。**デフォルト**: False                                                                                                        |
| `--id`                               | STR      | 既存の run ID にアップロードします。複数の file を同期する場合 (entity と project が同一の場合) にこれを指定すると、file は開始時刻順に同期されます。**デフォルト**: None                           |
| `--project, -p`                      | STR      | 同期するすべての run の project を上書きします。**デフォルト**: None                                                                                          |
| `--entity, -e`                       | STR      | 同期するすべての run の entity を上書きします。**デフォルト**: None                                                                                           |
| `--job-type`                         | STR      | 同期するすべての run のジョブタイプを上書きします。**デフォルト**: None                                                                                             |
| `--include-online, --no-skip-online` | BOOL フラグ | オンラインモードで作成された run を含めます。**デフォルト**: None                                                                                                |
| `--include-synced, --no-skip-synced` | BOOL フラグ | すでに同期済みの run を含めます。**デフォルト**: None                                                                                                      |
| `--replace-tags`                     | STR      | &#39;old1=new1,old2=new2&#39; の形式でタグをリネームします。**デフォルト**: None                                                                            |
| `--dry-run`                          | BOOL フラグ | 何もアップロードせずに、実行される内容のみを表示します。**デフォルト**: False                                                                                            |
| `-n`                                 | INT      | 一度に同期する run の最大数。同一の run に属する複数の file を同期する場合は、この設定に関係なく、file が開始時刻順に順次同期されます。これは、再開した run の場合や `--id` パラメーターを使用した場合に該当します。**デフォルト**: 5 |
