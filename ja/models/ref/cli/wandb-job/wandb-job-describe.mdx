## 使用方法 {#usage}

```bash
describe [OPTIONS] JOB
```

## 説明 {#description}

Launch ジョブの説明。Launch ジョブは、entity/project/job-name:alias-or-version の形式
で指定します。

## 引数 {#arguments}

| 名     | デフォルト | タイプ  |
| ----- | ----- | ---- |
| `job` | STR   | True |
