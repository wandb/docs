<div id="usage">
  ## 使用方法
</div>

```bash
inspect [OPTIONS] [PATH]
```

<div id="description">
  ## 説明
</div>

run の .wandb トランザクションログに含まれる生のレコードを参照します。

ログに保存されたレコードを一覧で表示し、選択したレコードの
テキストビューを並べて表示します。stdout がターミナルに接続されていない場合は、
代わりにレコードをテキストとして出力します。例:

wandb leet inspect run.wandb | less

PATH には .wandb file、これを含む run ディレクトリ、または
wandb ディレクトリを指定できます。PATH を指定しない場合は、
最新の run が使用されます。

<div id="arguments">
  ## 引数
</div>

| 名      | デフォルト | タイプ   |
| ------ | ----- | ----- |
| `path` | STR   | False |

  ## オプション
</div>
