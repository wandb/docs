## 使用方法 {#usage}

```bash
inspect [OPTIONS] [PATH]
```

## 説明 {#description}

run の .wandb トランザクションログに含まれる生のレコードを参照します。

ログに保存されているレコードを一覧表示し、選択したレコードを横にテキストビューで表示します。stdout がターミナルでない場合は、代わりにレコードをテキストとして出力します。例:

wandb leet inspect run.wandb | less

PATH には .wandb file、.wandb file を含む run ディレクトリ、または
wandb ディレクトリを指定できます。PATH を指定しない場合は、最新の run が使用されます。

## 引数 {#arguments}

| 名      | デフォルト | タイプ   |
| ------ | ----- | ----- |
| `path` | STR   | False |

## オプション {#options}

| フラグ          | タイプ      | 説明                                 |
| ------------ | -------- | ---------------------------------- |
| `-h, --help` | BOOL フラグ | このメッセージを表示して終了します。**デフォルト**: False |
