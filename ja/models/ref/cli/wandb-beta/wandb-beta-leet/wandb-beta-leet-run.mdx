## 使用方法 {#usage}

```bash
run [OPTIONS] [PATH]
```

## 説明 {#description}

LEET TUI を起動します。

LEET は、任意の PATH で指定した W&amp;B の run を表示するためのターミナル UI です。

PATH には、`.wandb` ファイル、`.wandb` ファイルを含む run ディレクトリ、
または W&amp;B の run URL を指定できます。
PATH を指定しない場合、コマンドは最新の run を探します。

## 引数 {#arguments}

| 名      | デフォルト | タイプ   |
| ------ | ----- | ----- |
| `path` | STR   | False |

## オプション {#options}

| フラグ          | タイプ      | 説明                                |
| ------------ | -------- | --------------------------------- |
| `-h, --help` | BOOL フラグ | このメッセージを表示して終了します。 **既定値**: False |
