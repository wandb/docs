<div id="examples">
  ## 例
</div>

project &quot;my-project&quot; 内の任意の run で、状態が
&quot;finished&quot; (つまり成功) または &quot;failed&quot; に変化したときに
トリガーされるイベントを定義します:

```python
from wandb import Api
from wandb.automations import OnRunState

api = Api()
project = api.project(name="my-project")

event = OnRunState(
    scope=project,
    filter=RunEvent.state.in_(["finished", "failed"]),
)
```
