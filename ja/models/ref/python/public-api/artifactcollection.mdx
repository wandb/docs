## <Badge color="yellow" size="lg" shape="rounded">クラス</Badge> wandb.apis.public.ArtifactCollection

関連する アーティファクト のグループを表す アーティファクト コレクション。

<div id="properties">
  ## プロパティ
</div>

<ResponseField name="aliases" type="list[str]">
  このコレクションに含まれるすべてのアーティファクト バージョンのエイリアス。
</ResponseField>

<ResponseField name="created_at" type="str">
  アーティファクト コレクションの作成日。
</ResponseField>

<ResponseField name="description" type="str | None">
  アーティファクト コレクションの説明。
</ResponseField>

<ResponseField name="entity" type="str">
  project を所有するエンティティ (ユーザーまたはチーム) 。
</ResponseField>

<ResponseField name="id" type="str">
  アーティファクト コレクションの一意の ID。
</ResponseField>

<ResponseField name="name" type="str">
  アーティファクト コレクションの名前。
</ResponseField>

<ResponseField name="project" type="str">
  アーティファクト コレクションを含む project。
</ResponseField>

<ResponseField name="project_id" type="str">
  このコレクションの project のエンコード済み GraphQL ID。
</ResponseField>

<ResponseField name="project_internal_id" type="str | None">
  取得されている場合、このコレクションの基盤となる project の GraphQL `internalId`。

  これは base64 エンコードされたグローバル ID です。デコードすると、
  `Project:123` または `ProjectInternalId:123` のようになります。
</ResponseField>

<ResponseField name="tags" type="list[str]">
  アーティファクト コレクションに関連付けられたタグ。
</ResponseField>

<ResponseField name="type" type="">
  アーティファクト コレクションのタイプを返します。
</ResponseField>

<ResponseField name="updated_at" type="str | None">
  アーティファクト コレクションが最後に更新された日付。
</ResponseField>
