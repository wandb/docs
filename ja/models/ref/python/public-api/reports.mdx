  ## <Badge color="yellow" size="lg" shape="rounded">クラス</Badge> wandb.apis.public.Reports

レポート は、`BetaReport` オブジェクトを遅延的に返すイテレーターです。

```python
(service_api: 'ServiceApi',
project: 'Project',
name: 'str | None' = None,
entity: 'str | None' = None,
per_page: 'int' = 50)
```

<div id="args">
  ## 引数
</div>

<ResponseField name="service_api" type="ServiceApi">
  このコレクションに対する W&amp;B API 呼び出しを実行する wandb-core サービスへのインターフェースです。
</ResponseField>

<ResponseField name="project" type="Project">
  レポート の取得元となる project です。
</ResponseField>

<ResponseField name="name" type="str | None">
  フィルター対象の レポート 名です。`None` の場合は、すべての レポート を取得します。
</ResponseField>

<ResponseField name="entity" type="str | None">
  project の entity 名です。デフォルトでは、project の entity が使用されます。
</ResponseField>

<ResponseField name="per_page" type="int">
  ページごとに取得する レポート の数です (デフォルトは 50) 。
</ResponseField>
