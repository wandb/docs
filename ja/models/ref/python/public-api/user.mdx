<div id="class-wandbapispublicuser">
  ## <Badge color="yellow" size="lg" shape="rounded">クラス</Badge> wandb.apis.public.User
</div>

W&amp;B インスタンス上のユーザー。

このクラスでは、ユーザーの APIキーを管理し、チーム への所属情報などにアクセスできます。`create` クラスメソッドを使用して、新しいユーザーを作成できます。

<div id="properties">
  ## プロパティ
</div>

<ResponseField name="api_keys" type="list[str]">
  ユーザーのAPIキーの名前。

  このプロパティが返すのはAPIキーの名前であり、キーに関連付けられたシークレットそのものでは*ありません*。キーの名前をAPIキーとして使用することはできません。

  ユーザーがAPIキーを持っていない場合、またはAPIキーが読み込まれていない場合、このリストは空です。
</ResponseField>

<ResponseField name="teams" type="list[str]">
  ユーザーのチームの名前。

  ユーザーがどのチームにも所属していない場合、またはチームデータが読み込まれていない場合、これは空のリストです。
</ResponseField>

<ResponseField name="user_api" type="Api | None">
  ユーザーの認証情報を使用する`wandb.Api`インスタンス。
</ResponseField>

<div id="methods">
  ## メソッド
</div>

<div id="method-usercreate">
  ### <Badge color="blue" size="lg" shape="rounded">メソッド</Badge> User.create()
</div>

```python
api: 'Api',
email: 'str',
admin: 'bool | None' = False
```

新しいユーザーを作成します。

これは内部メソッドです。代わりに `wandb.Api` の `create_user()` メソッドを使用してください。

<div id="arguments">
  ##### 引数
</div>

<ResponseField name="api" type="Api">
  ユーザーの作成に使用する API インスタンス。
</ResponseField>

<ResponseField name="email" type="str">
  ユーザーのメールアドレス。
</ResponseField>

<ResponseField name="admin" type="bool | None">
  このユーザーをグローバルインスタンス管理者にするかどうか。
</ResponseField>

<div id="method-userdelete_api_key">
  ### <Badge color="blue" size="lg" shape="rounded">メソッド</Badge> User.delete_api_key()
</div>

```python
self,
api_key: 'str'
```

ユーザーのAPIキーを削除します。

キーの所有者または管理者のみが削除できます。

<div id="arguments-2">
  ##### 引数
</div>

<ResponseField name="api_key" type="str">
  削除するAPIキーの名前。`api_keys` プロパティから返される名前のいずれかを使用してください。
</ResponseField>
