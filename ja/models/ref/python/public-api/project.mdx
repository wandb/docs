### <Badge color="blue" size="lg" shape="rounded">method</Badge> Project.collections()

```python
self,
filters: 'Mapping[str, Any] | None' = None,
order: 'str | None' = None,
per_page: 'int' = 50
```

このprojectに関連付けられているすべてのアーティファクトコレクションを返します。

<div id="arguments">
  ##### 引数
</div>

<ResponseField name="filters" type="Mapping[str, Any] | None">
  クエリに適用するフィルターのオプションのマッピング。
</ResponseField>

<ResponseField name="order" type="str | None">
  結果の順序を指定するオプションの文字列です。先頭に `+` を付けると昇順 (デフォルト) 、`-` を付けると降順になります。
</ResponseField>

<ResponseField name="per_page" type="int">
  1 ページあたりに取得するアーティファクトコレクションの数です。デフォルトは 50 です。
</ResponseField>
