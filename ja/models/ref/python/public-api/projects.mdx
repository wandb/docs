  ## <Badge color="yellow" size="lg" shape="rounded">クラス</Badge> wandb.apis.public.Projects

`Project` オブジェクトの遅延イテレーター。

entity が作成して保存したプロジェクトにアクセスするためのイテラブルなインターフェース。

```python
service_api: 'ServiceApi',
entity: 'str',
per_page: 'int' = 50
```

<div id="args">
  ## 引数
</div>

<ResponseField name="service_api" type="ServiceApi">
  W&amp;B をクエリするために使用するサービス API。
</ResponseField>

<ResponseField name="entity" type="str">
  プロジェクト を所有する entity。
</ResponseField>

<ResponseField name="per_page" type="int">
  API リクエストごとに取得する プロジェクト の数。
</ResponseField>

<div id="examples">
  ## 例
</div>

```python
from wandb.apis.public.api import Api

# この entity に属するプロジェクトを検索する
projects = Api().projects(entity="entity")

# ファイルを反復処理する
for project in projects:
    print(f"Project: {project.name}")
    print(f"- URL: {project.url}")
    print(f"- Created at: {project.created_at}")
    print(f"- Is benchmark: {project.is_benchmark}")
```
