<div id="properties">
  ## プロパティ
</div>

<ResponseField name="allow_all_artifact_types" type="bool">
  Registry ですべてのアーティファクト タイプが許可されているかどうかを返します。

  `True` の場合、任意のタイプのアーティファクトを追加できます。`False` の場合、アーティファクトは
  `artifact_types` にリストされているタイプに制限されます。
</ResponseField>

<ResponseField name="artifact_types" type="AddOnlyArtifactTypesList">
  Registry で許可されているアーティファクト タイプを返します。

  `allow_all_artifact_types` が `True` の場合、`artifact_types` には
  以前に保存されたタイプ、または現在 Registry で使用されているタイプが反映されます。
  `allow_all_artifact_types` が `False` の場合、アーティファクトは
  `artifact_types` のタイプに制限されます。

  注:
  以前に保存されたアーティファクト タイプは削除できません。
</ResponseField>

<ResponseField name="created_at" type="str">
  Registry が作成された時点のタイムスタンプです。
</ResponseField>

<ResponseField name="description" type="str | None">
  Registry の説明です。
</ResponseField>

<ResponseField name="entity" type="str">
  Registry の組織エンティティです。
</ResponseField>

<ResponseField name="full_name" type="str">
  `wandb-registry-` 接頭辞を含む Registry の完全名です。
</ResponseField>

<ResponseField name="id" type="str">
  この Registry の一意の ID です。
</ResponseField>

<ResponseField name="internal_id" type="str | None">
  取得されている場合、この Registry の基盤となる project の GraphQL `internalId` です。

  これは base64 エンコードされたグローバル ID です。デコードすると、
  `Project:123` または `ProjectInternalId:123` のようになります。
</ResponseField>

<ResponseField name="name" type="str">
  `wandb-registry-` 接頭辞を除いた Registry の名です。
</ResponseField>

<ResponseField name="organization" type="str">
  Registry の組織名です。
</ResponseField>

<ResponseField name="path" type="list[str]">
  説明はありません。
</ResponseField>

<ResponseField name="updated_at" type="str | None">
  Registry が最後に更新された時点のタイムスタンプです。
</ResponseField>

<ResponseField name="visibility" type="The visibility level.">
  Registry の可視性です。
</ResponseField>

### <Badge color="blue" size="lg" shape="rounded">メソッド</Badge> Registry.add_members()

```python
self, *members: 'User | UserMember | Team | TeamMember | str'
```

この Registry にUsersまたはTeamsを追加します。

<div id="arguments">
  ##### 引数
</div>

<ResponseField name="members" type="User | UserMember | Team | TeamMember | str">
  Registry に追加するUsersまたはTeams。`User` オブジェクト、`Team` オブジェクト、またはそれらの文字列IDを受け付けます。
</ResponseField>

<div id="raises">
  ##### 送出される例外
</div>

* `TypeError`: 引数としてメンバーが1つも渡されなかった場合。
* `ValueError`: ユーザーまたはチームのIDを推定または解析できない場合。

<div id="examples">
  ##### 例
</div>

```python
import wandb

api = wandb.Api()

# 既存のレジストリを取得する
registry = api.registry(name="my-registry", organization="my-org")

user1 = api.user(username="some-user")
user2 = api.user(username="other-user")
registry.add_members(user1, user2)

my_team = api.team(name="my-team")
registry.add_members(my_team)
```

### <Badge color="blue" size="lg" shape="rounded">メソッド</Badge> Registry.update_member()

```python
self,
member: 'User | UserMember | Team | TeamMember | str',

```

このRegistry内のメンバー (ユーザーまたはチーム) のロールを更新します。

<div id="arguments">
  ##### 引数
</div>

<ResponseField name="member" type="User | UserMember | Team | TeamMember | str">
  ロールを更新する対象のユーザーまたはチームです。`User` オブジェクト、`Team` オブジェクト、またはそれらの文字列 ID を受け取ります。
</ResponseField>

<ResponseField name="role" type="MemberRole | str">
  メンバーに割り当てる新しいロールです。次のいずれかを指定できます。

  * &quot;admin&quot;
  * &quot;member&quot;
  * &quot;viewer&quot;
  * &quot;restricted&#95;viewer&quot; (W&amp;B サーバーでサポートされる場合)
</ResponseField>

<div id="raises">
  ##### 送出される例外
</div>

* `ValueError`: ユーザーまたはチームの ID を特定できない場合。

<div id="examples">
  ##### 例
</div>

Registry のすべてのユーザーを管理者にする

```python
import wandb

api = wandb.Api()

# 既存のRegistryを取得する
registry = api.registry(name="my-registry", organization="my-org")

for member in registry.user_members():
    registry.update_member(member.user, role="admin")
```
