<div id="attributes">
  ## 属性
</div>

* `paths`: ダウンロードされた history ファイルのパス。
* `errors`: ダウンロードに失敗したファイルについて、ファイルパスをエラーメッセージに対応付けた辞書。すべてのダウンロードが成功した場合は None。
* `contains_live_data`: run に、まだ parquet ファイルにエクスポートされていないライブデータが含まれているかどうか。
