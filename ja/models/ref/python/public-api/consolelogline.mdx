<div id="attributes">
  ## 属性
</div>

* `number`: 0 から始まる、run のコンソールログ内の行の位置です。
* `timestamp`: 行が取得された時刻です。タイムゾーン情報を含む UTC datetime です。backend がその行の時刻を記録していない場合、または予期しない形式で送信した場合は None です。
* `level`: 行の重大度です。stderr に書き込まれた行の場合は `"error"`、それ以外の場合は空です。
* `label`: 複数のプロセスが同じ run に書き込む場合に、行を書き込んだプロセスを識別するラベルです。shared mode の `x_label` 設定で指定します。単一ライターの run では空です。
* `content`: 行のテキストです。
