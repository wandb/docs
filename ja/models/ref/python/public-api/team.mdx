## <Badge color="yellow" size="lg" shape="rounded">クラス</Badge> wandb.apis.public.Team

W&amp;B のチームを表すクラス。

このクラスは、チームの作成、メンバーの招待、サービスアカウントの管理など、W&amp;B のチームを管理するための method を提供します。チーム属性を扱うために Attrs を継承します。

```python
(service_api: 'ServiceApi',
name: 'str',
attrs: 'Mapping[str, Any] | None' = None)
```

<div id="args">
  ## 引数
</div>

<ResponseField name="service_api" type="ServiceApi">
  W&amp;B のクエリに使用するサービス API インスタンス。
</ResponseField>

<ResponseField name="name" type="str">
  チーム名
</ResponseField>

<ResponseField name="attrs" type="Mapping[str, Any] | None">
  省略可能なチーム属性の辞書
</ResponseField>

<div id="examples">
  ## 例
</div>

チームを検索して、メンバーを招待します。

```python
import wandb

api = wandb.Api()
team = api.team("my-team")
team.invite("user@example.com")
```

チームを作成し、サービスアカウントを追加します。

```python
import wandb

api = wandb.Api()
team = api.create_team("my-team")
team.create_service_account("CI service account")
```
