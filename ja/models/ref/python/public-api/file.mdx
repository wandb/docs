  ## <Badge color="yellow" size="lg" shape="rounded">クラス</Badge> wandb.apis.public.File
</div>

W&amp;B に保存された file。

W&amp;B に保存された単一の file を表します。file のメタデータにもアクセスできます。file は特定の run に関連付けられており、テキストファイル、モデルの重み、データセット、可視化、その他の Artifacts などを含めることができます。file のダウンロード、削除、プロパティへのアクセスが可能です。

特定の run にログされた特定の file を絞り込むには、辞書で 1 つ以上の属性を指定します。次のキーを使用して検索できます。

* id (str): file を含む run の ID
* name (str): file名
* url (str): file へのパス
* direct&#95;url (str): バケット内の file へのパス
* sizeBytes (int): fileサイズ (バイト単位)
* md5 (str): file の md5
* mimetype (str): file の MIME タイプ
* updated&#95;at (str): 最終更新のタイムスタンプ
* path&#95;uri (str): バケット内の file へのパス。現在は S3 オブジェクトと参照fileでのみ利用可能です

wandb サーバーから、run が以前に保存した file をダウンロードします。

<div id="arguments">
  ##### 引数
</div>

<ResponseField name="root" type="str">
  file の保存先となるローカルディレクトリ。デフォルトは現在の作業ディレクトリ (`"."`) です。
</ResponseField>

<ResponseField name="replace" type="bool">
  `True` の場合、ローカルfileが存在するとダウンロード時に上書きします。デフォルトは `False` です。
</ResponseField>

<ResponseField name="exist_ok" type="bool">
  `True` の場合、file がすでに存在していても `ValueError` を発生させず、`replace=True` でない限り再ダウンロードもしません。デフォルトは `False` です。
</ResponseField>

<ResponseField name="api" type="Api | None">
  指定した場合、file のダウンロードに使用する `Api` インスタンス。
</ResponseField>
