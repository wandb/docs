  ## <Badge color="blue" size="lg" shape="rounded">関数</Badge> wandb.plot.histogram()
</div>

W&amp;B 表 からヒストグラムチャートを作成します。

```python
table: 'wandb.Table',
value: 'str',
title: 'str' = '',
split_table: 'bool' = False
```

<div id="args">
  ## 引数
</div>

<ResponseField name="table" type="wandb.Table">
  ヒストグラム用のデータを含む W&amp;B 表。
</ResponseField>

<ResponseField name="value" type="str">
  ビン軸 (x軸) のラベル。
</ResponseField>

<ResponseField name="title" type="str">
  ヒストグラムプロットのタイトル。
</ResponseField>

<ResponseField name="split_table" type="bool">
  表を W&amp;B UI の別セクションとして分割するかどうか。`True` の場合、表は &quot;Custom Chart Tables&quot; という名前のセクションに表示されます。デフォルトは `False` です。
</ResponseField>

<div id="returns">
  ## 戻り値
</div>

`CustomChart`: W&amp;B にログできるカスタムチャートオブジェクト。チャートをログするには、これを `wandb.log()` に渡します。

<div id="examples">
  ## 例
</div>

```python
import math
import random
import wandb

# ランダムデータを生成する
data = [[i, random.random() + math.sin(i / 10)] for i in range(100)]

# W&B 表を作成する
table = wandb.Table(
    data=data,
    columns=["step", "height"],
)

# ヒストグラムプロットを作成する
histogram = wandb.plot.histogram(
    table,
    value="height",
    title="My Histogram",
)

# ヒストグラムプロットを W&B にログする
with wandb.init(...) as run:
    run.log({"histogram-plot1": histogram})
```
