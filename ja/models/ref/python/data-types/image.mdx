<div id="class-wandbimage">
  ## <Badge color="yellow" size="lg" shape="rounded">クラス</Badge> wandb.Image
</div>

W&amp;B に画像をログするクラスです。

```python
data_or_path: 'ImageDataOrPathType',
mode: 'str | None' = None,
caption: 'str | None' = None,
grouping: 'int | None' = None,
classes: 'Classes | Sequence[dict] | None' = None,
boxes: 'dict[str, BoundingBoxes2D] | dict[str, dict] | None' = None,
masks: 'dict[str, ImageMask] | dict[str, dict] | None' = None,
file_type: 'str | None' = None
```

<div id="args">
  ## 引数
</div>

<ResponseField name="data_or_path" type="ImageDataOrPathType">
  画像データの NumPy array / pytorch tensor、
  PIL image object、または画像ファイルへのパスを受け付けます。NumPy
  array または pytorch tensor を指定した場合、
  画像データは指定したファイルタイプで保存されます。
  値はすでに &#91;0, 255&#93; の範囲内にあることが想定されます。

  * pytorch tensor は (channel, height, width) 形式である必要があります
  * NumPy array は (height, width, channel) 形式である必要があります
</ResponseField>

<ResponseField name="mode" type="str | None">
  画像の PIL mode です。一般的なものは &quot;L&quot;、&quot;RGB&quot;、&quot;RGBA&quot; です。詳細については、Full Pillow docs を参照してください [https://pillow.readthedocs.io/en/stable/handbook/concepts.html#modes](https://pillow.readthedocs.io/en/stable/handbook/concepts.html#modes)
</ResponseField>

<ResponseField name="caption" type="str | None">
  画像の表示ラベルです。
</ResponseField>

<ResponseField name="grouping" type="int | None">
  画像のグループ化番号です。
</ResponseField>

<ResponseField name="classes" type="Classes | Sequence[dict] | None">
  画像のクラス情報の list で、バウンディングボックスや画像マスクのラベル付けに使用されます。
</ResponseField>

<ResponseField name="boxes" type="dict[str, BoundingBoxes2D] | dict[str, dict] | None">
  画像のバウンディングボックス情報を含む辞書です。参照 [https://docs.wandb.ai/models/ref/python/data-types/boundingboxes2d](https://docs.wandb.ai/models/ref/python/data-types/boundingboxes2d)
</ResponseField>

<ResponseField name="masks" type="dict[str, ImageMask] | dict[str, dict] | None">
  画像のマスク情報を含む辞書です。参照 [https://docs.wandb.ai/models/ref/python/data-types/imagemask](https://docs.wandb.ai/models/ref/python/data-types/imagemask)
</ResponseField>

<ResponseField name="file_type" type="str | None">
  画像の保存ファイルタイプです。`data_or_path` が画像ファイルへのパスである場合、このパラメーターは効果を持ちません。
</ResponseField>

<div id="properties">
  ## プロパティ
</div>

  説明は提供されていません。
</ResponseField>
