<div id="method-moleculefrom_rdkit">
  ### <Badge color="blue" size="lg" shape="rounded">メソッド</Badge> Molecule.from_rdkit()
</div>

```python
data_or_path: 'RDKitDataType',
caption: 'str | None' = None,
convert_to_3d_and_optimize: 'bool' = True,
mmff_optimize_molecule_max_iterations: 'int' = 200
```

RDKit がサポートする file/オブジェクト タイプを wandb.Molecule に変換します。

<div id="arguments">
  ##### 引数
</div>

<ResponseField name="data_or_path" type="RDKitDataType">
  (string, rdkit.Chem.rdchem.Mol) Molecule は、ファイル名または `rdkit.Chem.rdchem.Mol` オブジェクトから初期化できます。
</ResponseField>

<ResponseField name="caption" type="str | None">
  (string) 表示用に分子に関連付けられたキャプションです。
</ResponseField>

<ResponseField name="convert_to_3d_and_optimize" type="bool">
  (bool) 3D 座標を持つ `rdkit.Chem.rdchem.Mol` に変換します。これは計算コストの高い処理であり、複雑な分子では時間がかかる場合があります。
</ResponseField>

SMILES文字列をwandb.Moleculeに変換します。

<div id="arguments-2">
  ##### 引数
</div>

<ResponseField name="data" type="str">
  SMILES 文字列。
</ResponseField>

<ResponseField name="caption" type="str | None">
  分子に関連付けられた表示用キャプション。
</ResponseField>

<ResponseField name="sanitize" type="bool">
  RDKit の定義に基づいて、分子が化学的に妥当かどうかを確認します。
</ResponseField>

<ResponseField name="convert_to_3d_and_optimize" type="bool">
  3D 座標を持つ `rdkit.Chem.rdchem.Mol` に変換します。これは計算負荷の高い操作であり、複雑な分子では時間がかかる場合があります。
</ResponseField>
