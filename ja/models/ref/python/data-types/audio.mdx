```python
(data_or_path: 'str | pathlib.Path | list | np.ndarray',
```

<div id="args">
  ## 引数
</div>

<ResponseField name="data_or_path" type="str | pathlib.Path | list | np.ndarray">
  オーディオファイルへのパス、またはオーディオデータの NumPy 配列。
</ResponseField>

<ResponseField name="sample_rate" type="int | None">
  サンプルレート。生のオーディオデータの NumPy 配列を渡す場合は必須です。
</ResponseField>

<ResponseField name="caption" type="str | None">
  オーディオとともに表示するキャプション。
</ResponseField>
