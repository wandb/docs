## <Badge color="yellow" size="lg" shape="rounded">クラス</Badge> wandb.Html

W&amp;B に HTML コンテンツをログするための W&amp;B クラスです。

```python
data: 'str | pathlib.Path | TextIO',
inject: 'bool' = True,
data_is_not_path: 'bool' = False
```

<div id="args">
  ## 引数
</div>

<ResponseField name="data" type="str | pathlib.Path | TextIO">
  拡張子が &quot;.html&quot; のファイルへのパスを指定する文字列、または生の HTML を含む文字列もしくは IO オブジェクト。
</ResponseField>

<ResponseField name="inject" type="bool">
  HTML オブジェクトにスタイルシートを追加します。False に設定すると、HTML は変更せずそのまま渡されます。
</ResponseField>

<ResponseField name="data_is_not_path" type="bool">
  False に設定すると、data はファイルへのパスとして扱われます。
</ResponseField>
