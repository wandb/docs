---
title: データファイルを扱う
---

ノートブックのサイドバーを使用すると、ノートブックのサンドボックス内のファイルを管理したり、リモートのデータソースに接続したりできます。また、[W&amp;B Artifacts](/ja/models/artifacts/download-and-use-an-artifact) をノートブックにダウンロードすることもできます。

<div id="notebook-storage-and-persistence">
  ## ノートブックのストレージと永続性
</div>

各ノートブックは一時的な [CoreWeave サンドボックス](https://docs.coreweave.com/products/sandboxes) 上で実行されます。作成、アップロード、またはダウンロードしたファイルは、ノートブックのサイドバーの **Files** に表示され、サンドボックス内にのみ存在します。

接続済みのオブジェクトストレージ、データベース、データカタログは **Remote storage** に表示されます。

<Warning>
  ノートブックのサンドボックス内のファイルは一時的なものです。保持したいファイルは、サンドボックスがリセットまたは削除される前に永続ストレージへコピーしてください。
</Warning>

<div id="view-files">
  ## ファイルの表示
</div>

ノートブックのサイドバーでファイルを表示するには、次の手順に従います。

1. ノートブックのサイドバーで **View files** (<Icon icon="folder-tree" iconType="solid" />) を選択します。
2. 以下のセクションのいずれかを展開します。
   * **Files**: ノートブックのサンドボックス内のファイルを表示します。
   * **Remote storage**: 接続済みのリモートデータソースを参照します。

<div id="manage-files-and-folders">
  ## ファイルとフォルダーの管理
</div>

ファイルまたはフォルダーをアップロードまたは作成するには、次の手順を実行します。

1. ノートブックのサイドバーで、**View files** (<Icon icon="folder-tree" iconType="solid" />) を選択します。
2. **Files** を展開します。
3. 次のいずれかの操作を選択します。
   * **Upload file** (<Icon icon="arrow-up-from-bracket" iconType="solid" />) : 既存のファイルをサンドボックスにアップロードします。
   * **Add file** (<Icon icon="file-plus" iconType="solid" />) : ファイルを作成します。
   * **Add folder** (<Icon icon="folder-plus" iconType="solid" />) : フォルダーを作成します。

<div id="download-a-wb-artifact">
  ## W&amp;B アーティファクトをダウンロードする
</div>

ノートブック内で [W&amp;B アーティファクトをダウンロードして使用する](/ja/models/artifacts/download-and-use-an-artifact)ことができます。ダウンロードしたファイルは、ノートブックのサンドボックスに保存されます。

たとえば、次のコードは W&amp;B Registry からモデル アーティファクトをダウンロードします。

```python
import wandb

REGISTRY_NAME = "Zoo"
MODEL_COLLECTION_NAME = "Classifier_Models"
MODEL_VERSION = 0

artifact_name = (
    f"wandb-registry-{REGISTRY_NAME}/"
    f"{MODEL_COLLECTION_NAME}:v{MODEL_VERSION}"
)

with wandb.init() as run:
    artifact = run.use_artifact(artifact_name)
    artifact_path = artifact.download()
    print(artifact_path)
```

このコマンドは、ダウンロードしたアーティファクトのディレクトリへのパスを返します。例:

```text
/workspace/artifacts/zoo-pznwefqb:v0
```

ダウンロードしたアーティファクトは、`artifacts` ディレクトリ配下に配置されます。
