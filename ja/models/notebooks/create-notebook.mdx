{/* ## 既存のノートブックをインポートする */}

チームの 概要ページ または project の Workspace で、ノートブックの作成、リネーム、複製、削除を行えます。

## 新しいノートブックを作成する {#create-a-new-notebook}

既存の project またはチームの Workspace にノートブックを作成します。

<Tabs>
  <Tab title="チーム概要">
    1. チームの概要ページにアクセスします。
    2. **Notebooks** タブを選択します。
    3. **Create notebook** を選択します。
    4. **Project** ドロップダウンから、ノートブックを作成する project を選択します。新しい project を使用する場合は、**Create a new project** を選択します。
  </Tab>

  <Tab title="Project">
    1. Workspace にアクセスします。
    2. project のサイドバーから **Notebooks** を選択します。
    3. **Create notebook** を選択します。
  </Tab>
</Tabs>

## ノートブックをリネームする {#rename-a-notebook}

既存のノートブックは、チームの概要ページまたは Workspace からリネームできます。

<Tabs>
  <Tab title="チーム概要">
    1. チームの概要ページにアクセスします。
    2. **Notebooks** タブを選択します。
    3. **アクション (<Icon icon="ellipsis" iconType="solid" />)** メニューを開き、**Rename notebook** を選択します。
    4. ノートブックの新しい名前を入力し、**Save** を選択します。
  </Tab>

  <Tab title="project">
    1. Workspace にアクセスします。
    2. project のサイドバーから **Notebooks** を選択します。
    3. **アクション (<Icon icon="ellipsis" iconType="solid" />)** メニューを開き、**Rename notebook** を選択します。
    4. ノートブックの新しい名前を入力し、**Save** を選択します。
  </Tab>
</Tabs>

## ノートブックを複製する {#duplicate-a-notebook}

ノートブックを複製して、同じ project 内または別の project にコピーを作成できます。複製したノートブックには、元のノートブック名の先頭に `Copy` を付けた名前が設定されます。

<Tabs>
  <Tab title="チーム概要">
    1. チームの概要ページにアクセスします。
    2. **Notebooks** タブを選択します。
    3. **アクション (<Icon icon="ellipsis" iconType="solid" />)** メニューを開き、**Make a copy** を選択します。
  </Tab>

  <Tab title="Project">
    1. Workspace にアクセスします。
    2. project のサイドバーから **Notebooks** を選択します。
    3. **アクション (<Icon icon="ellipsis" iconType="solid" />)** メニューを開き、**Make a copy** を選択します。
  </Tab>
</Tabs>

## ノートブックを削除する {#delete-a-notebook}

チームの概要ページまたは Workspace からノートブックを削除します。

<Tabs>
  <Tab title="チーム概要">
    1. チームの概要ページにアクセスします。
    2. **Notebooks** タブを選択します。
    3. **アクション (<Icon icon="ellipsis" iconType="solid" />)** メニューを開き、**Delete notebook** を選択します。
    4. **Delete notebook** を選択します。
  </Tab>

  <Tab title="project">
    1. Workspace にアクセスします。
    2. project のサイドバーから **Notebooks** を選択します。
    3. **アクション (<Icon icon="ellipsis" iconType="solid" />)** メニューを開き、**Delete notebook** を選択します。
    4. **Delete notebook** を選択します。
  </Tab>
</Tabs>
