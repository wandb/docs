以下のガイドでは、最初のノートブックの作成からトレーニング experiment の実行まで、W&amp;B ノートブックの使い始め方を説明します。

## 最初のノートブックを作成する {#create-your-first-notebook}

1. project の Workspace にアクセスします。
2. プロジェクトのサイドバーで **Notebooks** を選択します。
3. **Create notebook** をクリックします。

詳細については、[ノートブックの作成と管理](/ja/models/notebooks/create-notebook)を参照してください。

## トレーニング experiment を実行する {#run-a-training-experiment}

このモックのトレーニングスクリプトは、シミュレートした accuracy と損失のメトリクスを W&amp;B にログします。以下のコードを Python スクリプトまたはノートブックのセルにコピー＆ペーストして実行してください。

1. **Python** を選択して、新しいコードセルを作成します。

2. 以下のコードをセルにコピー＆ペーストします。

   ```python
   import random
   import wandb

   PROJECT = "your-project-name"

   # ハイパーパラメーターの辞書
   config = {
       'epochs' : 10,
       'lr' : 0.01
   }

   with wandb.init(project=PROJECT, config=config) as run:
       offset = random.random() / 5
       print(f"lr: {config['lr']}")
       
       # トレーニング run をシミュレートする
       for epoch in range(2, config['epochs']):
           acc = 1 - 2**-config['epochs'] - random.random() / config['epochs'] - offset
           loss = 2**-config['epochs'] + random.random() / config['epochs'] + offset
           print(f"epoch={config['epochs']}, accuracy={acc}, loss={loss}")
           run.log({"accuracy": acc, "loss": loss})
   ```

3. macOS では **Command + Enter**、Windows または Linux では **Ctrl+Enter** を押します。あるいは、セルの横にある **Play** (<Icon icon="circle-play" iconType="solid" />) をクリックします。

## experiment を表示する {#view-your-experiment}

トレーニング experiment 中にログされた accuracy と損失のメトリクスを表示します。

1. プロジェクトのサイドバーから **Workspace** を選択します。
2. Workspace 内の runs と可視化を確認します。[runs](/ja/models/runs) のリストには、project にログされた各 run とその詳細が表示されます。[Workspace panels](/ja/models/app/features/panels) には、各 run 中にログされたメトリクスの可視化が表示されます。

## ノートブックを保存する {#save-the-notebook}

W&amp;B はノートブックを [W&amp;B Artifact](/ja/models/artifacts) として保存し、30 秒ごと、およびノートブックのコンピュートセッションが停止したときに、変更を新しい [Artifact バージョン](/ja/models/artifacts/create-a-new-artifact-version) として自動的に保存します。

最新の変更をすぐに保存するには、次のいずれかの方法を使用します。

* macOS では **Command+S**、Windows または Linux では **Ctrl+S** を押します。
* ノートブックのフッターで **Save** (<Icon icon="floppy-disk" iconType="solid" />) をクリックします。
