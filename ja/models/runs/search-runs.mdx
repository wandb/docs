---
title: "run を検索する"
description: "プロジェクトの Runs 表 または Workspace で、run 名または ID を使って特定の run を検索する方法を説明します。"
---

プロジェクトの Runs 表 または Workspace 内の検索ボックスを使用して、特定の[run 名または ID による run](/ja/models/runs/run-identifiers)を検索します。W&amp;B は、[Google RE2 構文](https://github.com/google/re2/wiki/Syntax)を使用する正規表現として検索クエリを解釈します。

設定値、メトリクス、タグで run をフィルターする方法については、[run をフィルターする](/ja/models/runs/filter-runs)を参照してください。

<div id="search-for-a-run-by-name-or-id">
  ## run 名または ID で run を検索する
</div>

1. プロジェクトのサイドバーで、**Runs** または **Workspace** を選択します。
2. Runs 表の上部にある検索ボックスを選択します。
3. run 名、run ID、または RE2 構文を使用する正規表現を入力します。

<div id="turn-off-regular-expressions-search">
  ## 正規表現検索を無効にする
</div>

正規表現ではなく、完全一致するテキスト文字列を検索するには、次の手順に従います。

1. プロジェクトのサイドバーで、**Runs** または **Workspace** を選択します。
2. Runs 表の上部にある検索ボックスを選択します。
3. RegEx トグル (`.*`) を無効にします。正規表現検索が無効な場合、トグルはグレーで表示されます。
