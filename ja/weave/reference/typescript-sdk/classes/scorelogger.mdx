ScoreLogger は単一の予測のスコアリングを管理します。
EvaluationLogger.logPrediction() によって返されます。

定義箇所: [src/evaluationLogger.ts:330](https://github.com/wandb/weave/blob/8c5f077eb11c42b84000726ff20504abc728d3fb/sdks/node/src/evaluationLogger.ts#L330)

<div id="example">
  ## 例
</div>

```ts twoslash
// @noErrors
const pred = await ev.logPrediction(example, output);
await pred.logScore("accuracy", 0.95);
await pred.logScore("relevance", 0.8);
await pred.finish(); // 予測を確定する
```

<div id="finish">
  ### finish()
</div>

> **finish**(): `Promise`&lt;`void`&gt;

予測のスコアリング処理を終了します。
蓄積されたscoresを用いて、`predict_and_score` call を完了します。
段階的な集計を更新し、メモリを解放します。
