ScoreLogger は単一の予測のスコアリングを管理します。
EvaluationLogger.logPrediction() によって返されます。

## 例 {#example}

```ts twoslash
// @noErrors
const pred = await ev.logPrediction(example, output);
await pred.logScore("accuracy", 0.95);
await pred.logScore("relevance", 0.8);
await pred.finish(); // 予測を確定する
```

### isFinishCalled {#isfinishcalled}

#### Get Signature {#get-signature}

> **get** **isFinishCalled**(): `boolean`

finish() が呼び出されたかどうかを確認します。
EvaluationLogger が未完了の予測を検出するために使用します。

##### 戻り値 {#returns-2}

`boolean`

## Methods {#methods}

### finish() {#finish}

> **finish**(): `Promise`&lt;`void`&gt;

予測のスコアリング処理を終了します。
蓄積されたscoresを用いて、`predict_and_score` call を確定します。
段階的な集計を更新し、メモリを解放します。

#### 戻り値 {#returns-3}

`Promise`&lt;`void`&gt;

***

### logScore() {#logscore}

> **logScore**(`scorerName`, `score`): `Promise`&lt;`void`&gt;

この予測のスコアをログします。
predict&#95;and&#95;score の子として Scorer Call を作成します。

#### パラメーター {#parameters-2}

<ParamField path="scorerName" type="string" required>
  scorer名 (例: &quot;accuracy&quot;, &quot;f1&#95;score&quot;)
</ParamField>

<ParamField path="score" type="any" required>
  スコアの値
</ParamField>

#### 戻り値 {#returns-4}

`Promise`&lt;`void`&gt;
