簡単に保存でき、自動でバージョン管理される Dataset オブジェクト

定義元: [src/dataset.ts:52](https://github.com/wandb/weave/blob/8c5f077eb11c42b84000726ff20504abc728d3fb/sdks/node/src/dataset.ts#L52)

<div id="example">
  ## 例
</div>

```ts twoslash
// @noErrors
// データセットを作成する
const dataset = new Dataset({
  id: 'grammar-dataset',
  rows: [
    { id: '0', sentence: "He no likes ice cream.", correction: "He doesn't like ice cream." },
    { id: '1', sentence: "She goed to the store.", correction: "She went to the store." },
    { id: '2', sentence: "They plays video games all day.", correction: "They play video games all day." }
  ]
})

// 特定のサンプルにアクセスする
const exampleLabel = dataset.getRow(2).sentence;

// データセットを保存する
const ref = await dataset.save()
```
