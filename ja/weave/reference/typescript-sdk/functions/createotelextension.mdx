```ts
createOtelExtension(opts?: object): (pi) => void
```

<GitHubLink url="https://github.com/wandb/weave/blob/7c9efdc9fe05ffcaf2430dd652ef9bc5b3ffdfaa/sdks/node/src/integrations/piCodingAgent.ts#L658" />

GenAI のセマンティック規約に準拠し、エージェントのライフサイクル全体にわたって OTEL スパンを送出する piコーディングエージェント拡張機能を作成します。

`weave.init(...)` が呼び出されている場合、スパンは自動的に Weave トレースサーバーの `/agents/otel/v1/traces` にエクスポートされます。そうでない場合は、`opts` にカスタム `tracer` を渡してください。

  <Expandable title="プロパティ" defaultOpen>
    <ParamField path="captureContent" type="boolean" />

    <ParamField path="tracer" type="Tracer" />
  </Expandable>
</ParamField>

## 戻り値 {#returns}

(`pi`) =&gt; `void`

## 例 {#example}

```typescript twoslash
// @noErrors
const resourceLoader = new DefaultResourceLoader({
  extensionFactories: [createOtelExtension()],
});
```
