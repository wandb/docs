```ts
login(apiKey: string, host?: string): Promise<void>
```

<GitHubLink url="https://github.com/wandb/weave/blob/7c9efdc9fe05ffcaf2430dd652ef9bc5b3ffdfaa/sdks/node/src/clientApi.ts#L26" />

指定されたAPIキーを使用して、Weights &amp; Biases (W&amp;B) にログインします。
この関数は、今後の使用に備えて認証情報を`netrc`ファイルに保存しようとしますが、
ファイルシステムに書き込めない場合でも処理は継続されます。

<div id="parameters">
  ## パラメーター
</div>

<ParamField path="apiKey" type="string" required>
  W&amp;B APIキー。
</ParamField>

<ParamField path="host" type="string">
  (省略可能) ホスト名 (通常は、カスタム W&amp;B サーバーを使用している場合にのみ必要です) 。
</ParamField>

<div id="returns">
  ## 戻り値
</div>

`Promise`&lt;`void`&gt;

<div id="throws">
  ## 例外
</div>

APIキーが指定されていない場合、またはWeave trace serverへの接続を確認できない場合。
