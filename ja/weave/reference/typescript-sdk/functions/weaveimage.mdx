```ts
weaveImage(options: object): WeaveImage
```

新しい WeaveImage オブジェクトを作成します

<div id="parameters">
  ## パラメーター
</div>

<ParamField path="options" type="object" required>
  このメディアタイプのオプションです

  * data: Buffer 形式の生の画像データ
  * imageType: (任意) 画像フォーマット: &#39;png&#39; (デフォルト)、&#39;jpeg&#39;、&#39;webp&#39;。
    公開時、保存される file の名前は常に image.png になります

</ParamField>
