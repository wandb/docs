```ts
startTurn(opts?: TurnInit = {}): Turn
```

<GitHubLink url="https://github.com/wandb/weave/blob/7c9efdc9fe05ffcaf2430dd652ef9bc5b3ffdfaa/sdks/node/src/genai/api.ts#L54" />

新しいターンを開始します。Conversation がアクティブな場合、ターンはその
`conversationId` を引き継ぎます。アクティブでない場合、ターンには conversation ID がありません。

<div id="parameters">
  ## パラメーター
</div>

<ParamField path="opts" type="TurnInit = {}">
  [`TurnInit`](../interfaces/turninit) を参照してください。
</ParamField>

<div id="returns">
  ## 戻り値
</div>

[`Turn`](../interfaces/turn)

<div id="examples">
  ## 例
</div>

```ts twoslash
// @noErrors
weave.startTurn();
```

```ts twoslash
// @noErrors
weave.startTurn({
  agentId: 'research-bot-prod',
  agentName: 'research-bot',
  agentDescription: 'Looks up facts on Wikipedia.',
  agentVersion: '1.4.2',
  model: 'gpt-4o',
  userMessage: 'What is the weather in Tokyo?',
  systemInstructions: ['You are a helpful weather bot.'],
  startTime: new Date('2026-05-29T10:00:00.000Z'),
});
```
