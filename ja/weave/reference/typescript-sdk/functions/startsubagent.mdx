```ts
startSubagent(opts: SubAgentInit): SubAgent
```

<GitHubLink url="https://github.com/wandb/weave/blob/7c9efdc9fe05ffcaf2430dd652ef9bc5b3ffdfaa/sdks/node/src/genai/api.ts#L137" />

SubAgent span を開始します。親の解決ルールは `startTool` と同じです。

<div id="parameters">
  ## パラメーター
</div>

<ParamField path="opts" type="SubAgentInit" required>
  [`SubAgentInit`](../interfaces/subagentinit) を参照してください。
</ParamField>

<div id="returns">
  ## 戻り値
</div>

[`SubAgent`](../interfaces/subagent)

<div id="examples">
  ## 例
</div>

```ts twoslash
// @noErrors
weave.startSubagent({name: 'critic'});
```

```ts twoslash
// @noErrors
weave.startSubagent({
  name: 'critic',
  model: 'gpt-4o',
  systemInstructions: ['Critique the proposed plan.'],
  startTime: new Date('2026-05-29T10:00:00.000Z'),
});
```
