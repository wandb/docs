> **startSubagent**(`opts`): [`SubAgent`](../interfaces/subagent)

```ts twoslash

weave.startSubagent({name: 'critic'});
```

```ts twoslash
// @noErrors
weave.startSubagent({
  name: 'critic',
  model: 'gpt-4o',
  systemInstructions: ['Critique the proposed plan.'],

});
```
