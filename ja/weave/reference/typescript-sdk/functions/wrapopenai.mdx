```ts
wrapOpenAI<T>(openai: T): T
```

<GitHubLink url="https://github.com/wandb/weave/blob/7c9efdc9fe05ffcaf2430dd652ef9bc5b3ffdfaa/sdks/node/src/integrations/openai.ts#L760" />

OpenAI API をラップし、OpenAI の Call に対する関数のトレースを有効にします。

## タイプパラメーター {#type-parameters}

<ParamField path="T" type="extends object" />

## パラメーター {#parameters}

<ParamField path="openai" type="T" required />

## 戻り値 {#returns}

`T`

## 例 {#example}

```ts twoslash
// @noErrors
const openai = wrapOpenAI(new OpenAI());
const result = await openai.chat.completions.create({
  model: 'gpt-3.5-turbo',
  messages: [{ role: 'user', content: 'Hello, world!' }]
});
```
