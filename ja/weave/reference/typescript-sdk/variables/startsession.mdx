> `const` **startSession**: (`opts`) =&gt; [`Conversation`](../interfaces/conversation) = `startConversation`

<GitHubLink url="https://github.com/wandb/weave/blob/7c9efdc9fe05ffcaf2430dd652ef9bc5b3ffdfaa/sdks/node/src/genai/api.ts#L33" />

新しい Conversation を開始し、現在の会話として設定します。
後続の `startTurn` 呼び出しでは、この会話が自動的に使用されます。

`attributes` を渡すと、会話によって生成されるすべての
span にカスタム (semconv 以外の) 属性を伝播できます。

<div id="examples">
  ## 例
</div>

```ts twoslash
// @noErrors
weave.startConversation({agentName: 'research-bot'});
```

```ts twoslash
// @noErrors
weave.startConversation({
  agentName: 'research-bot',
  conversationId: '019efa53-8a65-711c-b4c1-7c1cb72c0bb7',
  attributes: {'myagent.version': '1.23'},
});
```
