ツール の invocation です。ツール 名、引数、ツール-call id、結果を含む `execute_tool` span を出力します。string 型の引数と結果はそのまま記録され、それ以外の JSON 値はシリアライズされます。

`weave.startTool()` (または `turn.startTool()`、`llm.startTool()`) で作成し、`end()` で終了します。`end()` は結果とオプションの error metadata を受け入れます。

<div id="example">
  ## 例
</div>

```ts twoslash
// @noErrors
const tool = weave.startTool({name: 'get_weather', args: {city: 'Tokyo'}});
try {
  const result = await getWeather('Tokyo');
  tool.end({result});
} catch (error) {
  tool.end({error: error as Error, errorType: 'weather_error'});
  throw error;
}
```

<div id="addevent">
  ### ~~addEvent()~~
</div>

<Warning>
  **非推奨。** このデータは代わりに [setAttributes](#setattributes) で記録してください。
  OpenTelemetry では Span Event API (`Span.addEvent`) の段階的な廃止が進められています。この
  メソッドは引き続き動作し、既存の span イベントデータも引き続き有効です。
  [https://opentelemetry.io/blog/2026/deprecating-span-events/](https://opentelemetry.io/blog/2026/deprecating-span-events/) を参照してください。
</Warning>

> **addEvent**(`name`, `attributes?`, `startTime?`): `this`

名前付きイベントを span に追加します。コンテキストの圧縮、ツールループの検出、guardrail のトリガーなど、
span 以外のタイミングを記録する場合に便利です。`end()` の後に呼び出すと警告が出力され、
何も実行されません。OTel の `Span.addEvent` と同様の動作です。

<div id="end">
  ### end()
</div>

> **end**(`opts?`): `void`

任意の結果と error のタイプを記録し、span を閉じます。冪等です。
span を失敗としてマークするには `error` を渡し、終了時刻を過去に設定するには `endTime` を渡します。

> **setAttributes**(`attributes`): `this`
