ツールの invocation です。ツール名、JSON エンコードされた引数、ツール呼び出し ID、結果を含む `execute_tool` span を出力します。

`weave.startTool()` (または `turn.startTool()`、`llm.startTool()`) で作成し、`end()` で終了します。ツールの出力を span に記録するには、`end()` を呼び出す前に `result` を割り当てます。

定義元: [src/genai/tool.ts:43](https://github.com/wandb/weave/blob/8c5f077eb11c42b84000726ff20504abc728d3fb/sdks/node/src/genai/tool.ts#L43)

## 例

```ts twoslash
// @noErrors
const tool = weave.startTool({
  name: tc.function.name,
  args: tc.function.arguments,
  toolCallId: tc.id,
});
try {
  tool.result = await wikipediaSearch(JSON.parse(tc.function.arguments));
} finally {
  tool.end();
}
```

<div id="addevent">
  ### ~~addEvent()~~
</div>

<Warning>
  **非推奨。** このデータは代わりに [setAttributes](#setattributes) で記録してください。
  OpenTelemetry では Span Event API (`Span.addEvent`) の段階的な廃止が進められています。この
  メソッドは引き続き動作し、既存の span イベントデータも引き続き有効です。
  [https://opentelemetry.io/blog/2026/deprecating-span-events/](https://opentelemetry.io/blog/2026/deprecating-span-events/) を参照してください。
</Warning>

> **addEvent**(`name`, `attributes?`, `startTime?`): `this`

名前付きイベントを span に追加します。コンテキストの圧縮、ツールループの検出、guardrail のトリガーなど、
span 以外のタイミングを記録する場合に便利です。`end()` の後に呼び出すと警告が出力され、
何も実行されません。OTel の `Span.addEvent` と同様の動作です。

定義元: [src/genai/spanBase.ts:82](https://github.com/wandb/weave/blob/8c5f077eb11c42b84000726ff20504abc728d3fb/sdks/node/src/genai/spanBase.ts#L82)

> **end**(`opts?`): `void`

`result` を span にフラッシュして閉じます。冪等です。span を失敗としてマークするには `error` を渡し、終了時刻を過去に設定するには `endTime` を渡します。
