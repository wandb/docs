LLM Call。`gen_ai.*` 属性を含む `chat` span を生成します。

`weave.startLLM()` (または `turn.startLLM()`) で作成し、`end()` で終了します。非同期コンテキストでは、一度にアクティブにできる LLM は 1 つのみです。`startTool` / `startSubagent` を使用して、その配下に tool/subagent Call をネストします。

`inputMessages` / `outputMessages` / `usage` / `reasoning` は直接設定するか、ヘルパー関数 (`output`、`think`、`attachMedia`、`record`) を使用して設定します。

記録されたすべてのデータは、`end()` 時に span にフラッシュされます。

<div id="examples">
  ## 例
</div>

```ts twoslash
// @noErrors
const llm = weave.startLLM({model: 'gpt-4o-mini', providerName: 'openai'});

try {
  llm.inputMessages = [{role: 'user', content: prompt}];
  const resp = await openai.chat.completions.create({...});
  llm.output(resp.choices[0].message.content ?? '');
  llm.record({usage: {inputTokens: resp.usage?.prompt_tokens}});
} finally {
  llm.end();
}
```

```ts twoslash
// @noErrors
const llm = weave.startLLM({
  model: 'gpt-4o-mini',
  providerName: 'openai',
  systemInstructions: ['You are a helpful weather bot.'],
  startTime: new Date('2026-05-29T10:00:00.000Z'),
});

try {
  // ... LLM を呼び出し、llm.outputMessages / usage を設定 ...
} finally {
  llm.end();
}
```

<div id="addevent">
  ### ~~addEvent()~~
</div>

<Warning>
  **非推奨。** 代わりに [setAttributes](#setattributes) を使用してこのデータを記録してください。
  OpenTelemetry は Span Event API (`Span.addEvent`) を段階的に廃止しています。この
  メソッドは引き続き使用でき、既存の span event データも有効です。
  [https://opentelemetry.io/blog/2026/deprecating-span-events/](https://opentelemetry.io/blog/2026/deprecating-span-events/) を参照してください。
</Warning>

> **addEvent**(`name`, `attributes?`, `startTime?`): `this`

名前付きイベントを span に追加します。コンテキストの圧縮、tool ループの検出、guardrail の発動など、
span 以外の時点をマークする場合に役立ちます。`end()` の後に呼び出すと警告が表示され、
何も実行されません。OTel の `Span.addEvent` に対応します。

<div id="attachmedia">
  ### attachMedia()
</div>

> **attachMedia**(`opts`): `this`

LLM Call に添付するメディアを準備します。
`content` (インライン base64 バイト) 、`uri` (URI 参照) 、または `fileId`
(事前にアップロードされた file ID) のいずれか 1 つだけを指定します。添付は `end()` 時に
`inputMessages` 内の最後のユーザーメッセージに追加されます。

<div id="parameters-2">
  #### パラメーター
</div>

<ParamField path="opts" type="{…} | {…} | {…}" required>
  [`Modality`](../type-aliases/modality)、[`Modality`](../type-aliases/modality)、[`Modality`](../type-aliases/modality) を参照してください。

  完全なタイプ: `{ content: string; mimeType: string; modality: Modality; } | { modality: Modality; uri: string; } | { fileId: string; mimeType?: string; modality: Modality; }`
</ParamField>

</div>

> **think**(`content`): `this`

`this.reasoning.content` に蓄積されます。シリアル化時には `ReasoningPart` として最後のアシスタント メッセージに
組み込まれ、Python SDK のオンザワイヤ形式に一致します。
