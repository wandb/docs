agent invocation です。通常は、単一のユーザーメッセージに応答するための処理をラップします。`invoke_agent` span を発行し、そのターンにおける trace のルートとして機能します。常に `ROOT_CONTEXT` の下で開始されるため、OTel でインストルメントされた他のライブラリから誤って親を継承することはありません。

`weave.startTurn()` (または `conversation.startTurn()`) によって作成され、`end()` で終了します。1 つの非同期チェーン内で実行中にできるターンは 1 つだけです。子 (LLM、Tool、SubAgent) は `startLLM`、`startTool`、`startSubagent` の各 method を通じて attach されます。

<div id="examples">
  ## 例
</div>

```ts twoslash
// @noErrors
const turn = weave.startTurn();

try {
  const llm = turn.startLLM({model: 'gpt-4o', providerName: 'openai'});
  // ...
  llm.end();
} finally {
  turn.end();
}
```

```ts twoslash
// @noErrors
const turn = weave.startTurn({
  model: 'gpt-4o',
  agentName: 'research-bot',
  agentId: 'research-bot-prod',
  agentDescription: 'Looks up facts on Wikipedia.',
  agentVersion: '1.4.2',
  userMessage: 'What is the weather in Tokyo?',
  systemInstructions: ['You are a helpful weather bot.'],
  startTime: new Date('2026-05-29T10:00:00.000Z'),
});

try {
  const llm = turn.startLLM({model: 'gpt-4o', providerName: 'openai'});
  // ...
  llm.end();
} finally {
  turn.end();
}
```

<div id="addevent">
  ### ~~addEvent()~~
</div>

<Warning>
  **非推奨。** 代わりに [setAttributes](#setattributes) でこのデータを記録してください。
  OpenTelemetry は Span Event API (`Span.addEvent`) を段階的に廃止しています。この
  メソッドは引き続き動作し、既存の span event データも有効なままです。
  [https://opentelemetry.io/blog/2026/deprecating-span-events/](https://opentelemetry.io/blog/2026/deprecating-span-events/) を参照してください。
</Warning>

> **addEvent**(`name`, `attributes?`, `startTime?`): `this`

名前付きイベントを span に追加します。コンテキストの圧縮、ツールループの検出、guardrail のトリガーなど、
span 以外の時点を記録する際に便利です。`end()` の後は警告を出し、
何も行いません。OTel の `Span.addEvent` と同様の動作をします。

<div id="end">
  ### end()
</div>

> **end**(`opts?`): `void`

現在のフィールド値を読み取り (`start`以降に`record()`で行った変更を反映) 、span を終了します。冪等です。失敗としてマークするには`error`を渡します。終了時刻を過去に設定するには`endTime`を渡します。
