<div id="addevent">
  ### ~~addEvent()~~
</div>

<Warning>
  **非推奨。** 代わりに [setAttributes](#setattributes) でこのデータを記録してください。
  OpenTelemetry は Span Event API (`Span.addEvent`) を段階的に廃止しています。この
  メソッドは引き続き動作し、既存の span event データも有効なままです。
  [https://opentelemetry.io/blog/2026/deprecating-span-events/](https://opentelemetry.io/blog/2026/deprecating-span-events/) を参照してください。
</Warning>

> **addEvent**(`name`, `attributes?`, `startTime?`): `this`

名前付きイベントを span に追加します。コンテキストの圧縮、ツールループの検出、guardrail のトリガーなど、
span 以外の時点を記録する際に便利です。`end()` の後は警告を出し、
何も行いません。OTel の `Span.addEvent` と同様の動作をします。

定義元: [src/genai/spanBase.ts:82](https://github.com/wandb/weave/blob/8c5f077eb11c42b84000726ff20504abc728d3fb/sdks/node/src/genai/spanBase.ts#L82)

<div id="end">
  ### end()
</div>

> **end**(`opts?`): `void`

現在のフィールド値を読み取り (`start`以降に`record()`で行った変更を反映) 、span を終了します。冪等です。失敗としてマークするには`error`を渡します。終了時刻を過去に設定するには`endTime`を渡します。
