## メソッド {#methods}

### ~~addEvent()~~ {#addevent}

<Warning>
  **非推奨。** このデータは代わりに [setAttributes](#setattributes) で記録してください。
  OpenTelemetry では Span Event API (`Span.addEvent`) の段階的な廃止が進められています。
  このメソッドは引き続き動作し、既存のspanイベントデータも有効です。
  [https://opentelemetry.io/blog/2026/deprecating-span-events/](https://opentelemetry.io/blog/2026/deprecating-span-events/) を参照してください。
</Warning>

> **addEvent**(`name`, `attributes?`, `startTime?`): `this`

名前付きイベントをspanに追加します。コンテキストの圧縮、ツールループの検出、ガードレールのトリガーなど、span以外のタイミングを示す際に役立ちます。
`end()` の呼び出し後は警告を出力し、何も実行しません。OTel の `Span.addEvent` と同様の動作をします。

#### パラメーター {#parameters}

<ParamField path="name" type="string" required />

<ParamField path="attributes" type="Attributes" />

<ParamField path="startTime" type="TimeInput" />

#### 戻り値 {#returns-3}

`this`

#### 例 {#example}

```ts twoslash
// @noErrors
span.addEvent('context_compacted', {removedMessages: 12});
```

#### 継承元 {#inherited-from}

`SpanBase.addEvent`

### end() {#end}

> **end**(`opts?`): `void`

現在のフィールド値を読み取り (`start` 以降に `record()` で行われた変更を反映) 、span を閉じます。冪等です。`error` を渡すと失敗としてマークされ、`endTime` を渡すと終了時刻を過去に設定できます。

#### パラメーター {#parameters-2}

<ParamField path="opts" type="object">
  <Expandable title="プロパティ" defaultOpen>
    <ParamField path="endTime" type="TimeInput" />

    <ParamField path="error" type="Error" />
  </Expandable>
</ParamField>

#### 戻り値 {#returns-4}

`void`

***

### record() {#record}

> **record**(`opts`): `this`

可変フィールドの任意のサブセットを一括設定します。既存の値はマージではなく置換されます。
入力メッセージと出力メッセージは、span の終了時にシリアライズされます。

#### パラメーター {#parameters-3}

  </Expandable>
</ParamField>

### setAttributes() {#setattributes}

> **setAttributes**(`attributes`): `this`

span に複数の属性をまとめて設定します。`end()` の後に呼び出すと、警告が表示され何も実行されません。OTel の `Span.setAttributes` (および Python SDK の
`set_attributes`) と同様です。

#### パラメーター {#parameters-4}

<ParamField path="attributes" type="Attributes" required />

#### 戻り値 {#returns-6}

`this`

#### 例 {#example-2}

```ts twoslash
// @noErrors
span.setAttributes({'weave.tag': 'prod', 'gen_ai.response.id': id});
```
