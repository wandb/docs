```ts
startLLM(opts: LLMInit): LLM
```

<GitHubLink url="https://github.com/wandb/weave/blob/7c9efdc9fe05ffcaf2430dd652ef9bc5b3ffdfaa/sdks/node/src/genai/api.ts#L77" />

Start an LLM span as a child of the current Turn. Throws if no Turn is
active.

## Parameters

<ParamField path="opts" type="LLMInit" required>
  See [`LLMInit`](../interfaces/llminit).
</ParamField>

## Returns

[`LLM`](../interfaces/llm)

## Examples

```ts twoslash
// @noErrors
weave.startLLM({model: 'gpt-4o-mini', providerName: 'openai'});
```

```ts twoslash
// @noErrors
weave.startLLM({
  model: 'gpt-4o-mini',
  providerName: 'openai',
  systemInstructions: ['You are a helpful weather bot.'],
  startTime: new Date('2026-05-29T10:00:00.000Z'),
});
```
