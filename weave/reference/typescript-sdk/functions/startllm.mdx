# startLLM

▸ **startLLM**(`opts`): [`LLM`](../classes/llm)

Start an LLM span as a child of the current Turn. Throws if no Turn is
active.

| Name | Type |

| `opts` | [`LLMInit`](../interfaces/llminit) |

[`LLM`](../classes/llm)
