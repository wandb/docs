---
title: "How do I move a project to a different team or organization?"
keywords: ["Projects", "Teams", "Administrator"]
---

You can't move a whole project to another team or organization yourself. W&B Support performs the move for you. Open a support request that lists the projects to move and names the destination team.

The destination team must already exist before support can move anything into it. If it doesn't, create it first: see [Create a collaborative team](/platform/app/settings-page/teams#create-a-collaborative-team).

Before you request the move, note the following:

- **Reports break.** Reports that reference a moved project contain broken links afterward, because the project has a new location.
- **Ownership collapses to one user.** If runs in the project were created by several users, the moved project is assigned to a single user.
- **Stop logging first.** Don't log data to the project's runs while the move is in progress. Tell W&B Support when your experiments are idle.
- **Renaming isn't part of the move.** W&B Support can't rename a project while moving it. Rename it yourself in the project settings after the move completes.

Moving individual runs between projects doesn't require support. See [How do I move a run to another project?](/support/models/articles/how-do-i-move-a-run-to-another-project).
