---
title: "Why does deleting many artifacts at once time out?"
keywords: ["Artifacts", "Storage", "API"]
---

Deleting an artifact that contains many files from the W&B App can time out and return a `context deadline exceeded` error. Deleting a single small file succeeds, but deleting hundreds of artifacts or files at once fails. This is a known issue.

To work around it, delete artifacts programmatically in smaller batches with the [W&B Public API](/models/ref/python/public-api/api).

## Delete artifacts in batches

The following script steps through a project's artifact types and deletes each version, skipping the artifact types that W&B generates for you. Keep `DRY_RUN = True` for the first pass to review what the script deletes before you commit to it. Replace the `<entity>` and `<project>` placeholders with your own values.

<Warning>
Artifact deletion is irreversible.
</Warning>

```python
import wandb

# Assumes you've run `wandb login` already.
entity = "<entity>"  # your username or team
project = "<project>"
project_path = f"{entity}/{project}"

# Set to False to actually delete. Deletion is irreversible.
DRY_RUN = True

# Delete only your own artifacts; skip W&B system-generated ones.
SKIP_TYPES = {"run_table", "code", "job"}

api = wandb.Api()

for art_type in api.artifact_types(project_path):
    if art_type.name.startswith("wandb-") or art_type.name in SKIP_TYPES:
        continue
    for collection in api.artifact_collections(project_path, art_type.name):
        for version in collection.artifacts():
            if DRY_RUN:
                print(f"[dry-run] would delete {version.name}")
            else:
                print(f"Deleting {version.name}")
                version.delete(delete_aliases=True)
```

To narrow the deletion further, filter on `art_type.name` or `collection.name` so the script processes one artifact type or collection at a time.

To delete individual artifact versions interactively instead, use the Storage Explorer at **Billing > Manage Storage**, then select the team and project.

## Reclaim the space

Deleted artifacts are soft-deleted first, then removed during garbage collection, so your storage meter doesn't drop immediately. For the timing and how to verify your usage, see [Why does the storage meter not update after deleting runs?](/support/models/articles/why-does-the-storage-meter-not-update-af) and [Delete an artifact](/models/artifacts/delete-artifacts).
