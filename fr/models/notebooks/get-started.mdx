Le guide suivant vous aidera à faire vos premiers pas avec les notebooks W&amp;B, de la création de votre premier notebook à l&#39;exécution d&#39;une expérience d&#39;entraînement.

## Créer votre premier notebook {#create-your-first-notebook}

1. Accédez au workspace de votre projet.
2. Sélectionnez **Notebooks** dans la barre latérale du projet.
3. Cliquez sur **Create notebook**.

Pour en savoir plus, voir [Créer et gérer des notebooks](/fr/models/notebooks/create-notebook).

## Exécuter une expérience d&#39;entraînement {#run-a-training-experiment}

Ce script d&#39;entraînement fictif journalise des métriques simulées de précision et de perte dans W&amp;B. Copiez-collez le code suivant dans un script Python ou une cellule de notebook, puis exécutez-le :

1. Sélectionnez **Python** pour créer une cellule de code.

2. Copiez-collez le code suivant dans la cellule :

   ```python
   import random
   import wandb

   PROJECT = "your-project-name"

   # Dictionnaire des hyperparamètres
   config = {
       'epochs' : 10,
       'lr' : 0.01
   }

   with wandb.init(project=PROJECT, config=config) as run:
       offset = random.random() / 5
       print(f"lr: {config['lr']}")
       
       # Simuler un run d'entraînement
       for epoch in range(2, config['epochs']):
           acc = 1 - 2**-config['epochs'] - random.random() / config['epochs'] - offset
           loss = 2**-config['epochs'] + random.random() / config['epochs'] + offset
           print(f"epoch={config['epochs']}, accuracy={acc}, loss={loss}")
           run.log({"accuracy": acc, "loss": loss})
   ```

3. Appuyez sur **Command + Entrée** sous macOS ou sur **Ctrl + Entrée** sous Windows ou Linux. Vous pouvez également cliquer sur **Play** (<Icon icon="circle-play" iconType="solid" />) à côté de la cellule.

## Consulter votre expérience {#view-your-experiment}

Consultez les métriques de précision et de perte enregistrées pendant l&#39;expérience d&#39;entraînement :

1. Sélectionnez **Workspace** dans la barre latérale du projet.
2. Examinez les runs et les visualisations dans le Workspace. La liste des [runs](/fr/models/runs) affiche chaque run enregistré dans le projet ainsi que ses détails. Les [panneaux du Workspace](/fr/models/app/features/panels) affichent les visualisations des métriques enregistrées lors de chaque run.

## Enregistrer le notebook {#save-the-notebook}

W&amp;B stocke votre notebook sous forme d&#39;[artifact W&amp;B](/fr/models/artifacts) et enregistre automatiquement les modifications dans une nouvelle [version d&#39;artifact](/fr/models/artifacts/create-a-new-artifact-version) toutes les 30 secondes, ainsi qu&#39;à l&#39;arrêt de la session de calcul du notebook.

Pour enregistrer immédiatement vos dernières modifications, utilisez l&#39;une des options suivantes :

* Appuyez sur **Command+S** sous macOS ou sur **Ctrl+S** sous Windows ou Linux.
* Dans le pied de page du notebook, cliquez sur **Save** (<Icon icon="floppy-disk" iconType="solid" />).
