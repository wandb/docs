---
title: Travailler avec des fichiers de données
---

Utilisez la barre latérale du notebook pour gérer les fichiers du sandbox du notebook et vous connecter à des sources de données distantes. Vous pouvez également télécharger des [artefacts W&amp;B](/fr/models/artifacts/download-and-use-an-artifact) dans le notebook.

## Stockage et persistance des notebooks {#notebook-storage-and-persistence}

Chaque notebook s&#39;exécute dans un [CoreWeave Sandbox](https://docs.coreweave.com/products/sandboxes) temporaire. Les fichiers que vous créez, téléversez ou téléchargez apparaissent sous **Files** dans la barre latérale du notebook et n&#39;existent que dans le sandbox.

Le stockage d&#39;objets, les bases de données et les catalogues de données connectés apparaissent sous **Remote storage**.

<Warning>
  Les fichiers du sandbox du notebook sont temporaires. Copiez les fichiers que vous souhaitez conserver vers un stockage persistant avant la réinitialisation ou la suppression du sandbox.
</Warning>

## Afficher les fichiers {#view-files}

Pour afficher les fichiers dans la barre latérale du notebook :

1. Dans la barre latérale du notebook, sélectionnez **View files** (<Icon icon="folder-tree" iconType="solid" />).
2. Développez l&#39;une des sections suivantes :
   * **Files** pour afficher les fichiers du sandbox du notebook.
   * **Remote storage** pour parcourir les sources de données distantes connectées.

## Gérer les fichiers et les dossiers {#manage-files-and-folders}

Pour téléverser ou créer un fichier ou un dossier :

1. Dans la barre latérale du notebook, sélectionnez **View files** (<Icon icon="folder-tree" iconType="solid" />).
2. Développez **Files**.
3. Sélectionnez l&#39;une des actions suivantes :
   * **Upload file** (<Icon icon="arrow-up-from-bracket" iconType="solid" />) pour téléverser un fichier existant dans le sandbox.
   * **Add file** (<Icon icon="file-plus" iconType="solid" />) pour créer un fichier.
   * **Add folder** (<Icon icon="folder-plus" iconType="solid" />) pour créer un dossier.

## Télécharger un artefact W&amp;B {#download-a-wb-artifact}

Vous pouvez [télécharger et utiliser un artefact W&amp;B](/fr/models/artifacts/download-and-use-an-artifact) dans un notebook. Les fichiers téléchargés sont stockés dans le sandbox du notebook.

Par exemple, le code suivant télécharge un artefact de modèle depuis W&amp;B Registry :

```python
import wandb

REGISTRY_NAME = "Zoo"
MODEL_COLLECTION_NAME = "Classifier_Models"
MODEL_VERSION = 0

artifact_name = (
    f"wandb-registry-{REGISTRY_NAME}/"
    f"{MODEL_COLLECTION_NAME}:v{MODEL_VERSION}"
)

with wandb.init() as run:
    artifact = run.use_artifact(artifact_name)
    artifact_path = artifact.download()
    print(artifact_path)
```

La commande renvoie le chemin du répertoire de l&#39;artefact téléchargé. Par exemple :

```text
/workspace/artifacts/zoo-pznwefqb:v0
```

L&#39;artefact téléchargé apparaît dans le répertoire `artifacts` :
