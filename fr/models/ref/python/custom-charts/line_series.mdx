## <Badge color="blue" size="lg" shape="rounded">fonction</Badge> wandb.plot.line_series()

Construit un graphique de série de lignes.

```python
xs: 'Iterable[Iterable[Any]] | Iterable[Any]',
ys: 'Iterable[Iterable[Any]]',
keys: 'Iterable[str] | None' = None,
title: 'str' = '',
xname: 'str' = 'x',
split_table: 'bool' = False
```

<div id="args">
  ## Arguments
</div>

<ResponseField name="xs" type="Iterable[Iterable[Any]] | Iterable[Any]">
  Séquence de valeurs x. Si un seul tableau est fourni, toutes les valeurs y sont tracées en fonction de ce tableau x. Si un tableau de tableaux est fourni, chaque valeur y est tracée en fonction du tableau x correspondant.
</ResponseField>

<ResponseField name="ys" type="Iterable[Iterable[Any]]">
  Séquence de valeurs y, où chaque itérable représente une série de lignes distincte.
</ResponseField>

<ResponseField name="keys" type="Iterable[str] | None">
  Séquence de clés servant à étiqueter chaque série de lignes. Si elles ne sont pas fournies, les clés sont générées automatiquement sous la forme « line&#95;1 », « line&#95;2 », etc.
</ResponseField>

<ResponseField name="title" type="str">
  Titre du graphique.
</ResponseField>

<ResponseField name="xname" type="str">
  Étiquette de l’axe X.
</ResponseField>

<ResponseField name="split_table" type="bool">
  Indique si le tableau doit être placé dans une section distincte de l’interface W&amp;B. Si `True`, le tableau s’affiche dans une section nommée « Custom Chart Tables ». La valeur par défaut est `False`.
</ResponseField>

<div id="returns">
  ## Retourne
</div>

`CustomChart`: Un objet de graphique personnalisé qui peut être enregistré dans W&amp;B. Pour enregistrer le graphique, passez-le à `wandb.log()`.

<div id="examples">
  ## Exemples
</div>

Journalisation d’un seul tableau x, toutes les séries y étant tracées selon les mêmes valeurs x :

```python
import wandb

# Initialiser le W&B run
with wandb.init(project="line_series_example") as run:
    # Valeurs x partagées entre toutes les séries y
    xs = list(range(10))

    # Plusieurs séries y à tracer
    ys = [
        [i for i in range(10)],  # y = x
        [i**2 for i in range(10)],  # y = x²
        [i**3 for i in range(10)],  # y = x³
    ]

    # Générer et enregistrer le graphique de série de lignes
    line_series_chart = wandb.plot.line_series(
        xs,
        ys,
        title="title",
        xname="step",
    )
    run.log({"line-series-single-x": line_series_chart})
```

Dans cet exemple, une seule série `xs` (valeurs x partagées) est utilisée pour toutes les
séries `ys`. Chaque série y est ainsi tracée en fonction des
mêmes valeurs x (0-9).

Journalisation de plusieurs tableaux x, chaque série y étant tracée en fonction de son tableau x correspondant :

```python
import wandb

# Initialiser le W&B run
with wandb.init(project="line_series_example") as run:
    # Valeurs x distinctes pour chaque série y
    xs = [
        [i for i in range(10)],  # x pour la première série
        [2 * i for i in range(10)],  # x pour la deuxième série (étirée)
        [3 * i for i in range(10)],  # x pour la troisième série (encore plus étirée)
    ]

    # Séries y correspondantes
    ys = [
        [i for i in range(10)],  # y = x
        [i**2 for i in range(10)],  # y = x²
        [i**3 for i in range(10)],  # y = x³
    ]

    # Générer et enregistrer le graphique de série de lignes
    line_series_chart = wandb.plot.line_series(
        xs, ys, title="Multiple X Arrays Example", xname="Step"
    )
    run.log({"line-series-multiple-x": line_series_chart})
```

Dans cet exemple, chaque série de y est tracée par rapport à sa propre série de x.
Cela offre plus de flexibilité lorsque les valeurs de x ne sont pas uniformes
d’une série de données à l’autre.

Personnalisation des étiquettes de ligne avec `keys` :

```python
import wandb

# Initialiser le W&B run
with wandb.init(project="line_series_example") as run:
    xs = list(range(10))  # Tableau x unique
    ys = [
        [i for i in range(10)],  # y = x
        [i**2 for i in range(10)],  # y = x^2
        [i**3 for i in range(10)],  # y = x^3
    ]

    # Étiquettes personnalisées pour chaque ligne
    keys = ["Linear", "Quadratic", "Cubic"]

    # Générer et enregistrer le graphique de série de lignes
    line_series_chart = wandb.plot.line_series(
        xs,
        ys,
        keys=keys,  # Clés personnalisées (étiquettes de ligne)
        title="Custom Line Labels Example",
        xname="Step",
    )
    run.log({"line-series-custom-keys": line_series_chart})
```

Cet exemple montre comment définir des libellés personnalisés pour les lignes à l’aide de
l’argument `keys`. Les clés apparaîtront dans la légende sous la forme &quot;Linear&quot;,
&quot;Quadratic&quot; et &quot;Cubic&quot;.
