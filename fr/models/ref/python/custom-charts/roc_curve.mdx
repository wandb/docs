<div id="function-wandbplotroc_curve">
  ## <Badge color="blue" size="lg" shape="rounded">fonction</Badge> wandb.plot.roc_curve()
</div>

Construit un graphique de courbe ROC (Receiver Operating Characteristic).

```python
y_true: 'Sequence[numbers.Number]',
y_probas: 'Sequence[Sequence[float]] | None' = None,
labels: 'list[str] | None' = None,
classes_to_plot: 'list[numbers.Number] | None' = None,
title: 'str' = 'ROC Curve',
split_table: 'bool' = False
```

<div id="args">
  ## Arguments
</div>

<ResponseField name="y_true" type="Sequence[numbers.Number]">
  Les véritables étiquettes de classe (vérité de terrain) pour la variable cible. La forme doit être (num&#95;samples,).
</ResponseField>

<ResponseField name="y_probas" type="Sequence[Sequence[float]] | None">
  Les probabilités prédites ou les scores de décision pour chaque classe. La forme doit être (num&#95;samples, num&#95;classes).
</ResponseField>

<ResponseField name="labels" type="list[str] | None">
  Des libellés lisibles par l’humain correspondant aux indices de classe dans `y_true`. Par exemple, si `labels=['dog', 'cat']`, la classe 0 s’affichera comme &#39;dog&#39; et la classe 1 comme &#39;cat&#39; dans le graphique. Si None, les indices de classe bruts de `y_true` seront utilisés. La valeur par défaut est None.
</ResponseField>

<ResponseField name="classes_to_plot" type="list[numbers.Number] | None">
  Un sous-ensemble d’étiquettes de classe uniques à inclure dans la courbe ROC. Si None, toutes les classes de `y_true` seront tracées. La valeur par défaut est None.
</ResponseField>

<ResponseField name="title" type="str">
  Le titre du graphique de courbe ROC. La valeur par défaut est &quot;ROC Curve&quot;.
</ResponseField>

<ResponseField name="split_table" type="bool">
  Indique si le tableau doit être placé dans une section distincte de l’UI W&amp;B. Si `True`, le tableau sera affiché dans une section nommée &quot;Custom Chart Tables&quot;. La valeur par défaut est `False`.
</ResponseField>

<div id="returns">
  ## Retourne
</div>

`CustomChart` : Un objet de graphique personnalisé pouvant être enregistré dans W&amp;B. Pour enregistrer le graphique, passez-le à `wandb.log()`.

<div id="raises">
  ## Exceptions levées
</div>

* `wandb.Error`: Si numpy, pandas ou scikit-learn sont introuvables.

<div id="examples">
  ## Exemples
</div>

```python
import numpy as np
import wandb

# Simuler un problème de classification de diagnostic médical avec trois maladies
n_samples = 200
n_classes = 3

# Étiquettes réelles : attribuer "Diabetes", "Hypertension" ou "Heart Disease" à
# chaque échantillon
disease_labels = ["Diabetes", "Hypertension", "Heart Disease"]
# 0 : Diabetes, 1 : Hypertension, 2 : Heart Disease
y_true = np.random.choice([0, 1, 2], size=n_samples)

# Probabilités prédites : simuler des prédictions en s'assurant que leur somme vaut 1
# pour chaque échantillon
y_probas = np.random.dirichlet(np.ones(n_classes), size=n_samples)

# Spécifier les classes à tracer (les trois maladies)
classes_to_plot = [0, 1, 2]

# Initialiser un W&B run et enregistrer un graphique de courbe ROC pour la classification des maladies
with wandb.init(project="medical_diagnosis") as run:
    roc_plot = wandb.plot.roc_curve(
        y_true=y_true,
        y_probas=y_probas,
        labels=disease_labels,
        classes_to_plot=classes_to_plot,
        title="ROC Curve for Disease Classification",
    )
    run.log({"roc-curve": roc_plot})
```
