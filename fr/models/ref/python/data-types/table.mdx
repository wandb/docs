<div id="class-wandbtable">
  ## <Badge color="yellow" size="lg" shape="rounded">Classe</Badge> wandb.Table
</div>

La classe Table permet d’afficher et d’analyser des données tabulaires.

Contrairement aux feuilles de calcul traditionnelles, les Tables prennent en charge de nombreux types de données :
des valeurs scalaires, des chaînes de caractères, des tableaux NumPy et la plupart des sous-classes de `wandb.data_types.Media`.
Cela signifie que vous pouvez intégrer `Images`, `Video`, `Audio` et d’autres types de médias enrichis et annotés
directement dans les Tables, aux côtés d’autres valeurs scalaires plus classiques.

Cette classe est la classe principale utilisée pour générer des W&amp;B Tables
[https://docs.wandb.ai/models/tables](https://docs.wandb.ai/models/tables)

```python
columns: 'list[ColumnKey] | None' = None,
data: 'list[InputRow] | np.ndarray | pd.DataFrame | None' = None,
rows: 'list[InputRow] | None' = None,
dataframe: 'pd.DataFrame | None' = None,
dtype: 'Any' = None,
optional: 'bool | list[bool]' = True,
allow_mixed_types: 'bool' = False,
log_mode: 'LogMode | None' = 'IMMUTABLE'
```

<div id="args">
  ## Arguments
</div>

<ResponseField name="columns" type="list[ColumnKey] | None">
  Noms des colonnes du tableau. Valeurs par défaut : &#91;&quot;Input&quot;, &quot;Output&quot;, &quot;Expected&quot;&#93;.
</ResponseField>

<ResponseField name="data" type="list[InputRow] | np.ndarray | pd.DataFrame | None">
  Tableau 2D de valeurs orienté par lignes, tableau NumPy ou DataFrame pandas.
</ResponseField>

<ResponseField name="rows" type="list[InputRow] | None">
  Tableau 2D de valeurs orienté par lignes.
</ResponseField>

<ResponseField name="dataframe" type="pd.DataFrame | None">
  Objet DataFrame utilisé pour créer le tableau. Lorsqu&#39;il est défini, les arguments `data` et `columns` sont ignorés.
</ResponseField>

<ResponseField name="dtype" type="Any">
  Type attendu pour les valeurs des colonnes, utilisé pour valider les
  données. S&#39;il n&#39;est pas défini, les types sont déduits à partir des données. Il peut s&#39;agir de :

  * un type unique
    * un type intégré Python tel que `int`, `str`, `bool`, list, dict ou
      datetime.
    * un type W&amp;B Media comme `wandb.Image` déclaré dans wandb.data&#95;types
    * une valeur constante
  * une liste de l&#39;un des éléments ci-dessus pour attribuer un type différent à chaque
    colonne (doit avoir la même longueur que `columns`)
</ResponseField>

<ResponseField name="optional" type="bool | list[bool]">
  Détermine si les valeurs `None` sont autorisées. Valeur par défaut : True.

  * S&#39;il s&#39;agit d&#39;une valeur booléenne unique, le caractère facultatif est appliqué à toutes les
    colonnes spécifiées lors de la création
  * S&#39;il s&#39;agit d&#39;une liste de valeurs booléennes, le caractère facultatif est appliqué à chaque
    colonne ; la liste doit avoir la même longueur que `columns`
    s&#39;applique à toutes les colonnes. Une liste de valeurs booléennes s&#39;applique à chaque colonne correspondante.
</ResponseField>

<ResponseField name="allow_mixed_types" type="bool">
  Détermine si les colonnes peuvent contenir des types mixtes (désactive la validation de type). Valeur par défaut : False
</ResponseField>

<ResponseField name="log_mode" type="LogMode | None">
  Contrôle la façon dont la Table est enregistrée lorsque des modifications surviennent.
  Options :

  * &quot;IMMUTABLE&quot; (par défaut) : la Table ne peut être enregistrée qu&#39;une seule fois ; les tentatives d&#39;enregistrement suivantes après modification du tableau seront sans effet.
  * &quot;MUTABLE&quot; : la Table peut être enregistrée à nouveau après des modifications, créant une nouvelle version d&#39;artifact à chaque enregistrement.
  * &quot;INCREMENTAL&quot; : les données de la Table sont enregistrées de façon incrémentielle, chaque enregistrement créant une nouvelle entrée d&#39;artifact contenant les nouvelles données depuis le dernier enregistrement.
</ResponseField>

Ajoute une ou plusieurs colonnes calculées à partir des données existantes.

<div id="arguments-2">
  ##### Arguments
</div>

<ResponseField name="fn" type="Callable[[int, dict[ColumnKey, Any]], dict[str, Any]]">
  fonction qui accepte un index et le dictionnaire d’une ligne, et qui renvoie un dictionnaire représentant les nouvelles colonnes de cette ligne, avec pour clés les noms des nouvelles colonnes.
</ResponseField>

<div id="examples">
  ##### Exemples
</div>

Dans le callback :

* `ndx` est un entier qui représente l’indice de la ligne.
* `row` est un dictionnaire dont les clés correspondent aux colonnes existantes.

```python
import wandb

table = wandb.Table(columns=["x", "y"], data=[[3, 1], [4, 6]])
table.add_computed_columns(lambda ndx, row: {"diff": row["x"] - row["y"]})
```
