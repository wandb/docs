  ## <Badge color="yellow" size="lg" shape="rounded">Classe</Badge> wandb.Html
</div>

Classe W&amp;B permettant de journaliser du contenu HTML dans W&amp;B.

```python
data: 'str | pathlib.Path | TextIO',
inject: 'bool' = True,
data_is_not_path: 'bool' = False
```

<div id="args">
  ## Arguments
</div>

<ResponseField name="data" type="str | pathlib.Path | TextIO">
  Une chaîne représentant le chemin d’un fichier avec l’extension &quot;.html&quot;, ou une chaîne ou un objet IO contenant du HTML littéral.
</ResponseField>

<ResponseField name="inject" type="bool">
  Ajoute une feuille de style à l’objet HTML. Si cette option est définie sur False, le HTML est transmis tel quel.
</ResponseField>

<ResponseField name="data_is_not_path" type="bool">
  Si cette option est définie sur False, les données sont traitées comme le chemin d’un fichier.
</ResponseField>
