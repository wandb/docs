## <Badge color="yellow" size="lg" shape="rounded">Classe</Badge> wandb.Object3D

Classe W&amp;B pour les nuages de points 3D.

```python
data_or_path: 'np.ndarray | str | pathlib.Path | TextIO | dict',
caption: 'str | None' = None, **kwargs: 'str | FileFormat3D | None'
```

<div id="args">
  ## Arguments
</div>

<ResponseField name="data_or_path" type="np.ndarray | str | pathlib.Path | TextIO | dict">
  Object3D peut être initialisé à partir d’un fichier ou d’un tableau NumPy.
</ResponseField>

<ResponseField name="caption" type="str | None">
  Légende associée à l’objet pour l’affichage.
</ResponseField>

<ResponseField name="kwargs" type="str | FileFormat3D | None">
  Aucune description fournie.
</ResponseField>

### <Badge color="blue" size="lg" shape="rounded">méthode</Badge> Object3D.from_point_cloud()

```python
points: 'Sequence[Point]',
boxes: 'Sequence[Box3D]',
vectors: 'Sequence[Vector3D] | None' = None,
point_cloud_type: 'PointCloudType' = 'lidar/beta'
```

Initialise un Object3D à partir d’un objet Python.

<div id="arguments">
  ##### Arguments
</div>

<ResponseField name="points" type="Sequence[Point]">
  Les points du nuage de points.
</ResponseField>

<ResponseField name="boxes" type="Sequence[Box3D]">
  Boîtes englobantes 3D permettant d’annoter le nuage de points. Les boîtes englobantes s’affichent dans les visualisations de nuages de points.
</ResponseField>

<ResponseField name="vectors" type="Sequence[Vector3D] | None">
  Chaque vecteur s’affiche dans la visualisation du nuage de points. Peut être utilisé pour indiquer l’orientation des boîtes englobantes. La valeur par défaut est `None`.
</ResponseField>
