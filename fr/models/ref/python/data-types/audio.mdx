## <Badge color="yellow" size="lg" shape="rounded">Classe</Badge> wandb.Audio {#class-wandbaudio}

Classe W&amp;B pour les clips audio.

```python
(data_or_path: 'str | pathlib.Path | list | np.ndarray',
sample_rate: 'int | None' = None,
caption: 'str | None' = None)
```

## Arguments {#args}

<ResponseField name="data_or_path" type="str | pathlib.Path | list | np.ndarray">
  Chemin vers un fichier audio ou tableau NumPy de données audio.
</ResponseField>

<ResponseField name="sample_rate" type="int | None">
  Fréquence d’échantillonnage requise lors de la transmission d’un tableau NumPy brut de données audio.
</ResponseField>

<ResponseField name="caption" type="str | None">
  Légende à afficher avec l’audio.
</ResponseField>
