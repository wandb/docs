<div id="examples">
  ## Exemples
</div>

Définissez un événement qui se déclenche chaque fois que le tag &quot;prod&quot; est attribué à
une version d’artefact de la collection &quot;my-collection&quot; :

```python
from wandb import Api
from wandb.automations import OnAddArtifactTag, ArtifactEvent

api = Api()
collection = api.artifact_collection(name="my-collection", type_name="model")

event = OnAddArtifactTag(
    scope=collection,
    filter=ArtifactEvent.tag.eq("prod"),
)
```
