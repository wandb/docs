<div id="examples">
  ## Exemples
</div>

Définissez un événement qui se déclenche lorsqu’un nouvel artifact est créé dans la
collection &quot;my-collection&quot; :

```python
from wandb import Api
from wandb.automations import OnCreateArtifact

api = Api()
collection = api.artifact_collection(name="my-collection", type_name="model")

event = OnCreateArtifact(scope=collection)
```
