  ## <Badge color="yellow" size="lg" shape="rounded">Classe</Badge> wandb.apis.public.Files
</div>

Un itérateur paresseux sur une collection d’objets `File`.

Permet d’accéder aux fichiers chargés dans W&amp;B pendant un run et de les gérer. Gère automatiquement la pagination lors de l’itération sur de grandes collections de fichiers.

```python
(service_api: 'ServiceApi',
run: 'Run',
names: 'list[str] | None' = None,
per_page: 'int' = 50,
upload: 'bool' = False,
pattern: 'str | None' = None)
```

<div id="args">
  ## Arguments
</div>

<ResponseField name="service_api" type="ServiceApi">
  L’instance de l’API de service à utiliser pour interroger W&amp;B.
</ResponseField>

<ResponseField name="run" type="Run">
  L’objet run qui contient les fichiers
</ResponseField>

<ResponseField name="names" type="list[str] | None">
  Une liste de noms de fichiers servant à filtrer les fichiers
</ResponseField>

<ResponseField name="per_page" type="int">
  Le nombre de fichiers à récupérer par page
</ResponseField>

<ResponseField name="upload" type="bool">
  Si `True`, récupère l’URL d’upload pour chaque fichier
</ResponseField>

<ResponseField name="pattern" type="str | None">
  Motif à utiliser pour la correspondance lors du renvoi des fichiers depuis W&amp;B Ce motif utilise la syntaxe LIKE de mySQL. Ainsi, pour faire correspondre tous les fichiers se terminant par .json, utilisez &quot;%.json&quot;. Si `names` et `pattern` sont tous deux fournis, une ValueError est levée.
</ResponseField>

<div id="examples">
  ## Exemples
</div>

```python
from wandb.apis.public.files import Files
from wandb.apis.public.api import Api

# Exemple d'objet run
run = Api().run("entity/project/run-id")

# Obtenir les fichiers du run
files = run.files()

# Itérer sur les fichiers
for file in files:
    print(file.name)
    print(file.url)
    print(file.size)

    # Télécharger le fichier
    file.download(root="download_directory", replace=True)
```
