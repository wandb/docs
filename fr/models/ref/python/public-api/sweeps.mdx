## <Badge color="yellow" size="lg" shape="rounded">Classe</Badge> wandb.apis.public.Sweeps

Un itérateur paresseux d’une collection d’objets `Sweep`.

```python
service_api: 'ServiceApi',
entity: 'str',
project: 'str',
per_page: 'int' = 50,

```

<div id="args">
  ## Arguments
</div>

<ResponseField name="service_api" type="ServiceApi">
  L’API de service utilisée pour interroger W&amp;B.
</ResponseField>

<ResponseField name="entity" type="str">
  L’entité à laquelle appartiennent les sweeps.
</ResponseField>

<ResponseField name="project" type="str">
  Le projet contenant les sweeps.
</ResponseField>

<ResponseField name="per_page" type="int">
  Le nombre de sweeps à récupérer par requête API.
</ResponseField>

<ResponseField name="filters" type="dict[str, Any] | None">
  (dict) Requêtes de sweeps spécifiques à l’aide des filtres de runs. Voir wandb/apis/public/api.py:runs pour plus de détails.
</ResponseField>

<div id="examples">
  ## Exemples
</div>

```python
from wandb.apis.public import Api

sweeps = Api().project(name="project_name", entity="entity").sweeps()

# Parcourir les sweeps et afficher les détails
for sweep in sweeps:
    print(f"Sweep name: {sweep.name}")
    print(f"Sweep ID: {sweep.id}")
    print(f"Sweep URL: {sweep.url}")
    print("----------")
```
