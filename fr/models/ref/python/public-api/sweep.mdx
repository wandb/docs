<div id="attributes">
  ## Attributs
</div>

* `runs` (`Runs`) : Liste des runs
* `id` (`str`) : ID du balayage
* `project` (`str`) : Nom du projet auquel le balayage appartient
* `config` (`dict`) : Dictionnaire contenant la configuration du balayage
* `state` (`str`) : État du balayage. Peut être &quot;Finished&quot;, &quot;Failed&quot;, &quot;Crashed&quot; ou &quot;Running&quot;.
* `expected_run_count` (`int`) : Nombre de runs attendus pour le balayage

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="config" type="">
  La configuration de balayage utilisée pour le balayage.
</ResponseField>

<ResponseField name="entity" type="str">
  L’entité associée au balayage.
</ResponseField>

<ResponseField name="expected_run_count" type="int | None">
  Renvoyer le nombre de runs attendus dans le balayage, ou None si le nombre de runs est illimité.
</ResponseField>

<ResponseField name="name" type="">
  Le nom du balayage.

  Renvoyer le premier nom disponible selon l’ordre de priorité suivant :

  1. Nom d’affichage modifié par l’utilisateur
  2. Nom configuré lors de la création
  3. ID du balayage
</ResponseField>

<ResponseField name="order" type="">
  Renvoyer la clé d’ordre du balayage.
</ResponseField>

<ResponseField name="path" type="">
  Renvoyer le chemin du projet.

  Le chemin est une liste contenant l’entité, le nom du projet et l’ID du balayage.
</ResponseField>

<ResponseField name="url" type="">
  L’URL du balayage.

  L’URL du balayage est générée à partir de l’entité, du projet, du terme
  « balayages » et de l’ID du balayage.run&#95;id. Pour les
  utilisateurs SaaS, elle se présente sous la forme
  `https://wandb.ai/entity/project/sweeps/sweeps_ID`.
</ResponseField>

<ResponseField name="username" type="str">
  Obsolète. Utilisez plutôt `Sweep.entity`.
</ResponseField>
