## <Badge color="yellow" size="lg" shape="rounded">classe</Badge> wandb.apis.public.ArtifactCollection

Une collection d&#39;artifacts représentant un groupe d&#39;artifacts associés.

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="aliases" type="list[str]">
  Les alias de toutes les versions d&#39;artifact de cette collection.
</ResponseField>

<ResponseField name="created_at" type="str">
  La date de création de la collection d&#39;artifacts.
</ResponseField>

<ResponseField name="description" type="str | None">
  Une description de la collection d&#39;artifacts.
</ResponseField>

<ResponseField name="entity" type="str">
  L&#39;entité (utilisateur ou équipe) propriétaire du projet.
</ResponseField>

<ResponseField name="id" type="str">
  L&#39;ID unique de la collection d&#39;artifacts.
</ResponseField>

<ResponseField name="name" type="str">
  Le nom de la collection d&#39;artifacts.
</ResponseField>

<ResponseField name="project" type="str">
  Le projet qui contient la collection d&#39;artifacts.
</ResponseField>

<ResponseField name="project_id" type="str">
  L&#39;ID GraphQL encodé du projet de cette collection.
</ResponseField>

<ResponseField name="project_internal_id" type="str | None">
  L&#39;`internalId` GraphQL du projet sous-jacent de cette collection, s&#39;il a été récupéré.

  Il s&#39;agit d&#39;un ID global encodé en base64. Une fois décodé, il se présente sous la forme
  `Project:123` ou `ProjectInternalId:123`.
</ResponseField>

<ResponseField name="tags" type="list[str]">
  Les tags associés à la collection d&#39;artifacts.
</ResponseField>

<ResponseField name="type" type="">
  Renvoie le type de la collection d&#39;artifacts.
</ResponseField>

<ResponseField name="updated_at" type="str | None">
  La date de la dernière mise à jour de la collection d&#39;artifacts.
</ResponseField>
