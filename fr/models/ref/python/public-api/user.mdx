<div id="class-wandbapispublicuser">
  ## <Badge color="yellow" size="lg" shape="rounded">Classe</Badge> wandb.apis.public.User
</div>

Un utilisateur sur une instance W&amp;B.

Cette classe permet de gérer les clés API d’un utilisateur et d’accéder à des informations telles que les équipes auxquelles il appartient. La méthode de classe `create` peut être utilisée pour créer un nouvel utilisateur.

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="api_keys" type="list[str]">
  Noms des clés API de l&#39;utilisateur.

  Cette propriété renvoie les noms des clés API, *et non* le secret associé à chaque clé. Le nom d&#39;une clé ne peut pas être utilisé comme clé API.

  La liste est vide si l&#39;utilisateur n&#39;a pas de clés API ou si celles-ci n&#39;ont pas été chargées.
</ResponseField>

<ResponseField name="teams" type="list[str]">
  Noms des équipes de l’utilisateur.

  Il s’agit d’une liste vide si l’utilisateur n’est membre d’aucune équipe ou si les données des équipes n’ont pas été chargées.
</ResponseField>

<ResponseField name="user_api" type="Api | None">
  Une instance de `wandb.Api` utilisant les identifiants d’authentification de l’utilisateur.
</ResponseField>

<div id="arguments">

<ResponseField name="api" type="Api">

</ResponseField>

<ResponseField name="email" type="str">
  Adresse e-mail de l’utilisateur.
</ResponseField>

<ResponseField name="admin" type="bool | None">
  Indique si cet utilisateur doit être administrateur global de l’instance.
</ResponseField>
