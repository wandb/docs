## <Badge color="yellow" size="lg" shape="rounded">Classe</Badge> wandb.apis.public.Projects

Un itérateur paresseux d’objets `Project`.

Une interface itérable permettant d’accéder aux projets créés et enregistrés par l’entité.

```python
service_api: 'ServiceApi',
entity: 'str',
per_page: 'int' = 50
```

<div id="args">
  ## Arguments
</div>

<ResponseField name="service_api" type="ServiceApi">
  L’API de service utilisée pour interroger W&amp;B.
</ResponseField>

<ResponseField name="entity" type="str">
  L’entité propriétaire des projets.
</ResponseField>

<ResponseField name="per_page" type="int">
  Le nombre de projets à récupérer par requête auprès de l’API.
</ResponseField>

<div id="examples">
  ## Exemples
</div>

```python
from wandb.apis.public.api import Api

# Trouver les projets appartenant à cette entité
projects = Api().projects(entity="entity")

# Itérer sur les fichiers
for project in projects:
    print(f"Project: {project.name}")
    print(f"- URL: {project.url}")
    print(f"- Created at: {project.created_at}")
    print(f"- Is benchmark: {project.is_benchmark}")
```
