<div id="properties">
  ## Propriétés
</div>

<ResponseField name="allow_all_artifact_types" type="bool">
  Indique si tous les types d&#39;artefacts sont autorisés dans le registre.

  Si `True`, des artefacts de tout type peuvent être ajoutés. Si `False`, les artefacts sont
  restreints aux types répertoriés dans `artifact_types`.
</ResponseField>

<ResponseField name="artifact_types" type="AddOnlyArtifactTypesList">
  Renvoie les types d&#39;artefacts autorisés dans le registre.

  Si `allow_all_artifact_types` est `True`, `artifact_types` reflète les
  types précédemment enregistrés ou actuellement utilisés dans le registre.
  Si `allow_all_artifact_types` est `False`, les artefacts sont restreints aux
  types figurant dans `artifact_types`.

  Remarque :
  Les types d&#39;artefacts précédemment enregistrés ne peuvent pas être supprimés.
</ResponseField>

<ResponseField name="created_at" type="str">
  Horodatage de la création du registre.
</ResponseField>

<ResponseField name="description" type="str | None">
  Description du registre.
</ResponseField>

<ResponseField name="entity" type="str">
  Entité d&#39;organisation du registre.
</ResponseField>

<ResponseField name="full_name" type="str">
  Nom complet du registre, incluant le préfixe `wandb-registry-`.
</ResponseField>

<ResponseField name="id" type="str">
  ID unique de ce registre.
</ResponseField>

<ResponseField name="internal_id" type="str | None">
  `internalId` GraphQL du projet sous-jacent de ce registre, s&#39;il a été récupéré.

  Il s&#39;agit d&#39;un ID global encodé en base64. Une fois décodé, il se présente sous la forme
  `Project:123` ou `ProjectInternalId:123`.
</ResponseField>

<ResponseField name="name" type="str">
  Nom du registre sans le préfixe `wandb-registry-`.
</ResponseField>

<ResponseField name="organization" type="str">
  Nom de l&#39;organisation du registre.
</ResponseField>

<ResponseField name="path" type="list[str]">
  Aucune description fournie.
</ResponseField>

<ResponseField name="updated_at" type="str | None">
  Horodatage de la dernière mise à jour du registre.
</ResponseField>

<ResponseField name="visibility" type="The visibility level.">
  Visibilité du registre.
</ResponseField>

</div>

```python
self, *members: 'User | UserMember | Team | TeamMember | str'
```

Ajoute des Users ou des équipes à ce registre.

<div id="arguments">
  ##### Arguments
</div>

<ResponseField name="members" type="User | UserMember | Team | TeamMember | str">
  Les Users ou équipes à ajouter au registre. Accepte des objets `User`, des objets `Team` ou leurs ID sous forme de chaîne.
</ResponseField>

<div id="raises">
  ##### Exceptions levées
</div>

* `TypeError`: Si aucun membre n’est passé en argument.
* `ValueError`: S’il est impossible de déduire ou d’analyser les ID d’utilisateur ou d’équipe.

<div id="examples">
  ##### Exemples
</div>

```python
import wandb

api = wandb.Api()

# Récupérer un registre existant
registry = api.registry(name="my-registry", organization="my-org")

user1 = api.user(username="some-user")
user2 = api.user(username="other-user")
registry.add_members(user1, user2)

my_team = api.team(name="my-team")
registry.add_members(my_team)
```

Met à jour le rôle d’un membre (utilisateur ou équipe) dans ce registre.

<div id="arguments-5">
  ##### Arguments
</div>

<ResponseField name="member" type="User | UserMember | Team | TeamMember | str">
  L’utilisateur ou l’équipe dont le rôle doit être mis à jour. Accepte un objet `User`, un objet `Team` ou leur ID sous forme de chaîne.
</ResponseField>

<ResponseField name="role" type="MemberRole | str">
  Le nouveau rôle à attribuer au membre. Peut être l’un des suivants :

  * &quot;admin&quot;
  * &quot;member&quot;
  * &quot;viewer&quot;
  * &quot;restricted&#95;viewer&quot; (si pris en charge par le serveur W&amp;B)
</ResponseField>

<div id="raises-4">
  ##### Exceptions levées
</div>

* `ValueError`: S’il est impossible de déterminer l’ID de l’utilisateur ou de l’équipe.

<div id="examples-3">
  ##### Exemples
</div>

Faites de tous les utilisateurs du registre des administrateurs

```python
import wandb

api = wandb.Api()

# Récupérer un registre existant
registry = api.registry(name="my-registry", organization="my-org")

for member in registry.user_members():
    registry.update_member(member.user, role="admin")
```
