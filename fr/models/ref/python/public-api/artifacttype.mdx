Obtenir toutes les collections d&#39;artifacts associées à ce type d&#39;artifact.

<div id="arguments">
  ##### Arguments
</div>

<ResponseField name="filters" type="Mapping[str, Any] | None">
  Mappage facultatif des filtres à appliquer à la requête.
</ResponseField>

<ResponseField name="order" type="str | None">
  Chaîne facultative permettant de spécifier l’ordre des résultats. S’il est préfixé par &#39;+&#39;, le tri est croissant (par défaut). S’il est préfixé par &#39;-&#39;, le tri est décroissant. Par défaut, l’ordre utilisé est l’ID de la collection, par ordre décroissant.
</ResponseField>

<ResponseField name="per_page" type="int">
  Le nombre de collections d&#39;artifacts à récupérer par page. La valeur par défaut est 50.
</ResponseField>

<ResponseField name="start" type="str | None">
  Curseur de pagination pour reprendre une requête antérieure, capturé à partir de l’attribut `.cursor` d’un paginateur précédent.
</ResponseField>
