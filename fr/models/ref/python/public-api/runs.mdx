<div id="class-wandbapispublicruns">
  ## <Badge color="yellow" size="lg" shape="rounded">Classe</Badge> wandb.apis.public.Runs
</div>

Un itérateur paresseux d’objets `Run` associé à un projet et à un filtre facultatif.

Les runs sont récupérés par pages depuis le serveur W&amp;B selon les besoins.

Cet objet est généralement utilisé indirectement via l’espace de noms `Api.runs`.

```python
(service_api: 'ServiceApi',
entity: 'str',
project: 'str',
filters: 'dict[str, Any] | None' = None,
order: 'str' = '+created_at',
per_page: 'int' = 50,
include_sweeps: 'bool' = False,
lazy: 'bool' = True,
api_key: 'str | None' = None)
```

<div id="args">
  ## Arguments
</div>

<ResponseField name="service_api" type="ServiceApi">
  L’API de service à utiliser pour les requêtes.
</ResponseField>

<ResponseField name="entity" type="str">
  L’entité (nom d’utilisateur ou équipe) propriétaire du projet.
</ResponseField>

<ResponseField name="project" type="str">
  Le nom du projet depuis lequel récupérer les runs.
</ResponseField>

<ResponseField name="filters" type="dict[str, Any] | None">
  Filtres à appliquer à la requête de runs.
</ResponseField>

<ResponseField name="order" type="str">
  L’ordre peut être `created_at`, `heartbeat_at`, `config.*.value` ou `summary_metrics.*`. Si l’ordre est précédé de `+`, le tri est croissant (par défaut). Si l’ordre est précédé de `-`, le tri est décroissant. Par défaut, l’ordre est `run.created&#95;at`, du plus ancien au plus récent.
</ResponseField>

<ResponseField name="per_page" type="int">
  Le nombre de runs à récupérer par requête (50 par défaut).
</ResponseField>

<ResponseField name="include_sweeps" type="bool">
  Indique s’il faut inclure les informations sur les Sweeps dans les runs. La valeur par défaut est `True`.
</ResponseField>

<ResponseField name="lazy" type="bool">
  Indique s’il faut différer le chargement des champs volumineux (`config`, `summaryMetrics`, `systemMetrics`) jusqu’à ce qu’ils soient consultés. La valeur par défaut est `True`.
</ResponseField>

<ResponseField name="api_key" type="str | None">
  Aucune description fournie.
</ResponseField>

Met à niveau cette collection de Runs du mode paresseux au mode complet.

Bascule vers la récupération des données complètes des runs et
met à niveau tous les objets Run déjà chargés afin qu&#39;ils contiennent l&#39;ensemble des données.
Utilise le chargement en parallèle pour de meilleures performances lors de la mise à niveau de plusieurs runs.
