## <Badge color="yellow" size="lg" shape="rounded">Classe</Badge> wandb.apis.public.File

Fichier enregistré dans W&amp;B.

Représente un fichier unique stocké dans W&amp;B. Donne accès aux métadonnées du fichier.
Les fichiers sont associés à un run spécifique et
peuvent inclure des fichiers texte, des poids de modèle, des jeux de données, des visualisations et d’autres
Artifacts. Vous pouvez télécharger le fichier, le supprimer et accéder à ses
propriétés.

Spécifiez un ou plusieurs attributs dans un dictionnaire pour identifier un
fichier spécifique enregistré dans un run spécifique. Vous pouvez effectuer une recherche à l’aide des clés suivantes :

* id (str): ID du run qui contient le fichier
* name (str): nom du fichier
* url (str): chemin vers le fichier
* direct&#95;url (str): chemin vers le fichier dans le bucket
* sizeBytes (int): taille du fichier en octets
* md5 (str): md5 du fichier
* mimetype (str): type MIME du fichier
* updated&#95;at (str): horodatage de la dernière mise à jour
* path&#95;uri (str): chemin vers le fichier dans le bucket, actuellement disponible uniquement pour les objets S3 et les fichiers de référence

<div id="arguments">
  ##### Arguments
</div>

<ResponseField name="root" type="str">
  Répertoire local où enregistrer le fichier. La valeur par défaut est le répertoire de travail actuel (&quot;.&quot;).
</ResponseField>

<ResponseField name="replace" type="bool">
  Si `True`, le téléchargement écrase un fichier local s&#39;il existe. La valeur par défaut est `False`.
</ResponseField>

<ResponseField name="exist_ok" type="bool">
  Si `True`, ne déclenche pas de `ValueError` si le fichier existe déjà et ne le retélécharge pas, sauf si `replace=True`. La valeur par défaut est `False`.
</ResponseField>

<ResponseField name="api" type="Api | None">
  Si spécifié, l&#39;instance `Api` utilisée pour télécharger le fichier.
</ResponseField>
