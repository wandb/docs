<div id="attributes">
  ## Attributs
</div>

* `paths` : chemins des fichiers d’historique téléchargés.
* `errors` : dictionnaire associant les chemins de fichiers aux messages d’erreur des fichiers dont le téléchargement a échoué. `None` si tous les téléchargements ont réussi.
* `contains_live_data` : indique si le run contient des données en temps réel, qui n’ont pas encore été exportées vers des fichiers parquet.
