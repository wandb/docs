<div id="attributes">
  ## Attributs
</div>

* `number` : Position de la ligne dans le journal de la console du run, à partir de 0.
* `timestamp` : Heure à laquelle la ligne a été capturée, sous la forme d’une date et heure UTC tenant compte du fuseau horaire. None si le backend n’a pas enregistré d’heure pour la ligne ou en a envoyé une dans un format inattendu.
* `level` : Niveau de gravité de la ligne : `"error"` pour les lignes écrites sur stderr, vide sinon.
* `label` : Étiquette identifiant le processus qui a écrit la ligne lorsque plusieurs processus écrivent dans le même run, telle que définie par le paramètre `x_label` en mode partagé. Vide pour les runs avec un seul processus d’écriture.
* `content` : Texte de la ligne.
