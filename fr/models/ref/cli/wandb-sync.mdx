<div id="usage">
  ## Utilisation
</div>

```bash
sync [OPTIONS] [PATHS]...
```

<div id="description">
  ## Description
</div>

Téléversez vers le cloud des données de run W&amp;B existantes en local.

Synchronisez vers le serveur W&amp;B les runs hors ligne ou incomplets. Fournissez PATHS pour synchroniser
des runs spécifiques, ou lancez la commande sans arguments pour synchroniser les runs non téléversés du
dossier wandb.

Si aucun PATHS n&#39;est fourni, une confirmation est demandée avant la
synchronisation. Passez --yes pour ignorer la confirmation ou --dry-run pour quitter sans
synchroniser.

PATHS doit correspondre à des répertoires de run, généralement au format

./wandb/run-YYYYMMDD&#95;HHMMSS-RUN&#95;ID

YYYYMMDD&#95;HHMMSS est l&#39;horodatage de création du run et RUN&#95;ID
son ID unique.

Par exemple, pour afficher une synthèse des runs locaux et de leur statut de synchronisation :

```bash
wandb sync --dry-run
```

Pour synchroniser le run avec l&#39;ID du run abcd1234 enregistré dans ./wandb/run-20170617&#95;000000-abcd1234 :

```bash
wandb sync ./wandb/run-20170617_000000-abcd1234
```

Pour synchroniser tous les runs non synchronisés du dossier wandb :

```bash
wandb sync
```

Utilisez `wandb clean` pour supprimer les données locales des runs déjà synchronisés. Voir

```bash
wandb clean --help
```

pour plus d&#39;informations.

<div id="options">
  ## Options
</div>

| Flag                                 | Type      | Description                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------------------ | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `-v, --verbose`                      | Flag BOOL | Affiche davantage d&#39;informations. **Par défaut** : False                                                                                                                                                                                                                                                                                                           |
| `--yes`                              | Flag BOOL | Ne pas demander de confirmation. **Par défaut** : False                                                                                                                                                                                                                                                                                                                |
| `--id`                               | STR       | Téléverse vers un ID du run existant. Si cette option est définie lors de la synchronisation de plusieurs fichiers (avec la même entité et le même projet), les fichiers sont synchronisés par ordre d&#39;heure de démarrage. **Par défaut** : None                                                                                                                   |
| `--project, -p`                      | STR       | Redéfinit le projet pour tous les runs synchronisés. **Par défaut** : None                                                                                                                                                                                                                                                                                             |
| `--entity, -e`                       | STR       | Redéfinit l&#39;entité pour tous les runs synchronisés. **Par défaut** : None                                                                                                                                                                                                                                                                                          |
| `--job-type`                         | STR       | Redéfinit le type de job pour tous les runs synchronisés. **Par défaut** : None                                                                                                                                                                                                                                                                                        |
| `--include-online, --no-skip-online` | Flag BOOL | Inclut les runs créés en mode en ligne. **Par défaut** : None                                                                                                                                                                                                                                                                                                          |
| `--include-synced, --no-skip-synced` | Flag BOOL | Inclut les runs déjà synchronisés. **Par défaut** : None                                                                                                                                                                                                                                                                                                               |
| `--replace-tags`                     | STR       | Renomme les tags au format &#39;old1=new1,old2=new2&#39;. **Par défaut** : None                                                                                                                                                                                                                                                                                        |
| `--dry-run`                          | Flag BOOL | Affiche ce qui se passerait sans rien téléverser. **Par défaut** : False                                                                                                                                                                                                                                                                                               |
| `-n`                                 | INT       | Nombre maximal de runs à synchroniser en même temps. Lors de la synchronisation de plusieurs fichiers appartenant au même run, les fichiers sont synchronisés séquentiellement par ordre d&#39;heure de démarrage, quelle que soit la valeur de ce paramètre. C&#39;est le cas pour les runs repris ou lors de l&#39;utilisation du paramètre --id. **Par défaut** : 5 |
