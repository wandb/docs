## Utilisation {#usage}

```bash
describe [OPTIONS] JOB
```

## Description {#description}

Décrivez un job Launch. Indiquez le job Launch sous la forme
de : entité/projet/nom-du-job:alias-ou-version.

## Arguments {#arguments}

| Nom   | Par défaut | Type |
| ----- | ---------- | ---- |
| `job` | STR        | True |
