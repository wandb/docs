<div id="usage">
  ## Utilisation
</div>

```bash
inspect [OPTIONS] [PATH]
```

<div id="description">
  ## Description
</div>

Parcourez les enregistrements bruts du journal de transactions .wandb d’une exécution.

Ouvre une liste consultable des enregistrements stockés dans le journal, accompagnée d’une
vue texte de l’enregistrement sélectionné. Lorsque stdout n’est pas un terminal,
affiche plutôt les enregistrements au format texte, par exemple :

wandb leet inspect run.wandb | less

PATH peut être un fichier .wandb, un répertoire d’exécution qui en contient un ou un
répertoire wandb. Si PATH n’est pas fourni, la dernière exécution est utilisée.
