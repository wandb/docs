## Utilisation {#usage}

```bash
run [OPTIONS] [PATH]
```

## Description {#description}

Lancez l’interface terminal LEET.

LEET est une interface terminal permettant d’afficher un run W&amp;B indiqué par un PATH facultatif.

PATH peut inclure un fichier .wandb, un répertoire de run contenant un fichier .wandb,
ou une URL de run W&amp;B.
Si PATH n’est pas fourni, la commande recherche le run le plus récent.

| Nom    | Par défaut | Type  |
| ------ | ---------- | ----- |
| `path` | STR        | False |
