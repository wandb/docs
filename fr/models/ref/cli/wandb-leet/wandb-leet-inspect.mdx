## Utilisation {#usage}

```bash
inspect [OPTIONS] [PATH]
```

## Description {#description}

Parcourez les enregistrements bruts du journal de transactions `.wandb` d&#39;une exécution.

Ouvre une liste navigable des enregistrements stockés dans le journal, accompagnée d&#39;une
vue texte de l&#39;enregistrement sélectionné. Lorsque stdout n&#39;est pas un terminal,
affiche les enregistrements sous forme de texte, par exemple :

wandb leet inspect run.wandb | less

PATH peut être un fichier `.wandb`, un répertoire d&#39;exécution qui en contient un ou un
répertoire wandb. Si PATH n&#39;est pas fourni, la dernière exécution est utilisée.

## Arguments {#arguments}

| Nom    | Par défaut | Type  |
| ------ | ---------- | ----- |
| `path` | STR        | False |

| Indicateur   | Type            | Description                                          |
