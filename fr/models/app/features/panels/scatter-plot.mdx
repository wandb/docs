Utilisez les nuages de points dans W&amp;B pour comparer des runs et visualiser les relations entre les métriques d’expérience. Les nuages de points vous aident à repérer des tendances, des valeurs aberrantes et des compromis entre de nombreux runs, ce qui est utile pour ajuster les hyperparamètres ou comparer des variantes de modèle.

<div id="use-case">
  ## Cas d’usage
</div>

Utilisez des nuages de points pour comparer plusieurs runs et visualiser les performances d’une expérience.

Avec un nuage de points, vous pouvez :

* Affichez des lignes pour les valeurs minimales, maximales et moyennes.
* Personnalisez les infobulles des métadonnées.
* Définissez la couleur des points.
* Ajustez les plages des axes.
* Utilisez une échelle logarithmique pour les axes.
* Configurez la façon dont la **ligne frontière** et les points associés sont étiquetés et mis en évidence. Voir [Options d’affichage de la ligne frontière](#frontier-line-display-options).
* Ajoutez des **lignes de référence** pour marquer des seuils ou des valeurs cibles sur un axe. Voir [Options d’affichage des lignes de référence](#reference-line-display-options).

<div id="create-a-scatter-plot">
  ## Créer un nuage de points
</div>

Pour créer un nuage de points dans l’interface W&amp;B :

1. Accédez à l’onglet **Workspaces**.
2. Dans le panneau **Charts**, cliquez sur le menu d’action **(<Icon icon="ellipsis" iconType="solid" />)**.
3. Dans le menu contextuel, sélectionnez **Add panels**.
4. Dans le menu **Add panels**, sélectionnez **Scatter plot**.
5. Définissez les axes `x` et `y` pour tracer les données que vous souhaitez afficher. Vous pouvez également définir des valeurs minimale et maximale pour vos axes ou ajouter un axe `z`.
6. Cliquez sur **Apply** pour créer le nuage de points.

Le nouveau nuage de points apparaît dans le panneau **Charts**, avec les données que vous avez configurées.

<div id="frontier-line-display-options">
  ## Options d’affichage de la ligne frontière
</div>

Sur un nuage de points, la *ligne frontière* relie les valeurs les plus hautes et les plus basses de l’axe Y observées jusque-là dans les données du graphique. Vous pouvez ajuster l’apparence de cette ligne et des points environnants dans les paramètres du graphique pour mettre en évidence la frontière.

Pour configurer les options d’affichage de la ligne frontière :

1. Survolez le panneau du nuage de points, puis cliquez sur l’icône d’engrenage pour ouvrir le volet latéral des paramètres du panneau.
2. Sélectionnez l’onglet **Annotations**.
3. Définissez les options :
   * **Show run labels** : Basculez l’affichage d’une étiquette contenant le nom du run ou du groupe.
   * **Dim non-frontier points** : Basculez l’atténuation visuelle des points qui ne se trouvent pas sur la ligne frontière afin de mieux faire ressortir celle-ci.
4. Cliquez sur **Apply** pour enregistrer vos modifications.

Le nuage de points se met à jour pour refléter vos choix d’annotation.

<div id="reference-line-display-options">
  ## Options d’affichage des lignes de référence
</div>

Une *ligne de référence* est une ligne pointillée horizontale ou verticale tracée à une valeur numérique fixe sur l’axe X ou Y. Utilisez des lignes de référence pour indiquer des seuils, des valeurs de référence ou des valeurs cibles sur un graphique.

Pour configurer les lignes de référence :

1. Survolez le panneau du nuage de points, puis cliquez sur l’icône d’engrenage pour ouvrir le volet latéral des paramètres du panneau.
2. Sélectionnez l’onglet **Lignes de référence**.
3. Cliquez sur **Ajouter une ligne de référence**.
4. Configurez la ligne :
   * Pour choisir une couleur, cliquez sur l’échantillon de couleur.
   * Sélectionnez **Axe X** ou **Axe Y** dans la liste déroulante.
   * Saisissez une valeur numérique pour tracer la ligne à cet endroit sur l’axe.
   * Facultatif : saisissez un libellé.
5. Répétez l’opération pour ajouter d’autres lignes. Un compteur à côté de **Ajouter une ligne de référence** indique combien de lignes, sur le maximum autorisé, vous avez utilisées.
6. Cliquez sur **Appliquer** pour enregistrer vos modifications.

Le nuage de points se met à jour pour refléter votre configuration de lignes de référence.

Pour supprimer une ligne de référence, cliquez sur le bouton de fermeture (<Icon icon="xmark" iconType="solid" />) de sa ligne.

Les lignes de référence présentent le comportement et les limites suivants :

* Vous pouvez ajouter au maximum cinq lignes de référence par graphique, tous axes confondus, et non cinq par axe.
* Seuls les axes numériques prennent en charge les lignes de référence. Les axes temporels ne les prennent pas en charge. La liste déroulante des axes répertorie uniquement les axes admissibles. Si ni l’axe X ni l’axe Y n’est numérique, l’onglet **Lignes de référence** affiche `Reference lines require a numeric X or Y axis.` et vous ne pouvez pas ajouter de ligne.
* Sur un axe utilisant une échelle logarithmique, la valeur d’une ligne de référence doit être supérieure à zéro.
* Chaque ligne s’affiche sous forme de ligne pointillée dans la couleur qui lui est attribuée. La couleur par défaut est sarcelle.
* Le libellé de la ligne sur le graphique affiche la valeur suivie du texte du libellé, par exemple `0.9 - Quality target`. Si vous laissez le libellé vide, le graphique affiche uniquement la valeur. Le graphique tronque ce libellé combiné à 35 caractères et conserve le libellé complet dans la configuration du panneau.
* Lorsque les lignes sont proches les unes des autres, W&amp;B décale automatiquement leurs libellés afin qu’ils ne se chevauchent pas.
