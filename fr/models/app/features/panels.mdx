Utilisez les visualisations de panneaux du Workspace pour explorer vos [données enregistrées](/fr/models/ref/python/experiments/run.md/#method-runlog) selon leurs clés, visualiser les relations entre les hyperparamètres et les métriques de sortie, et bien plus encore. Cette page explique comment choisir un mode de Workspace, ajouter et configurer des panneaux, les organiser en sections et les partager avec des collaborateurs.

<div id="workspace-modes">
  ## Modes de Workspace
</div>

Les projets W&amp;B prennent en charge deux modes de Workspace différents. L’icône à côté du nom du Workspace indique son mode.

| Icon                                                                                                  | Mode de Workspace                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <img src="/images/app_ui/automated_workspace.svg" alt="icône de Workspace automatisé" width="32px" /> | **Les Workspaces automatisés** génèrent automatiquement des panneaux pour toutes les clés enregistrées dans le projet. Choisissez un Workspace automatique :<ul><li>Pour démarrer rapidement en visualisant toutes les données disponibles du projet.</li><li>Pour les projets de plus petite taille qui enregistrent moins de clés.</li><li>Pour une analyse plus globale.</li></ul>Si vous supprimez un panneau d’un Workspace automatique, vous pouvez utiliser le [générateur rapide de panneaux](#quick-panel-builder) pour le recréer.                                               |
| <img src="/images/app_ui/manual_workspace.svg" alt="icône de Workspace manuel" width="32px" />        | **Les Workspaces manuels** démarrent comme des pages vierges et n’affichent que les panneaux que vous ajoutez intentionnellement. Choisissez un Workspace manuel :<ul><li>Lorsque seule une partie des clés enregistrées dans le projet vous intéresse.</li><li>Pour une analyse plus ciblée.</li><li>Pour améliorer les performances d’un Workspace en évitant de charger des panneaux qui vous sont moins utiles.</li></ul>Utilisez le [générateur rapide de panneaux](#quick-panel-builder) pour remplir rapidement un Workspace manuel et ses sections avec des visualisations utiles. |

Pour modifier la façon dont un Workspace génère des panneaux, [réinitialisez le Workspace](#reset-a-workspace).

<Note>
  **Annuler les modifications apportées à votre Workspace**

  Pour annuler les modifications apportées à votre Workspace, cliquez sur le bouton Undo (flèche pointant vers la gauche) ou appuyez sur **Cmd+Z** (macOS) ou **Ctrl+Z** (Windows ou Linux).
</Note>

<div id="reset-a-workspace">
  ## Réinitialiser un Workspace
</div>

Réinitialisez un Workspace pour en modifier le mode ou effacer ses panneaux afin de repartir de zéro.

Pour réinitialiser un Workspace :

1. En haut du Workspace, cliquez sur le **menu d’actions (<Icon icon="ellipsis" iconType="solid" />)**.
2. Cliquez sur **Réinitialiser le Workspace**.

<div id="configure-the-workspace-layout">
  ## Configurer la mise en page du Workspace
</div>

Les paramètres de mise en page du Workspace contrôlent la manière dont les panneaux et les sections sont organisés et affichés dans l’ensemble du Workspace.

Pour configurer la mise en page du Workspace, cliquez sur **Settings** en haut du Workspace, puis sur **Workspace layout**. Les paramètres suivants sont disponibles :

* **Masquer les sections vides pendant la recherche** (activé par défaut)
* **Trier les panneaux par ordre alphabétique** (désactivé par défaut)
* **Organisation des sections** (regroupées selon le premier préfixe par défaut). Pour modifier ce paramètre :
  1. Cliquez sur l&#39;icône de cadenas.
  2. Choisissez comment regrouper les panneaux dans une section.

Pour configurer les valeurs par défaut des graphiques en courbes du Workspace, référez-vous à [Graphiques en courbes](/fr/models/app/features/panels/line-plot/).

<div id="configure-a-sections-layout">
  ### Configurer la mise en page d’une section
</div>

Pour configurer la mise en page d’une section, cliquez sur son icône d’engrenage, puis sur **Préférences d’affichage**. Les paramètres suivants sont disponibles :

* **Activer ou désactiver les noms de run en couleur dans les infobulles** (activé par défaut)
* **Afficher uniquement le run mis en surbrillance dans les infobulles du graphique associé** (désactivé par défaut)
* **Nombre de runs affichés dans les infobulles** (un seul run, tous les runs ou **Par défaut**)
* **Afficher les noms complets des runs dans l’infobulle du graphique principal** (désactivé par défaut)

<div id="view-a-panel-in-full-screen-mode">
  ## Afficher un panneau en mode plein écran
</div>

Le mode plein écran donne plus d’espace à un panneau, ce qui est utile pour examiner vos données de plus près. En mode plein écran, le sélecteur de run s’affiche.

Pour afficher un panneau en mode plein écran :

1. Survolez le panneau.
2. Cliquez sur le menu **d’actions (<Icon icon="ellipsis" iconType="solid" />)** du panneau, puis sur le bouton plein écran, qui ressemble à un viseur ou à un contour montrant les quatre coins d’un carré.
   <Frame>
     <img src="/images/app_ui/panel_fullscreen.png" alt="Panneau en plein écran" />
   </Frame>

Lorsque vous [partagez le panneau](#share-a-panel) tout en l’affichant en mode plein écran, le lien généré s’ouvre automatiquement en mode plein écran.

Lorsque vous travaillez en mode plein écran, utilisez les conseils suivants :

* Pour revenir au Workspace du panneau depuis le mode plein écran, cliquez sur la flèche pointant vers la gauche en haut de la page.
* Pour naviguer entre les panneaux d’une section sans quitter le mode plein écran, utilisez soit les boutons **Précédent** et **Suivant** sous le panneau, soit les touches fléchées gauche et droite.
* Pour libérer davantage d’espace pour le panneau, réduisez le sélecteur de run avec **Cmd+.** (macOS) ou **Ctrl+.** (Windows ou Linux).
* Lorsque vous affichez une image d’un [panneau multimédia](/fr/models/app/features/panels/media) en mode plein écran, les raccourcis clavier permettent de zoomer ou dézoomer, de réinitialiser le zoom ou d’adapter le zoom à l’écran. Voir [Raccourcis clavier](/fr/models/app/keyboard-shortcuts#media-panels).

Voir [Raccourcis clavier](/fr/models/app/keyboard-shortcuts) pour les autres raccourcis du mode plein écran et des panneaux.

<div id="add-panels">
  ## Ajouter des panneaux
</div>

Les sections suivantes décrivent comment ajouter des panneaux à votre Workspace. Vous pouvez ajouter des panneaux un par un ou automatiquement pour chaque clé sélectionnée. Vous pouvez également demander à ARIA d&#39;ajouter des panneaux pour vous.

<div id="add-a-panel-manually">
  ### Ajouter un panneau manuellement
</div>

Ajoutez des panneaux à votre Workspace, un à la fois, soit globalement dans le Workspace, soit au niveau de la section.

<div id="add-panels-to-a-workspace">
  #### Ajouter des panneaux à un Workspace
</div>

1. Accédez au Workspace de votre projet.
2. Cliquez sur **ajouter des panneaux**, à droite du champ de recherche de panneaux.
3. Dans la fenêtre modale qui s’affiche, sélectionnez le type de panneau à ajouter, par exemple un graphique, un contenu multimédia ou un panneau de requête.

<div id="add-panels-to-a-section">
  #### Ajouter des panneaux à une section
</div>

1. Accédez à votre Workspace de projet.
2. Facultatif : créez une nouvelle section. Faites défiler jusqu’en bas du Workspace et cliquez sur **Ajouter une section**.
3. Cliquez sur le menu **d’actions (<Icon icon="ellipsis" iconType="solid" />)** de la section, puis sur **+ Ajouter des panneaux**.
4. Dans la fenêtre modale qui s’affiche, sélectionnez le type de panneau à ajouter, par exemple un graphique, un média ou un panneau de requête.

  <img src="/images/app_ui/add_single_panel.gif" alt="Démo de l'ajout d'un panneau" />
</Frame>

<div id="quick-panel-builder">
  ### Générateur rapide de panneaux
</div>

Utilisez le **générateur rapide de panneaux** pour créer automatiquement des panneaux pour les clés de métriques sélectionnées au niveau du Workspace ou d’une section.

<Note>
  Dans un Workspace automatique, le **générateur rapide de panneaux** est masqué si des panneaux existent déjà pour toutes les clés enregistrées. Si vous supprimez un panneau, utilisez le **générateur rapide de panneaux** pour l’ajouter de nouveau.
</Note>

Vous pouvez créer des panneaux de deux façons avec le **générateur rapide de panneaux** :

| Option                             | Description                                                                                                                                                                        |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Panneaux à clé unique**          | Sélectionnez des clés spécifiques. W&amp;B crée un panneau distinct pour chaque clé de métrique et compare cette métrique entre les runs visibles.                                 |
| **Panneaux à plusieurs métriques** | Saisissez une expression régulière RE2. W&amp;B crée un panneau contenant toutes les clés de métriques correspondant à l’expression, y compris celles enregistrées ultérieurement. |

Par exemple, supposons que votre Workspace inclue les clés de métriques `train/loss` et `val/loss`. Vous pouvez utiliser le **générateur rapide de panneaux** pour créer des panneaux de l’une des façons suivantes :

* **Panneaux à clé unique** : crée deux panneaux, un pour `train/loss` et un pour `val/loss`.
* **Panneaux à plusieurs métriques** : l’expression régulière `.*\/loss` crée un panneau contenant les deux métriques.

<div id="add-panels-to-the-workspace">
  #### Ajouter des panneaux au Workspace
</div>

1. Accédez au Workspace de votre projet.
2. Sélectionnez **ajouter des panneaux** à côté du champ de recherche de panneaux, puis sélectionnez **générateur rapide de panneaux**.
3. Sélectionnez **Panneaux à clé unique** ou **Panneaux à plusieurs métriques**.
4. Indiquez les clés de métrique ou une expression régulière dans le champ de recherche.
5. Effectuez l’étape suivante selon le mode de création :
   * **Panneaux à clé unique** : Survolez une clé de métrique, puis sélectionnez **Ajouter**. Répétez l’opération pour chaque clé de métrique à ajouter.
   * **Panneaux à plusieurs métriques** : Indiquez une expression régulière pour créer un panneau contenant les clés de métrique correspondantes. Cliquez sur **Ajouter un panneau**.

<div id="add-panels-to-a-section-2">
  #### Ajouter des panneaux à une section
</div>

1. Accédez au Workspace de votre projet.
2. Facultatif : pour créer une section, faites défiler jusqu’en bas du Workspace et sélectionnez **Ajouter une section**.
3. Dans la section, sélectionnez **ajouter un panneau**, puis sélectionnez **générateur rapide de panneaux**.
4. Sélectionnez **panneaux à clé unique** ou **panneaux à plusieurs métriques**.
5. Spécifiez les clés de métrique ou l’expression régulière dans le champ de recherche.
6. Effectuez l’étape suivante selon le mode de création :
   * **panneaux à clé unique** : survolez une clé de métrique, puis sélectionnez **ajouter**. Répétez l’opération pour chaque clé de métrique que vous souhaitez ajouter.
   * **panneaux à plusieurs métriques** : spécifiez une expression régulière pour créer un panneau contenant les clés de métrique correspondantes. Cliquez sur **ajouter un panneau**.

<Tip>
  Vous pouvez également demander à ARIA d’ajouter des panneaux pour vous :

  <AriaChatBubbles prompt="Ajoute des panneaux de graphique en courbes pour chaque métrique sous le préfixe train/." response="Je vais ajouter des panneaux de graphique en courbes pour chaque métrique train/ enregistrée dans les runs visibles et les organiser dans votre Workspace." />
</Tip>

<div id="share-a-panel">
  ## Partager un panneau
</div>

Partagez un panneau pour envoyer les collaborateurs directement vers une vue ciblée d’une visualisation spécifique sans passer par le Workspace complet. Pour partager un panneau à l’aide d’un lien, effectuez l’une des opérations suivantes :

* Lorsque le panneau est affiché en mode plein écran, copiez l’URL dans le navigateur.
* Cliquez sur le menu **d’actions (<Icon icon="ellipsis" iconType="solid" />)**, puis sélectionnez **Copier l’URL du panneau**.

Partagez le lien avec l’utilisateur ou l’équipe. Lorsqu’il accède au lien, le panneau s’ouvre en [mode plein écran](#view-a-panel-in-full-screen-mode).

Pour revenir au Workspace du panneau depuis le mode plein écran, cliquez sur la flèche vers la gauche en haut de la page.

<div id="compose-a-panels-full-screen-link-programmatically">
  ### Composer par programmation le lien plein écran d’un panneau
</div>

Lorsque vous [créez une automatisation](/fr/models/automations/) ou un flux de travail similaire, il peut être utile d’inclure l’URL du panneau en plein écran. Le format suivant présente l’URL d’un panneau en plein écran. Dans l’exemple suivant, remplacez les noms de l’entité, du projet, du panneau et de la section entre crochets.

```text
https://wandb.ai/[ENTITY_NAME]/[PROJECT_NAME]?panelDisplayName=[PANEL_NAME]&panelSectionName=[SECTION_NAME]
```

Si plusieurs panneaux d’une même section portent le même nom, cette URL ouvre le premier panneau portant ce nom.

<div id="embed-or-share-a-panel-on-social-media">
  ### Intégrer ou partager un panneau sur les réseaux sociaux
</div>

Pour intégrer un panneau à un site web ou le partager sur les réseaux sociaux, le panneau doit être accessible à toute personne disposant du lien. Si un projet est privé, seuls les membres du projet peuvent consulter le panneau. Si le projet est public, toute personne disposant du lien peut consulter le panneau.

Pour obtenir le code permettant d’intégrer ou de partager un panneau sur les réseaux sociaux :

1. Depuis le Workspace, survolez le panneau, puis cliquez sur son menu d’actions **(<Icon icon="ellipsis" iconType="solid" />)**.
2. Cliquez sur l’onglet **Partager**.
3. Remplacez **Seules les personnes invitées ont accès** par **Toute personne disposant du lien peut voir**. Sinon, les options de l’étape suivante ne sont pas disponibles.
4. Choisissez **Partager sur Twitter**, **Partager sur Reddit**, **Partager sur LinkedIn** ou **Copier le lien d’intégration**.

<div id="email-a-panel-report">
  ### Envoyer par e-mail un report de panneau
</div>

Pour envoyer par e-mail un seul panneau sous forme de report autonome :

1. Survolez le panneau, puis cliquez sur le **menu d’actions (<Icon icon="ellipsis" iconType="solid" />)** du panneau.
2. Cliquez sur **Share panel in report**.
3. Sélectionnez l&#39;onglet **Invite**.
4. Saisissez une adresse e-mail ou un nom d&#39;utilisateur.
5. Facultatif : remplacez **can view** par **can edit**.
6. Cliquez sur **Invite**. W&amp;B envoie un e-mail à l&#39;utilisateur avec un lien vers le report contenant uniquement le panneau que vous partagez.

Contrairement au [partage d&#39;un panneau](#share-a-panel), le destinataire ne peut pas accéder au Workspace depuis ce report.

<div id="manage-panels">
  ## Gérer les panneaux
</div>

Après avoir ajouté des panneaux à un Workspace, vous pouvez les modifier, les déplacer, les dupliquer ou les supprimer pour que vos visualisations restent organisées et à jour.

<div id="edit-a-panel">
  ### Modifier un panneau
</div>

Pour modifier un panneau :

1. Cliquez sur son icône en forme de crayon.
2. Modifiez les paramètres du panneau.
3. Facultatif : pour changer le type du panneau, sélectionnez le type, puis configurez les paramètres.
4. Cliquez sur **Appliquer**.

<div id="move-a-panel">
  ### Déplacer un panneau
</div>

Pour déplacer un panneau vers une autre section, vous pouvez utiliser la poignée de déplacement du panneau. Pour sélectionner plutôt la nouvelle section dans une liste :

1. Facultatif : créez une nouvelle section en cliquant sur **Add section** après la dernière section.
2. Cliquez sur le menu **d’actions (<Icon icon="ellipsis" iconType="solid" />)** du panneau.
3. Cliquez sur **Move**, puis sélectionnez une nouvelle section.

Vous pouvez également utiliser la poignée de déplacement pour réorganiser les panneaux dans une section.

<div id="duplicate-a-panel">
  ### Dupliquer un panneau
</div>

Pour dupliquer un panneau :

1. En haut du panneau, cliquez sur le menu d’actions **(<Icon icon="ellipsis" iconType="solid" />)**.
2. Cliquez sur **Dupliquer**.

Si vous le souhaitez, vous pouvez [personnaliser](#edit-a-panel) ou [déplacer](#move-a-panel) le panneau dupliqué.

<div id="remove-panels">
  ### Supprimer des panneaux
</div>

Pour supprimer un panneau :

1. Survolez le panneau.
2. Cliquez sur le menu d’actions **(<Icon icon="ellipsis" iconType="solid" />)**.
3. Cliquez sur **Supprimer**.

Pour supprimer tous les panneaux d’un Workspace manuel, cliquez sur son menu d’actions **(<Icon icon="ellipsis" iconType="solid" />)**, puis sur **Effacer tous les panneaux**.

Pour supprimer tous les panneaux d’un Workspace automatique ou manuel, vous pouvez [réinitialiser le Workspace](#reset-a-workspace). Sélectionnez **Automatique** pour repartir avec l’ensemble de panneaux par défaut, ou sélectionnez **Manuel** pour repartir avec un Workspace vide, sans aucun panneau.

<div id="manage-sections">
  ## Gérer les sections
</div>

Les sections regroupent les panneaux associés, ce qui facilite la navigation dans les grands Workspaces. Par défaut, les sections d’un Workspace reflètent la hiérarchie de logging de vos clés. Cependant, dans un Workspace manuel, les sections n’apparaissent qu’une fois que vous commencez à ajouter des panneaux.

<div id="add-a-section">
  ### Ajouter une section
</div>

Pour ajouter une section, cliquez sur **Add section** après la dernière section.

Pour ajouter une nouvelle section avant ou après une section existante, vous pouvez également cliquer sur le menu **d’actions (<Icon icon="ellipsis" iconType="solid" />)** de la section, puis sur **New section below** ou **New section above**.

<Warning>
  Ne donnez pas le nom « Section » à une section. En raison d’une limitation connue, les panneaux de cette section ne s’affichent pas tant que vous n’avez pas renommé la section.
</Warning>

<div id="manage-a-sections-panels">
  ### Gérer les panneaux d&#39;une section
</div>

Dans une section, vous pouvez redimensionner les panneaux, contrôler la pagination et supprimer des panneaux individuels. Les sections comportant un grand nombre de panneaux sont paginées par défaut. Le nombre de panneaux affichés par défaut sur une page dépend de la configuration du panneau et de la taille des panneaux dans la section.

Pour redimensionner un panneau, survolez-le, cliquez sur la poignée de redimensionnement, puis faites-la glisser pour ajuster sa taille. Le redimensionnement d&#39;un panneau redimensionne tous les panneaux de la section.

Si une section est paginée, vous pouvez personnaliser le nombre de panneaux à afficher sur une page :

1. En haut de la section, cliquez sur **1 à `[X]` sur `[Y]`**, où `[X]` correspond au nombre de panneaux visibles et `[Y]` au nombre total de panneaux.
2. Choisissez le nombre de panneaux à afficher par page, jusqu&#39;à 100.

Pour supprimer un panneau d&#39;une section :

1. Survolez le panneau, puis cliquez sur son menu **d’actions (<Icon icon="ellipsis" iconType="solid" />)**.
2. Cliquez sur **Supprimer**.

Si vous réinitialisez un Workspace pour revenir à un Workspace automatisé, tous les panneaux supprimés réapparaissent.

<div id="rename-a-section">
  ### Renommer une section
</div>

Pour renommer une section, cliquez sur son menu **d’actions (<Icon icon="ellipsis" iconType="solid" />)**, puis sur **Renommer la section**.

<Warning>
  Ne donnez pas à une section le nom « Section ». En raison d’une limitation connue, les panneaux de cette section ne s’afficheront pas tant que la section n’aura pas été renommée.
</Warning>

<div id="delete-a-section">
  ### Supprimer une section
</div>

Pour supprimer une section, cliquez sur le menu **d’actions (<Icon icon="ellipsis" iconType="solid" />)**, puis sur **Supprimer section**. Cela supprime la section et les panneaux qu’elle contient.
