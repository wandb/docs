title: "Code d'erreur API 500 - Le serveur a rencontré une erreur lors du traitement de votre requête"
keywords: ["Erreurs du serveur"]
---

Une erreur `500` accompagnée du message `Le serveur a rencontré une erreur lors du traitement de votre requête` indique une erreur interne du serveur dans Serverless Inference.

## Pourquoi cela arrive {#why-this-happens}

Les erreurs internes du serveur sont généralement passagères et proviennent du côté serveur. Elles ne sont pas causées par votre requête ni par votre configuration.

## Ce que vous pouvez faire {#what-you-can-do}

Pour résoudre l’erreur, suivez ces étapes :

1. **Réessayez après un court délai.** Attendez quelques secondes, puis réessayez votre requête. Utilisez un backoff exponentiel pour les nouvelles tentatives automatiques.
2. **Contactez l’assistance si le problème persiste.** Si vous continuez à voir des erreurs `500` après plusieurs nouvelles tentatives, contactez [l’assistance W&amp;B](mailto:support@wandb.com) en fournissant des détails sur votre requête.
