---
title: Comment préserver les données de run dans des environnements éphémères ?
keywords: ["Variables d'environnement", "Journaux", "Runs"]
---

Définissez `WANDB_DIR` sur un répertoire situé sur un stockage persistant afin de préserver les données de run locales et les journaux de diagnostic dans les environnements éphémères. Sinon, les fichiers du répertoire local `wandb/` peuvent être perdus lorsque le pod ou le conteneur est supprimé.
