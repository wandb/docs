---
title: "Comment puis-je faire pivoter ou révoquer l’accès ?"
keywords: ["Administrateur", "Sécurité", "API Keys"]
---

Si vous avez accès à votre compte, vous pouvez révoquer et faire pivoter vous-même vos clés API personnelles. Si vous n’avez plus accès à votre compte, si la clé appartient à un utilisateur qui a quitté votre organisation ou si vous avez des difficultés à suivre ces instructions, contactez l’[assistance](mailto:support@wandb.com).
Les administrateurs de l’organisation peuvent révoquer et faire pivoter des clés API dans toute l’organisation, et les administrateurs d’équipe peuvent effectuer ces actions pour les clés API d’une équipe.

Pour faire pivoter une clé API dans des circonstances normales :

1. Créez une nouvelle clé API.
2. Reconfigurez vos scripts pour utiliser la nouvelle clé.
3. Supprimez l’ancienne clé.

<Warning>Si une clé API a été divulguée ou compromise, supprimez immédiatement l’ancienne clé au lieu d’attendre.</Warning>

Pour obtenir des instructions étape par étape, voir [Clés API](/fr/platform/app/settings-page/user-settings#api-keys).
