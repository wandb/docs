### genai {#genai}

> `readonly` **genai** : `objet`

#### batchOptions {#batchoptions}

> `facultatif` **batchOptions**: `BufferConfig`

Configuration de `BatchSpanProcessor`. Ignorée sauf si `spanProcessor === 'batch'`.

#### spanProcessor {#spanprocessor}

> `facultatif` **spanProcessor**: `"batch"` | `"simple"` | `SpanProcessor`

Définit comment les spans GenAI sont exportés.

* `'batch'` (par défaut) : `BatchSpanProcessor`, adapté aux agents de production
  et aux processus de longue durée.
* `'simple'` : `SimpleSpanProcessor`, un POST HTTP par span. Utile pour les
  tests et les CLI de courte durée, où un vidage déterministe importe davantage que le
  débit.
* Instance de `SpanProcessor` : un processeur fourni par l&#39;utilisateur. L&#39;appelant est responsable
  de son cycle de vie ; l&#39;exporter OTLP Weave ciblant `/agents/otel/v1/traces`
  n&#39;est pas utilisé.

***

### printCallLink {#printcalllink}

> `readonly` **printCallLink**: `boolean`

Imprime des liens vers l&#39;interface Weave pour les ops dans le terminal.

#### Par défaut {#default}

`true`

***

### useCallsComplete {#usecallscomplete}

> **useCallsComplete** : `boolean`

Envoie les appels terminés au point de terminaison `calls/complete` (début et fin
appariés côté client) plutôt qu&#39;à l&#39;ancien chemin `call/upsert_batch`.

#### Par défaut {#default-2}

`true`

***

### useOTelV2 {#useotelv2}

> **useOTelV2** : `boolean`

Achemine les intégrations compatibles avec OTel via leur variante OTel.

#### Par défaut {#default-3}

`true`
