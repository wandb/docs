Une conversation regroupe des tours de conversation sous un même `gen_ai.conversation.id`. Elle ne
constitue pas elle-même un span OTel : les spans enfants y associent l’ID de conversation.

<div id="startturn">
  ### startTurn()
</div>

> **startTurn**(`opts?`) : [`Turn`](./turn)

Démarre un nouveau `Turn` dans cette `Conversation`. Le tour de conversation hérite du `conversationId` de la conversation ; `agentName`, `agentId`, `agentDescription`, `agentVersion` et `model` utilisent les valeurs de la conversation lorsqu’ils ne sont pas fournis dans `opts`.

<div id="parameters-2">
  #### Paramètres
</div>

<ParamField path="opts" type="TurnInit = {}">
  Voir [`TurnInit`](./turninit).
</ParamField>

<div id="returns-7">
  #### Renvoie
</div>

[`Turn`](./turn)

<div id="examples">
  #### Exemples
</div>

```ts twoslash
// @noErrors
const turn = conversation.startTurn();
```

```ts twoslash
// @noErrors
const turn = conversation.startTurn({
  model: 'gpt-4o',
  agentName: 'research-bot',
  agentId: 'research-bot-prod',
  agentDescription: 'Looks up facts on Wikipedia.',
  agentVersion: '1.4.2',
  userMessage: 'What is the weather in Tokyo?',
  systemInstructions: ['You are a helpful weather bot.'],
  startTime: new Date('2026-05-29T10:00:00.000Z'),
});
```
