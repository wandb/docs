Une invocation d&#39;outil. Émet un span `execute_tool` contenant le nom de l&#39;outil,
les arguments encodés en JSON, l&#39;ID de l&#39;appel d&#39;outil et le résultat.

Créé par `weave.startTool()` (ou `turn.startTool()` ou
`llm.startTool()`) et terminé avec `end()`. Attribuez `result` avant
d&#39;appeler `end()` pour enregistrer la sortie de l&#39;outil dans le span.

Défini dans : [src/genai/tool.ts:43](https://github.com/wandb/weave/blob/8c5f077eb11c42b84000726ff20504abc728d3fb/sdks/node/src/genai/tool.ts#L43)

## Exemple

```ts twoslash
// @noErrors
const tool = weave.startTool({
  name: tc.function.name,
  args: tc.function.arguments,
  toolCallId: tc.id,
});
try {
  tool.result = await wikipediaSearch(JSON.parse(tc.function.arguments));
} finally {
  tool.end();
}
```

<div id="addevent">
  ### ~~addEvent()~~
</div>

<Warning>
  **Obsolète.** Enregistrez plutôt ces données avec [setAttributes](#setattributes).
  OpenTelemetry abandonne progressivement l’API d’événements de span (`Span.addEvent`). Cette
  méthode fonctionne toujours et les données d’événements de span existantes restent valides.
  Voir [https://opentelemetry.io/blog/2026/deprecating-span-events/](https://opentelemetry.io/blog/2026/deprecating-span-events/)
</Warning>

> **addEvent**(`name`, `attributes?`, `startTime?`): `this`

Ajoute un événement nommé au span. Utile pour marquer des moments non associés à un span, tels que
la compaction du contexte, la détection de boucles d’outils ou le déclenchement de guardrails. Émet un avertissement et
ne fait rien après `end()`. Reproduit `Span.addEvent` d’OTel.

Défini dans : [src/genai/spanBase.ts:82](https://github.com/wandb/weave/blob/8c5f077eb11c42b84000726ff20504abc728d3fb/sdks/node/src/genai/spanBase.ts#L82)

> **end**(`opts?`) : `void`

Envoyez `result` au span et fermez-le. Idempotent. Transmettez `error` pour marquer
le span comme ayant échoué ; transmettez `endTime` pour antidater la fermeture.
