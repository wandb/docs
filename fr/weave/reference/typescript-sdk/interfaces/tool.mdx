Une invocation d&#39;outil. Émet un span `execute_tool` contenant le nom de l&#39;outil,
les arguments, l&#39;ID de l&#39;appel d&#39;outil et le résultat. Les arguments et les
résultats de type chaîne sont enregistrés tels quels ; les autres valeurs JSON sont sérialisées.

Créée par `weave.startTool()` (ou `turn.startTool()`, ou
`llm.startTool()`) et terminée par `end()`, qui accepte le résultat et
des métadonnées d&#39;erreur facultatives.

## Exemple {#example}

```ts twoslash
// @noErrors
const tool = weave.startTool({name: 'get_weather', args: {city: 'Tokyo'}});
try {
  const result = await getWeather('Tokyo');
  tool.end({result});
} catch (error) {
  tool.end({error: error as Error, errorType: 'weather_error'});
  throw error;
}
```

## Méthodes {#methods}

### ~~addEvent()~~ {#addevent}

<Warning>
  **Obsolète.** Enregistrez plutôt ces données avec [setAttributes](#setattributes).
  OpenTelemetry abandonne progressivement l’API d’événements de span (`Span.addEvent`). Cette
  méthode fonctionne toujours et les données d’événements de span existantes restent valides.
  Voir [https://opentelemetry.io/blog/2026/deprecating-span-events/](https://opentelemetry.io/blog/2026/deprecating-span-events/)
</Warning>

> **addEvent**(`name`, `attributes?`, `startTime?`): `this`

Ajoute un événement nommé au span. Utile pour marquer des moments non associés à un span, tels que
la compaction du contexte, la détection de boucles d’outils ou le déclenchement de guardrails. Émet un avertissement et
ne fait rien après `end()`. Reproduit `Span.addEvent` d’OTel.

#### Paramètres {#parameters}

<ParamField path="name" type="string" required />

<ParamField path="attributes" type="Attributes" />

<ParamField path="startTime" type="TimeInput" />

#### Renvoie {#returns}

`this`

#### Exemple {#example-2}

```ts twoslash
// @noErrors
span.addEvent('context_compacted', {removedMessages: 12});
```

### end() {#end}

> **end**(`opts?`) : `void`

Enregistrez un résultat et un type d&#39;erreur facultatifs, puis fermez le span. Idempotent.
Transmettez `error` pour marquer le span comme ayant échoué et `endTime` pour antidater la fermeture.

#### Paramètres {#parameters-2}

<ParamField path="opts" type="ToolEndOptions">

</ParamField>

#### Renvoie {#returns-2}

`void`

### setAttributes() {#setattributes}

> **setAttributes**(`attributes`) : `this`

Définit simultanément plusieurs attributs sur le span. Émet un avertissement et ne fait rien après
`end()`. Correspond à `Span.setAttributes` d’OTel (ainsi qu’à
`set_attributes` du SDK Python).

#### Paramètres {#parameters-3}

<ParamField path="attributes" type="Attributes" required />

#### Renvoie {#returns-3}

#### Exemple {#example-3}
