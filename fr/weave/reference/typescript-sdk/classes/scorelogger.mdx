ScoreLogger gère l’attribution d’un score à une seule prédiction.
Renvoyé par EvaluationLogger.logPrediction().

<div id="example">
  ## Exemple
</div>

```ts twoslash
// @noErrors
const pred = await ev.logPrediction(example, output);
await pred.logScore("accuracy", 0.95);
await pred.logScore("relevance", 0.8);
await pred.finish(); // Finalise la prédiction
```

<div id="finish">
  ### finish()
</div>

> **finish**(): `Promise`&lt;`void`&gt;

Termine le processus d’attribution d’un score de la prédiction.
Finalise l’appel `predict_and_score` avec les scores accumulés.
Met à jour les agrégats incrémentiels et libère la mémoire.

<div id="returns-3">
  #### Renvoie
</div>

`Promise`&lt;`void`&gt;

<div id="logscore">
  ### logScore()
</div>

> **logScore**(`scorerName`, `score`): `Promise`&lt;`void`&gt;

Journalisez un score pour cette prédiction.
Crée un appel de scorer enfant de predict&#95;and&#95;score.
