## Paramètres {#parameters}

<ParamField path="options" type="object" required>
  Les options de ce type de média

  * data : les données audio brutes sous forme de Buffer
  * audioType : (Facultatif) le type de fichier audio ; actuellement, seul &#39;wav&#39; est pris en charge

  <Expandable title="propriétés" defaultOpen>

## Exemple {#example}

```ts twoslash
// @noErrors
const audioBuffer = fs.readFileSync('path/to/audio.wav');
const weaveAudio = weaveAudio({ data: audioBuffer });
```
