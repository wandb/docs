```ts
login(apiKey: string, host?: string): Promise<void>
```

<GitHubLink url="https://github.com/wandb/weave/blob/7c9efdc9fe05ffcaf2430dd652ef9bc5b3ffdfaa/sdks/node/src/clientApi.ts#L26" />

Connectez-vous à Weights &amp; Biases (W&amp;B) à l’aide de la clé API fournie.
Cette fonction tente d’enregistrer les identifiants dans votre fichier netrc pour une utilisation ultérieure,
mais elle continue même si elle ne parvient pas à écrire sur le système de fichiers.

<div id="parameters">
  ## Paramètres
</div>

<ParamField path="apiKey" type="string" required>
  Votre clé API W&amp;B.
</ParamField>

<ParamField path="host" type="string">
  (Facultatif) Le nom d’hôte (en général, nécessaire uniquement si vous utilisez un serveur W&amp;B personnalisé).
</ParamField>

<div id="returns">
  ## Renvoie
</div>

`Promise`&lt;`void`&gt;

<div id="throws">
  ## Lève une exception
</div>

Si la clé API n’est pas renseignée ou si la connexion au serveur de trace Weave ne peut pas être vérifiée.
