<div id="parameters">
  ## Paramètres
</div>

<ParamField path="options" type="object" required>
  Les options de ce type de média

  * data : les données brutes de l’image sous forme de Buffer
  * imageType : (Facultatif) le format de l’image : &#39;png&#39; (par défaut), &#39;jpeg&#39; ou &#39;webp&#39;.
    Lors de la publication, le fichier stocké est toujours nommé image.png
