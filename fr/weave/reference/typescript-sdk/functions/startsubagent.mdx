## Paramètres {#parameters}

<ParamField path="opts" type="SubAgentInit" required>
  Voir [`SubAgentInit`](../interfaces/subagentinit).

## Renvoie {#returns}

## Exemples {#examples}

```ts twoslash
// @noErrors
weave.startSubagent({name: 'critic'});
```

```ts twoslash
// @noErrors
weave.startSubagent({
  name: 'critic',
  model: 'gpt-4o',
  systemInstructions: ['Critique the proposed plan.'],
  startTime: new Date('2026-05-29T10:00:00.000Z'),
});
```
