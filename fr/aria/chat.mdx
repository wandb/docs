Cette page explique comment gérer vos conversations avec ARIA : démarrer et reprendre des chats, mettre en file d&#39;attente des messages de suivi, ajouter du contexte, accorder l&#39;accès au réseau et donner votre feedback sur les réponses. Le contexte peut inclure des runs, des panneaux du Workspace, des traces W&amp;B Weave et des images. Elle explique également comment organiser votre historique de conversation en renommant, épinglant et supprimant des conversations.

## Démarrer un nouveau chat {#start-a-new-chat}

Pour démarrer un nouveau chat, ouvrez ARIA, puis cliquez sur l’icône en forme de crayon dans le coin supérieur droit de la fenêtre de chat.

Vous pouvez mener plusieurs chats en parallèle. ARIA vous notifie lorsqu’il répond à un chat, même si vous avez fermé la fenêtre de chat.

Démarrer un nouveau chat ne supprime pas vos conversations précédentes. Pour [voir les conversations précédentes](/fr/aria/chat#view-chat-history), cliquez sur **<Icon icon="sidebar-reveal" iconType="solid" />** (**Reveal chat history**) pour ouvrir la barre latérale de l’historique de conversation.

## Envoyer un message {#send-a-message}

Saisissez un message, puis appuyez sur **Entrée** pour l’envoyer.

* Appuyez sur **Maj+Entrée** pour ajouter des lignes.
* Cliquez sur **+** pour ajouter des images.
* Pour ajouter une référence de run, saisissez `<Icon icon="at" iconType="solid"/>`, puis sélectionnez un run dans la liste. Saisissez du texte pour filtrer la liste et effectuer une recherche approximative.
* Pour plus de flexibilité, rédigez un message plus complexe dans un éditeur de texte, puis collez-le. Le texte brut est pris en charge et les caractères `@` collés ne sont pas résolus en références de run.

Pour annuler l’opération en cours et envoyer *immédiatement* le prochain [message en file d&#39;attente](#queue-messages), appuyez sur l’icône d’arrêt à droite du champ de saisie.

Pour vous aider à conserver le contexte, ARIA affiche les graphiques en courbes et les graphiques à barres directement dans le chat, avec prise en charge de l’affichage en plein écran. Le survol d’un run dans l’onglet **Runs** du workspace met en évidence les graphiques de ce run dans ARIA, et le survol d’un panel dans ARIA met en évidence le run dans l’onglet **Runs**.

## Messages en file d&#39;attente {#queue-messages}

La file d&#39;attente de messages contient les tâches de suivi et les questions que vous envoyez à ARIA pendant qu&#39;elle travaille. ARIA traite chaque message en file d&#39;attente dans l&#39;ordre, en utilisant l&#39;intégralité de la conversation comme contexte. Le message suivant est traité dès que le précédent est terminé.

Utilisez la file d&#39;attente pour enchaîner plusieurs étapes à la fois et vous éloigner, plutôt que de revenir au chat pour les envoyer une par une. Par exemple, vous pouvez commencer par une comparaison :

<AriaChatBubbles prompt="Comparez les 10 derniers runs et indiquez-moi quels hyperparamètres ont le plus compté." response="Le taux d'apprentissage et la taille de lot expliquent la majeure partie de la variance de la perte de validation sur ces 10 runs. Vous trouverez les détails de chacun ci-dessous." />

Pendant qu&#39;ARIA travaille, envoyez des requêtes supplémentaires dans la fenêtre de chat. W&amp;B ajoute les requêtes en attente à la file d&#39;attente d&#39;ARIA.

Cet exemple envoie deux messages à la fois :

```text title="Queued messages"
Trace un graphique de la perte de validation en fonction du taux d'apprentissage pour ces runs.

Rédige cette comparaison sous forme de report que je puisse partager avec mon équipe.
```

L’en-tête de la file d’attente indique le nombre de messages en attente. Chaque message en file d’attente comporte trois commandes :

* **Icône en forme de crayon** (<Icon icon="pencil" iconType="solid" />) : modifiez le message avant qu’ARIA ne l’exécute. ARIA place le message dans la zone de saisie et le retire de la file d’attente. Renvoyez-le pour le remettre en file d’attente. Cette commande est indisponible si la zone de saisie contient déjà un brouillon.
* **Icône de flèche vers le haut** (<Icon icon="arrow-up" iconType="solid" />) : exécutez le message immédiatement, sans attendre son tour. ARIA interrompt son travail en cours et exécute ce message en priorité. Les autres messages en file d’attente conservent leur ordre.
* **Icône de corbeille** (<Icon icon="trash" iconType="solid" />) : supprimez le message de la file d’attente.

Les messages en file d’attente conservent le contexte que vous leur avez joint, notamment les [mentions de runs](/fr/aria/chat#add-context-to-a-conversation) et les [images](/fr/aria/chat#add-an-image-to-a-conversation).

La mise en file d’attente commence après votre premier message dans un chat, car une file d’attente nécessite une conversation sur laquelle s’exécuter. Le premier message que vous envoyez, ainsi que tout message envoyé à un chat inactif dont la file d’attente est vide, est transmis immédiatement à ARIA. Chaque chat possède sa propre file d’attente, et les files d’attente des chats que vous fermez continuent de s’exécuter.

Si ARIA a besoin d’une clarification ou de votre autorisation avant de poursuivre, la file d’attente est suspendue jusqu’à votre réponse. Pour exécuter un message en file d’attente sans répondre au préalable, cliquez sur l’icône de flèche vers le haut à côté de ce message.

## Gérer les conversations {#manage-conversations}

Les sections suivantes décrivent comment afficher, renommer, épingler et supprimer vos conversations.

### Voir l&#39;historique de conversation {#view-chat-history}

Pour consulter les conversations précédentes :

1. Ouvrez ARIA.
2. Cliquez sur **<Icon icon="sidebar-reveal" iconType="solid" />** (**Reveal chat history**) pour ouvrir la barre latérale de l&#39;historique de conversation. Elle est repliée par défaut. Ce même bouton affiche **Collapse chat history** lorsque la barre latérale est ouverte.
3. Sélectionnez une conversation pour la reprendre.

Les conversations épinglées apparaissent en premier, sous un unique en-tête **Pinned**, sans regroupement par date. Viennent ensuite les conversations non épinglées, regroupées sous **Today**, **Yesterday**, **Last 7 Days**, **Last 30 Days**, puis par mois, puis par mois et année pour les conversations de plus d&#39;un an. Au sein de chaque groupe, la conversation active la plus récente apparaît en premier.

Survolez la ligne d&#39;une conversation, ou placez-y le focus au clavier, pour faire apparaître deux boutons :

* **<Icon icon="thumbtack" iconType="solid" />** (**Pin chat** / **Unpin chat**) : voir [Épingler une conversation](#pin-a-conversation).
* **<Icon icon="ellipsis" iconType="solid" />** (**Chat actions**) : ouvre un menu proposant **Rename chat** et **Delete chat**. Voir [Renommer une conversation](#rename-a-conversation) et [Supprimer des conversations précédentes](#delete-previous-conversations).

La section **Customize** de la barre latérale de l&#39;historique de conversation répertorie également les automatisations ARIA que vous avez créées. Voir [Utiliser les automatisations avec ARIA](/fr/models/automations/create-automations/aria).

### Renommer une conversation {#rename-a-conversation}

Lorsque vous envoyez le premier message d&#39;un nouveau chat, ARIA génère un titre pour la conversation. Le titre scintille dans la barre latérale de l&#39;historique de conversation pendant qu&#39;ARIA le rédige. Si ARIA ne parvient pas à générer de titre, la conversation prend pour titre un extrait de votre premier prompt. ARIA n&#39;attribue un titre à une conversation qu&#39;une seule fois : les messages suivants ne modifient pas le titre.

Pour attribuer un autre titre à une conversation :

1. Dans la barre latérale de l&#39;historique de conversation, survolez la conversation que vous souhaitez renommer.
2. Cliquez sur **<Icon icon="ellipsis" iconType="solid" />** (**Chat actions**), puis sélectionnez **Rename chat**. Le titre devient un champ modifiable.
3. Saisissez un titre de 255 caractères maximum.
4. Appuyez sur **Entrée** ou cliquez sur **<Icon icon="check" iconType="solid" />** (**Save chat title**) pour enregistrer. Appuyez sur **Échap** ou cliquez sur **<Icon icon="xmark" iconType="solid" />** (**Cancel rename**) pour annuler votre modification.

Si vous videz le champ puis enregistrez, le titre est remplacé par un extrait de votre premier prompt, ou par **Untitled conversation** si aucun extrait n&#39;est disponible. Si vous enregistrez une saisie composée uniquement d&#39;espaces, le renommage est annulé et le titre est conservé.

Les titres renommés sont synchronisés entre tous les onglets ouverts de votre navigateur. Vous pouvez également renommer un chat depuis votre téléphone. Voir [Chat avec ARIA](/fr/platform/hosting/monitoring-usage/mobile-app#chat-with-aria) dans la documentation de l&#39;application mobile.

### Épingler une conversation {#pin-a-conversation}

Épinglez une conversation pour la maintenir en haut de la barre latérale de l&#39;historique de conversation, au lieu de la laisser descendre au fur et à mesure que de nouveaux chats s&#39;accumulent.

1. Dans la barre latérale de l&#39;historique de conversation, survolez la conversation que vous souhaitez épingler.
2. Cliquez sur **<Icon icon="thumbtack" iconType="solid" />** (**Pin chat**). La conversation passe sous l&#39;en-tête **Pinned**.
3. Pour la désépingler, cliquez sur **<Icon icon="thumbtack" iconType="solid" />** (**Unpin chat**) sur une conversation épinglée.

Le nombre de conversations épinglables n&#39;est pas limité, et les modifications d&#39;épinglage sont synchronisées entre vos onglets de navigateur ouverts. L&#39;épinglage n&#39;affecte que votre propre liste de conversations, et non ce que voient les membres de votre équipe ayant accès au même projet.

### Supprimer les conversations précédentes {#delete-previous-conversations}

Pour supprimer une conversation précédente :

1. Ouvrez ARIA.
2. Cliquez sur **<Icon icon="sidebar-reveal" iconType="solid" />** (**Reveal chat history**) pour ouvrir la barre latérale de l’historique de conversation.
3. Survolez la conversation que vous souhaitez supprimer, cliquez sur **<Icon icon="ellipsis" iconType="solid" />** (**Chat actions**), puis sélectionnez **Delete chat**.
4. Dans la boîte de dialogue **Delete this chat?**, cliquez sur **Delete** pour confirmer. Cette action est irréversible.

## Détacher la fenêtre de chat {#undock-chat-window}

Vous pouvez détacher la fenêtre de chat dans une fenêtre séparée, ce qui vous permet d’afficher la réponse d’ARIA côte à côte avec les données de votre projet.

Pour détacher le chat, cliquez sur l’icône de détachement dans le coin supérieur droit de la fenêtre de chat, à côté du bouton de fermeture (**X**).

## Ajouter du contexte à une conversation {#add-context-to-a-conversation}

Joignez des runs, des panneaux du Workspace, ainsi que des traces et des évaluations Weave à un chat afin de fournir à ARIA le contexte précis de votre question. Chaque élément s&#39;affiche dans la zone de saisie sous forme de tag que vous pouvez supprimer. Vous pouvez joindre plusieurs éléments à un même message. L&#39;ajout de contexte n&#39;envoie pas le message à lui seul. Lorsque vous êtes prêt, cliquez sur **Send**.

Lorsque vous ajoutez du contexte depuis une page, ARIA l&#39;ajoute à la conversation ouverte dans la fenêtre de chat. Si aucune conversation n&#39;est ouverte, ARIA en démarre une nouvelle.

### Mentionner un run {#mention-a-run}

Saisissez `@` dans la zone de saisie et sélectionnez un run. Par exemple, vous pouvez demander à ARIA d’analyser un run précis en incluant le nom du run dans votre prompt :

```text title="User prompt"
Analyze the run @run-20230615_123456-abcdefg and summarize the results
```

Vous pouvez également ajouter un run depuis le tableau **Runs** du Workspace. Survolez le run, cliquez sur son menu **action (<Icon icon="ellipsis" iconType="solid" />)**, puis sélectionnez **Ask ARIA**.

### Ajouter un panneau de Workspace {#add-a-workspace-panel}

Pour joindre un panneau de Workspace à un chat :

1. Dans votre Workspace, survolez le panneau et cliquez sur son menu **action (<Icon icon="ellipsis" iconType="solid" />)**.
2. Sélectionnez **Ask ARIA**. ARIA s&#39;ouvre avec le panneau joint.
3. Saisissez votre question, par exemple `Why does loss spike after step 2,000?`, puis envoyez-la.

L&#39;option **Ask ARIA** figure dans les menus des panneaux des Workspaces que vous pouvez modifier. Elle n&#39;est pas disponible dans les panneaux des Reports.

### Ajouter des traces et des évaluations Weave {#add-weave-traces-and-evaluations}

Dans Weave, cliquez sur le bouton ARIA pour joindre des traces, des évaluations ou des résultats d’évaluation à un chat. Survolez le bouton pour afficher son libellé, par exemple **Ask ARIA about this trace** ou **Ask ARIA about these evals**. Le bouton est disponible aux emplacements suivants :

* Tableau **Traces** ou **Evals** : sélectionnez une ou plusieurs lignes. Le bouton apparaît dans la barre d’outils du tableau et joint toutes les lignes sélectionnées.
* **Page de détails d’une trace ou d’une évaluation** : le bouton se trouve dans l’en-tête de la page.
* **Comparaison d’évaluations** : lorsque vous comparez des évaluations et affichez les détails d’un exemple, le bouton joint les prédictions et les scores de cet exemple.

ARIA s’appuie sur les traces et les évaluations jointes pour répondre à votre question. Par exemple :

```text title="User prompt"
Pourquoi le modèle a-t-il obtenu un score plus faible sur ces exemples que lors de l'évaluation précédente ?
```

## Ajouter une image à une conversation {#add-an-image-to-a-conversation}

Cliquez sur l’icône plus (`+`) dans l’angle inférieur gauche de la fenêtre de chat pour ajouter une image à votre conversation. Vous pouvez ensuite demander à ARIA d’analyser l’image ou de vous fournir des informations à son sujet.

## Accorder l&#39;accès réseau {#grant-network-access}

Lorsqu&#39;une tâche a besoin d&#39;un domaine bloqué par le sandbox d&#39;ARIA, ARIA vous demande un accès réseau et attend votre réponse. Par exemple, une tâche qui installe un paquet Python a besoin de `pypi.org` et de `files.pythonhosted.org`. Par défaut, le sandbox dans lequel ARIA exécute du code peut joindre les services W&amp;B, mais bloque la plupart des autres domaines sur Internet.

La requête s&#39;affiche dans le chat sous **The agent is requesting network access**. Elle indique le motif de la demande et répertorie les domaines demandés, tous sélectionnés. Répondez à la requête de l&#39;une des manières suivantes :

* Pour accorder l&#39;accès, décochez les domaines que vous ne souhaitez pas autoriser, puis cliquez sur **Grant access**. ARIA reprend son travail et peut joindre les domaines autorisés.
* Pour refuser l&#39;accès, cliquez sur **Deny**. ARIA poursuit sans cet accès supplémentaire.

Tant qu&#39;une requête est en attente, vous ne pouvez pas envoyer de messages et les messages en file d&#39;attente ne sont pas exécutés.

<Warning>
  Le code exécuté dans le sandbox peut envoyer des données à n&#39;importe quel domaine que vous autorisez. N&#39;accordez l&#39;accès qu&#39;aux domaines de confiance.
</Warning>

Les domaines autorisés restent disponibles pendant toute la durée de la conversation, jusqu&#39;à ce que vous les révoquiez. Chaque nouveau chat démarre uniquement avec l&#39;accès par défaut. Vous ne pouvez pas ajouter de domaines vous-même : ARIA les demande lorsqu&#39;une tâche en a besoin.

### Vérifier ou révoquer l&#39;accès réseau {#review-or-revoke-network-access}

Une fois l&#39;accès accordé dans une conversation, **<Icon icon="link" iconType="solid" />** (**Manage network access**) apparaît dans la zone de saisie, à côté de l&#39;icône plus (`+`).

Pour révoquer l&#39;accès :

1. Cliquez sur **<Icon icon="link" iconType="solid" />** (**Manage network access**). La liste des domaines autorisés pour la conversation s&#39;ouvre.
2. Décochez les domaines dont vous souhaitez révoquer l&#39;accès.
3. Cliquez sur **Update access**.

W&amp;B envoie à ARIA un message indiquant les domaines révoqués, et ARIA s&#39;exécute désormais sans y avoir accès. Vous ne pouvez pas modifier l&#39;accès réseau pendant qu&#39;ARIA travaille.

## Donner votre avis {#provide-feedback}

Cliquez sur l’icône de pouce levé ou de pouce baissé à la fin de la réponse pour donner votre avis sur la réponse d’ARIA. Votre avis aide W&amp;B à améliorer les performances et la précision d’ARIA.

Pour savoir comment W&amp;B gère l’utilisation des données pour ARIA, voir [Gouvernance et sécurité](/fr/aria/governance).
